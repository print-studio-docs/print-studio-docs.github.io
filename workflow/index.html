从零到打印：完整工作流 ​

一条主线完成「创建实例 → 创建模板 → 绘制元素 → 绑定数据 → 模板预览 → 打印预览与执行打印 → 导出文件」7 个环节，全程只用代码，不依赖设计器界面。

  1. 11 实例→
  2. 22 模板→
  3. 33 元素→
  4. 44 绑定→
  5. 55 预览→
  6. 66 打印→
  7. 77 导出

第一步：创建实例 ​

ts
import { createPrintStudio } from '@printstack/print-studio'

const studio = createPrintStudio({ storage: false })

storage: false 关闭自动草稿——纯代码场景由业务全权管理保存。实例必须在流程结束时 dispose()，本页在第七步的 finally 中统一释放。

第二步：创建模板 ​

缺省打开的欢迎模板仅供设计器试用；纯代码搭建从空白文档开始：

ts
studio.document.create() // 重置为空白文档
studio.document.rename('销售订单')

文档 → 页面 → 数据源：

ts
const page = studio.page.active
page.update({
  name: '订单页',
  width: 210, // mm，A4 纵向
  height: 297,
  margins: { top: 25, right: 10, bottom: 20, left: 10 },
})

// 数据源声明（可选）：schema 供绑定选择器使用，sampleData 用于数据预览与省略 input 时的缺省输入
studio.dataSource.upsert({
  key: 'order',
  label: '订单',
  sampleData: { number: 'SO-2026-001', customer: '示例客户' },
  schema: [
    { name: 'number', type: 'string' },
    { name: 'customer', type: 'string' },
  ],
})
studio.dataSource.upsert({
  key: 'items',
  label: '商品明细',
  sampleData: [{ name: '商品 1', quantity: 2, amount: 10 }],
  schema: [
    {
      name: 'item',
      type: 'array',
      children: [
        { name: 'name', type: 'string' },
        { name: 'quantity', type: 'number' },
        { name: 'amount', type: 'number' },
      ],
    },
  ],
})

第三步：绘制元素 ​

页眉（放页面模板，跨页共用）+ 明细表（跨页）+ 标签页（循环区块）：

ts
// 页面模板：公司抬头 + 页码
const stationery = studio.template.create({ name: '公司抬头与页码' })
stationery.page.update({
  width: 210,
  height: 297,
  margins: { top: 25, right: 10, bottom: 20, left: 10 },
})
stationery.page.elements.add({
  type: 'text',
  x: 10,
  y: 8,
  width: 190,
  height: 10,
  props: { text: '示例公司 · {{ $document.documentName }}', fontSize: 16 },
})
stationery.page.elements.add({
  type: 'text',
  x: 10,
  y: 283,
  width: 190,
  height: 8,
  props: {
    text: '第 {{ $document.pageNumber }} / {{ $document.pageCount }} 页',
    textAlign: 'center',
    fontSize: 9,
  },
})
studio.template.apply(stationery, [page])

// 订单页：表头 + 明细表 + 签字区（跟随表格末尾）
page.elements.add({
  type: 'text',
  x: 10,
  y: 27,
  width: 190,
  height: 10,
  props: { text: '订单：{{ order.number }}    客户：{{ order.customer }}' },
})
const table = page.elements.add({
  type: 'table',
  x: 10,
  y: 42,
  width: 190,
  bindings: { rows: 'items' },
  props: {
    columns: [
      { title: '商品', bind: 'name', width: 3, align: 'left' },
      { title: '数量', bind: 'quantity', width: 1, align: 'right' },
      {
        title: '金额',
        bind: 'amount',
        width: 2,
        align: 'right',
        format: { type: 'number', digits: 2 },
      },
    ],
    rows: [],
    heightMode: 'auto',
    pagination: {
      crossPage: true,
      repeatHeader: true,
      rowsPerPage: 20,
      fillEmptyRows: false,
      positionMode: 'flow',
    },
    summary: {
      enabled: true,
      position: 'bottom',
      scope: 'lastPage',
      columns: { '0': { type: 'text', text: '合计' }, '2': { type: 'sum' } },
    },
  },
})
const signature = page.elements.add({
  type: 'text',
  x: 10,
  y: 70,
  width: 120,
  height: 12,
  props: { text: '收货人签字：____________' },
})
studio.followBlock.create({
  pageId: page.id,
  elementIds: [signature.id],
  target: { kind: 'element', id: table.id },
  gap: 5,
  name: '签收区域',
})

// 标签页：3 列循环平铺
const labelPage = studio.page.create({
  name: '商品标签',
  width: 210,
  height: 297,
})
studio.template.apply(stationery, [labelPage])
const label = labelPage.elements.add({
  type: 'text',
  x: 10,
  y: 30,
  width: 55,
  height: 20,
  props: {
    text: '商品：{{ name }}\n数量：{{ quantity | number:0 }}',
    fontSize: 10,
  },
})
studio.repeatGroup.create({
  pageId: labelPage.id,
  elementIds: [label.id],
  name: '商品标签网格',
  collection: 'items',
  direction: 'grid',
  columns: 3,
  gapX: 5,
  gapY: 3,
  positionMode: 'flow',
})

第四步：绑定数据 ​

模板中的 {{ … }} 表达式与 bindings 在输出时求值。注入的 input 是本次完整输入：

ts
const input = {
  order: { number: 'SO-2026-001', customer: '示例客户' },
  items: Array.from({ length: 45 }, (_, i) => ({
    name: `商品 ${i + 1}`,
    quantity: 2,
    amount: (i + 1) * 10,
  })),
}

第五步：模板预览 ​

注入数据查看模板的输出效果，检查分页与告警：

ts
// 输出预览：iframe 遮罩，可关闭
const handle = await studio.preview(input)
handle.close()

// 嵌入指定容器
await studio.preview(input, { container: document.getElementById('pv')! })

// 独立挂载完整打印预览：无需先挂载设计器
// 预览界面提供分页导航、缩放、数据编辑和打印操作
await studio.preview(input, {
  mode: 'designer',
  container: document.getElementById('pv')!,
})

// 静态 HTML：生成完整文档后由宿主展示
const { html } = await studio.toHTML(input)
const iframe = document.createElement('iframe')
iframe.srcdoc = html
document.body.appendChild(iframe)

画布编辑预览只有挂载设计器后才存在：studio.mount({ el })；开启 settings.previewWithData 后画布按示例数据解析（数据预览）。studio.preview(input, { mode: 'designer' }) 则可在不挂载设计器的情况下独立展示完整打印预览，并支持指定容器。各输出形态的对比见预览 / 打印 / 导出。

第六步：打印预览与执行打印 ​

ts
const { warnings } = await studio.print(input, { timeoutMs: 30000 })
  • print() 经隐藏 iframe 调起浏览器打印对话框；对话框内的展示由浏览器提供，warnings 只反映本次渲染的绑定与资源告警。
  • print() resolve 只表示任务已提交；不代表用户确认或设备出纸。
  • 打印 CSS（@page size、分页边界）由管线自动生成，无需业务提供。
  • 调起打印对话框前需要确认输出效果时，先执行第五步的 studio.preview(input)。

第七步：导出文件 ​

ts
// PDF：生成 Blob，由宿主触发保存
const { blob } = await studio.toPDF(input)
downloadBlob(blob, 'order.pdf')

// HTML：生成完整 HTML 文档字符串，由宿主展示或保存
const { html } = await studio.toHTML(input)

// 模板 JSON：存服务端，下次 document.loadJson 恢复
const json = studio.export.json()
ts
function downloadBlob(blob: Blob, filename: string): void {
  const url = URL.createObjectURL(blob)
  const link = document.createElement('a')
  link.href = url
  link.download = filename
  link.click()
  URL.revokeObjectURL(url)
}

导出方法只生成结果，不触发下载；输出格式为 HTML / PDF / 模板 JSON，无位图导出，详见预览 / 打印 / 导出。

流程结束（含异常路径）在 finally 中释放实例：

ts
try {
  // 第二、三步的模板构建与第五至七步的输出调用
} finally {
  studio.dispose()
}

上面各步的组合即上方 Playground 中的「完整订单工作流」示例（订单 + 45 行明细 + 合计 + 签字区 + 标签页）。关键决策回顾：

决策理由
页眉页码放页面模板多页共用，渲染在内容层之下
表格 crossPage + repeatHeader45 行明细自动分页且延续页带表头
签字区用跟随块始终跟随表格末尾，无需按内容量调整位置
标签用 repeatGroup 网格数据驱动平铺，超页自动分页
汇总 scope: 'lastPage'末页全量合计
