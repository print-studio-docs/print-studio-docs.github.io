createPrinter() ​

createPrinterfunction

`@printstack/print-studio/printer` 的 `createPrinter()` 创建**纯输出渲染器**：不创建编辑实例、不持有可编辑文档、不提供事件接口。适合「已有模板 JSON、只需注入数据输出」的场景：输出服务、后台批量打印、定时任务。
ts
import { createPrinter } from '@printstack/print-studio/printer'
import type { Printer, PrinterOptions } from '@printstack/print-studio/printer'

创建选项 ​

选项
选项类型必填默认值说明
errorsErrorRuntime可选—错误运行时；默认创建独立实例；业务提示经规则接入
elementsElementDefinition[]可选—元素集合；传入后不自动注册内置元素；仍会注册 resources 中的元素
parsersDocumentParser[]可选—自定义解析器；补充或覆盖同 ID 解析器
resourcesPluginResources[]可选—共享资源包；在内置元素和解析器的基础上注册共享资源，可与设计器使用同一资源包
rendering{ fonts?; imageLoadTimeoutMs?; worker?; workerTimeoutMs? }可选—渲染配置；imageLoadTimeoutMs 默认 15000（ms），控制单张图片加载与解码等待；worker 默认 false，workerTimeoutMs 默认 60000（ms）；fonts 同 Designer

成员 ​

成员
成员类型必填默认值说明
toHTML(template, input, options?, execution?)Promise<HtmlResult>可选—生成 HTML；options 为 HtmlParseOptions，见 [预览 / 打印 / 导出](./output)
toPDF(template, input, options?, execution?)Promise<PdfResult>可选—生成 PDF；options 为 PdfParseOptions，见 [预览 / 打印 / 导出](./output)
preview(template, input, options?)Promise<PreviewHandle>可选—浏览器 iframe 预览；画布主题见 [预览 / 打印 / 导出](./output#preview)
print(template, input, options?)Promise<{ warnings }>可选—浏览器打印
errorsErrorRuntime可选—统一错误运行时
elements / parsersElementRegistry / ParserRegistry可选—渲染器注册表；elements 也用于 deserializeDocument 反序列化
dispose()() => void可选—释放资源；取消待完成任务，可重复调用

template 必填（PrintDocument），input 必填（Record<string, unknown>；无数据时显式传 {}，不会自动用示例数据替代）。

所有输出入口在准备资源前，按当前元素注册表补全缺失或为 undefined 的属性并执行元素的 normalizeProps；页面模板中的元素遵循同一规则，传入模板不被修改。外部 JSON 应使用 deserializeDocument(rawJson, printer.elements) 读取，并检查 skippedTypes。内置元素包括钢笔路径；扩展元素需在读取前随 resources 或 elements 注册。

完整示例 ​

ts
import { createErrorRuntime } from '@printstack/print-studio'
import { deserializeDocument } from '@printstack/print-studio/core'
import { createPrinter } from '@printstack/print-studio/printer'

const renderer = createPrinter({
  errors: createErrorRuntime({
    report(event) {
      console.error('输出失败', event.context.source, event.error)
    },
  }),
  rendering: {
    imageLoadTimeoutMs: 15000,
    worker: false,
    workerTimeoutMs: 60000,
  },
})

try {
  // 模板可来自服务端；deserializeDocument 宽容补全并剔除未注册类型
  const raw = JSON.parse(
    await fetch('/api/templates/invoice').then((r) => r.text()),
  )
  const { document, skippedTypes } = deserializeDocument(raw, renderer.elements)
  if (skippedTypes.length > 0) {
    console.warn('跳过的未注册类型：', skippedTypes)
  }

  const input = { order: { number: 'SO-2026-001' } }
  const { html } = await renderer.toHTML(document, input, { title: '订单打印' })
  const { blob } = await renderer.toPDF(document, input, {
    rasterPxPerMm: 300 / 25.4,
  })
} finally {
  renderer.dispose()
}

createPrinter() 省略 elements 时自动注册全部内置元素。需要缩小产物或使用自定义元素集合时，显式传入所需元素集合；传入后只注册该集合：

ts
import {
  createPrinter,
  textElement,
  tableElement,
} from '@printstack/print-studio/printer'

const printer = createPrinter({ elements: [textElement, tableElement] })

如果需要同时使用内置元素和自定义元素，请将两者合并后传入 elements：

ts
import {
  builtinElements,
  createPrinter,
} from '@printstack/print-studio/printer'

const printer = createPrinter({ elements: [...builtinElements, watermark] })

与 Designer 输出的差异 ​

对比项createDesigner()createPrinter()
调用签名studio.toHTML(input?, …)（模板在实例内）renderer.toHTML(template, input, …)（每次显式传入）
编辑能力document / page / elements / events 全量无
输入缺省回退数据源 sampleData必须显式传入 {} 或数据
Vue 组件可传给 <PrintDesigner>不可

WARNING

参数方向不能互换 studio.toHTML(input) 只接收数据；renderer.toHTML(template, input) 模板在前。创建选项也不同：PrinterOptions 仅含 errors / elements / parsers / printTargets / resources / rendering，不含文档、保存与挂载相关选项。

预览与打印 ​

ts
const preview = await renderer.preview(template, input, { container })
preview.close()

const { warnings } = await renderer.print(template, input, {
  target: 'browser',
  timeoutMs: 30000,
})

createPrinter({ printTargets }) 可注册外部目标，目标选择与返回值规则同 studio.print()。

浏览器目标的 print() resolve 后即可 dispose()（打印对话框已调起）；预览窗口打开期间 dispose() 会关闭预览。print() 返回成功不代表设备出纸。
