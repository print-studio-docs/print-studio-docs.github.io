createPrintRenderer() ​

@printstack/print-studio/runtime 的 createPrintRenderer() 创建纯输出渲染器：不创建编辑实例、不持有可编辑文档、不提供事件接口。适合「已有模板 JSON、只需注入数据输出」的场景：输出服务、后台批量打印、定时任务。

ts
import { createPrintRenderer } from '@printstack/print-studio/runtime'
import type { PrintRenderer, PrintRendererOptions } from '@printstack/print-studio/runtime'

创建选项 ​

选项功能类型必填说明
errors错误运行时ErrorRuntime否默认创建独立实例；业务提示经规则接入
elements自定义元素ElementDefinition[]否补充或覆盖同类型内置元素
parsers自定义解析器DocumentParser[]否补充或覆盖同 ID 解析器
rendering渲染配置{ fonts?; worker?; workerTimeoutMs? }否worker 默认 false，workerTimeoutMs 默认 60000（ms）；fonts 同 DesignStudio

成员 ​

成员功能类型必填说明
toHTML(template, input, options?, execution?)生成 HTMLPromise<HtmlResult>否options 为 HtmlParseOptions，见 [预览 / 打印 / 导出](./output)
toPDF(template, input, options?, execution?)生成 PDFPromise<PdfResult>否options 为 PdfParseOptions，见 [预览 / 打印 / 导出](./output)
preview(template, input, options?)浏览器预览Promise<PreviewHandle>否
print(template, input, options?)浏览器打印Promise<{ warnings }>否
errors统一错误运行时ErrorRuntime否
elements / parsers渲染器注册表ElementRegistry / ParserRegistry否elements 也用于 deserializeDocument 反序列化
dispose()释放资源() => void否取消待完成任务，可重复调用

template 必填（PrintDocument），input 必填（Record<string, unknown>；无数据时显式传 {}，不会自动用示例数据替代）。

完整示例 ​

ts
import { createErrorRuntime } from '@printstack/print-studio'
import { deserializeDocument } from '@printstack/print-studio/core'
import { createPrintRenderer } from '@printstack/print-studio/runtime'

const renderer = createPrintRenderer({
  errors: createErrorRuntime({
    report(event) {
      console.error('输出失败', event.context.source, event.error)
    },
  }),
  rendering: { worker: false, workerTimeoutMs: 60000 },
})

try {
  // 模板可来自服务端；deserializeDocument 宽容补全并剔除未注册类型
  const raw = JSON.parse(await fetch('/api/templates/invoice').then((r) => r.text()))
  const { document, skippedTypes } = deserializeDocument(raw, renderer.elements)
  if (skippedTypes.length > 0) {
    console.warn('跳过的未注册类型：', skippedTypes)
  }

  const input = { order: { number: 'SO-2026-001' } }
  const { html } = await renderer.toHTML(document, input, { title: '订单打印' })
  const { blob } = await renderer.toPDF(document, input, { rasterPxPerMm: 300 / 25.4 })
} finally {
  renderer.dispose()
}

与 DesignStudio 输出的差异 ​

对比项createPrintStudio()createPrintRenderer()
调用签名studio.toHTML(input?, …)（模板在实例内）renderer.toHTML(template, input, …)（每次显式传入）
编辑能力document / page / elements / events 全量无
输入缺省回退数据源 sampleData必须显式传入 {} 或数据
Vue 组件可传给 <PrintDesigner>不可

参数方向不能互换

studio.toHTML(input) 只接收数据；renderer.toHTML(template, input) 模板在前。创建选项也不同：PrintRendererOptions 仅含 errors / elements / parsers / rendering，不含文档、保存与挂载相关选项。

预览与打印 ​

ts
const preview = await renderer.preview(template, input, { container })
preview.close()

const { warnings } = await renderer.print(template, input, { timeoutMs: 30000 })

print() resolve 后即可 dispose()（打印对话框已调起）；预览窗口打开期间 dispose() 会关闭预览。print() 返回成功不代表设备出纸。
