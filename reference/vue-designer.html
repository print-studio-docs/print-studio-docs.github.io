Vue 集成 ​

@printstack/print-studio/vue 提供 Vue 3 组件与组合式函数。非 Vue 宿主直接用 studio.mount({ el })，见 createDesigner。

ts
import {
  PrintDesigner,
  useDesigner,
  installDesigner,
  createEditorContext,
} from '@printstack/print-studio/vue'

useDesigner() ​

ts
function useDesigner(options?: UseDesignerOptions): Designer

interface UseDesignerOptions extends DesignerOptions {
  context?: EditorContext
}
ts
const studio = useDesigner({ storage: false })
选项
选项类型必填默认值说明
contextEditorContext可选—显式复用已有上下文；不传时先找祖先注入，再新建实例
其余选项DesignerOptions可选—同 createDesigner；仅在本次新建实例时应用；复用上下文时只应用 defaultElementType

上下文选择顺序：显式 context → 祖先注入 → 新建实例。返回的 Designer 在当前 Vue 作用域销毁时自动 dispose；复用的上下文本身不会被销毁，由创建方清理。

TIP

Vue 注入只能从祖先流向后代：父页面无法获取子设计器的注入，兄弟组件也不会自动共享。需要共享时把 studio 显式传给 <PrintDesigner :studio="studio" />。

PrintDesigner 组件 ​

vue
<script setup lang="ts">
import { PrintDesigner, useDesigner } from '@printstack/print-studio/vue'

const studio = useDesigner({ storage: false })
</script>

<template>
  <!-- 宿主容器必须有明确高度；库样式无需导入 -->
  <div style="height: 80vh">
    <PrintDesigner :studio="studio" />
  </div>
</template>

Props ​

Prop类型与作用
studioDesigner；推荐传入的业务实例
contextEditorContext；已有上下文的进阶接入；studio 优先
classPrefixstring；当前视图的自有 BEM 类名前缀（TDesign 组件保留 t- 前缀），默认沿用实例配置（缺省为 ps），例如 class-prefix="ps2"
initialDocumentPrintDocument；自行创建上下文时的初始文档
onSave(document: PrintDocument) => Promise<void>；自行创建时配置保存
persistPreferences / preferenceStorage自行创建时配置偏好存储，默认关闭；启用后默认使用 localStorage
storageDocumentStorage | false；自行创建时的草稿策略，默认 false
rendering输出执行配置；自行创建上下文时使用
elements / parsers / resources自定义元素、解析器及共享资源包；自行创建上下文时使用
startup控制加载页，接收阶段变化并提供重试动作
pluginsPluginInput[]；初始化时安装
presetsDesignerPresets（dataSources / pageTemplates 预设）
settings部分 DesignerSettings；如 previewWithData、showMargins
uimenuBar/toolBar/optionsBar/panels/infoBar 布尔值，默认全 true
zIndex设计器浮层层级

Props 更新规则：

  • studio / context 创建时选择，不支持热切换；切换用 key 重建组件。
  • classPrefix 在挂载时确定；修改前缀时用 key 重建组件。
  • 传入已有实例后，persistPreferences/preferenceStorage/onSave/storage/rendering/elements/parsers/resources 应在实例创建处配置，组件上的同名配置被忽略。
  • initialDocument 有独立 watcher：即使传入 studio，后续更新该 prop 也会加载文档。为避免两处驱动文档，推荐统一使用 studio.document.load/loadJson。

自行创建上下文时，初始文档优先使用 initialDocument，其次恢复 storage 中的草稿；两者均不可用时，提供 presets 则创建预设文档，否则打开内置欢迎模板。

attachDesigner 低阶入口 ​

ts
function attachDesigner(
  container: HTMLElement,
  options?: MountDesignerOptions,
): MountedDesigner

@printstack/print-studio/designer 的命令式挂载，同步返回句柄：

ts
import { attachDesigner } from '@printstack/print-studio/designer'

const mounted = attachDesigner(container, { studio })
await mounted.ready // 界面与插件就绪

// mounted.studio —— 实例（未传 studio 时自建）
// mounted.unmount() —— 卸载视图；自建实例时连带 dispose

组件和 attachDesigner() 通过 startup.onStageChange 报告 modules、designer、workspace、ready；初始化期间卸载会停止后续阶段通知，并取消加载页待执行的计时和淡出动画。设 showLoading: false 可隐藏内置加载页。视图保留在失败状态时，可通过 onRetry 提供重试动作。

同一容器重复挂载抛错。推荐优先使用 studio.mount({ el })（实例统一入口）。

installDesigner() / createEditorContext() ​

进阶 API：createEditorContext() 显式创建编辑上下文（跨组件 / 路由复用），installDesigner() 在应用层注册设计器能力。多数业务只需 useDesigner + <PrintDesigner> 或 createDesigner + studio.mount。

独立宿主可从 @printstack/print-studio 导入 createEditorContext()，在领域插件之外加载完整的设计器内置插件。需要自行控制装配时，根入口的 createEditorRuntime() 与 @printstack/print-studio/vue 的 createEditorContext() 默认只安装领域插件。根入口的 installBuiltinCommands(ctx) 可单独安装设计器内置命令并返回卸载函数。getDesignerContext(studio) 读取仍有效的 Designer 实例所关联的上下文。

设计器挂载在顶层页面或由设计器入口创建的 iframe 内时，文档处于 dirty 状态会请求浏览器在刷新或关闭宿主页面时确认。是否提示及文案由浏览器决定；卸载设计器后不再拦截。
