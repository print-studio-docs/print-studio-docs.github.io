Vue 集成 ​

@printstack/print-studio/vue 提供 Vue 3 组件与组合式函数。非 Vue 宿主直接用 studio.mount({ el })，见 createPrintStudio。

ts
import { PrintDesigner, usePrintStudio, installDesigner, createEditorContext } from '@printstack/print-studio/vue'

usePrintStudio() ​

ts
function usePrintStudio(options?: UsePrintStudioOptions): DesignStudio

interface UsePrintStudioOptions extends PrintStudioOptions {
  context?: EditorContext
}
ts
const studio = usePrintStudio({ storage: false })
选项功能类型必填说明
context显式复用已有上下文EditorContext否不传时先找祖先注入，再新建实例
其余选项同 createPrintStudioPrintStudioOptions否仅在本次新建实例时应用；复用上下文时只应用 defaultElementType

上下文选择顺序：显式 context → 祖先注入 → 新建实例。本次调用创建的实例在当前 Vue 作用域销毁时自动 dispose；复用的外部实例由创建方清理。

TIP

Vue 注入只能从祖先流向后代：父页面无法获取子设计器的注入，兄弟组件也不会自动共享。需要共享时把 studio 显式传给 <PrintDesigner :studio="studio" />。

PrintDesigner 组件 ​

vue
<script setup lang="ts">
import { PrintDesigner, usePrintStudio } from '@printstack/print-studio/vue'

const studio = usePrintStudio({ storage: false })
</script>

<template>
  <!-- 宿主容器必须有明确高度；库样式无需导入 -->
  <div style="height: 80vh">
    <PrintDesigner :studio="studio" />
  </div>
</template>

Props ​

Prop类型与作用
studioDesignStudio；推荐传入的业务实例
contextEditorContext；已有上下文的进阶接入；studio 优先
initialDocumentPrintDocument；自行创建上下文时的初始文档
onSave(document: PrintDocument) => Promise<void>；自行创建时配置保存
storageDocumentStorage | false；自行创建时的草稿策略，默认 false
rendering输出执行配置；自行创建上下文时使用
elements / parsers自定义元素 / 解析器；自行创建上下文时使用
pluginsDesignerPlugin[]；初始化时安装
presetsDesignerPresets（dataSources / pageTemplates 预设）
settings部分 DesignerSettings；如 previewWithData、showMargins
uimenuBar/toolBar/optionsBar/panels/infoBar 布尔值，默认全 true
zIndex设计器浮层层级

Props 更新规则：

  • studio / context 创建时选择，不支持热切换；切换用 key 重建组件。
  • 传入已有实例后，onSave/storage/rendering/elements/parsers 应在实例创建处配置，组件上的同名配置被忽略。
  • initialDocument 有独立 watcher：即使传入 studio，后续更新该 prop 也会加载文档。为避免两处驱动文档，推荐统一使用 studio.document.load/loadJson。

事件 ​

事件参数与时机
readyEditorContext；界面与内置能力初始化完成后
dirty-changeboolean；dirty 状态变化（不立即回放当前值）
errorunknown；命令、启动与组件树路径捕获的错误
dispose视图清理时（组件卸载或关联实例销毁）

ref 暴露 ​

成员说明
context组件使用的 EditorContext
getDocument()读取当前文档快照
loadDocument(document)加载文档
save()触发保存
isDirty()查询未保存状态

mountPrintDesigner 低阶入口 ​

ts
function mountPrintDesigner(
  container: HTMLElement,
  options: MountPrintDesignerOptions,
): MountedPrintDesigner

@printstack/print-studio/designer 的命令式挂载，同步返回句柄：

ts
import { mountPrintDesigner } from '@printstack/print-studio/designer'

const mounted = mountPrintDesigner(container, { studio })
await mounted.ready // 界面与插件就绪

// mounted.studio —— 实例（未传 studio 时自建）
// mounted.unmount() —— 卸载视图；自建实例时连带 dispose

同一容器重复挂载抛错。推荐优先使用 studio.mount({ el })（实例统一入口）。

installDesigner() / createEditorContext() ​

进阶 API：createEditorContext() 显式创建编辑上下文（跨组件 / 路由复用），installDesigner() 在应用层注册设计器能力。多数业务只需 usePrintStudio + <PrintDesigner> 或 createPrintStudio + studio.mount。
