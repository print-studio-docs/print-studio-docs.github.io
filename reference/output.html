预览 / 打印 / 导出 ​

DesignStudio 的输出入口共用同一条渲染流程：解析绑定 → 展开循环 → 应用页面模板 → 生成 HTML / PDF。所有输出都以「输入数据快照」渲染，不修改模板。输出形态仅 HTML / PDF / JSON 三类，无图片导出。

输出 API 一览 ​

调用返回用途
studio.preview(input?, options?)Promise<PreviewHandle>浏览器内预览（iframe 输出或独立 Designer 打印预览）
studio.print(input?, options?)Promise<{ warnings: string[] }>打开浏览器打印对话框
studio.toHTML(input?, options?, execution?)Promise<HtmlResult>生成独立 HTML 字符串
studio.toPDF(input?, options?, execution?)Promise<PdfResult>生成 PDF Blob
studio.export.json()string模板 JSON
studio.export.html(input?)Promise<HtmlResult>生成 HTML（与 toHTML 同一实现）
studio.export.pdf(input?)Promise<PdfResult>生成 PDF（与 toPDF 同一实现）

input 为 Record<string, unknown>，省略时取数据源示例数据。export.html / export.pdf 与 toHTML / toPDF 都只生成并返回结果，不触发下载；下载由宿主处理，见下文示例。

preview() ​

ts
// 全屏遮罩预览（带关闭按钮）
const handle = await studio.preview(input)
handle.close() // 关闭并中止加载

// 使用 Designer 的打印预览对话框
await studio.preview(input, { mode: 'designer' })

// 无需 studio.mount()，在指定容器内展示完整打印预览
await studio.preview(input, {
  mode: 'designer',
  container: document.getElementById('pv')!,
})

// 嵌入指定容器
const embedded = await studio.preview(input, {
  container: document.getElementById('pv')!,
})
console.log(embedded.element, embedded.warnings)
PreviewOptions功能类型必填默认值说明
container预览宿主容器HTMLElement否—需明确高度；缺省挂载到 body 并全屏展示
mode预览方式iframe | designer否iframedesigner 独立挂载完整打印预览，无需挂载设计器
signal取消渲染与帧就绪等待AbortSignal否—
timeoutMs等待上限number否60000覆盖字体准备、渲染与 iframe 资源就绪

PreviewHandle：element: HTMLIFrameElement（sandbox 限制脚本）、warnings: string[]、close()。

mode: 'designer' 独立挂载 Designer 的打印预览，复用页面导航、缩放、打印数据编辑与打印功能。省略 input 时使用示例数据：

  • 无需调用 studio.mount()；指定 container 时在容器内展示，缺省挂载到 body。界面样式由独立 iframe 隔离。
  • 每次调用使用调用时的文档与输入数据快照，不占用已挂载设计器的弹窗状态。
  • 元素与解析器沿用当前工作区的注册表；预览中的打印操作通过当前工作区的 preview.print 命令执行，支持命令替换及 command:* 事件订阅。
  • signal 与 timeoutMs 控制首轮渲染和资源就绪等待；Promise 在首轮预览就绪后 resolve，element 指向显示打印内容的 iframe，warnings 包含渲染和资源告警。
  • 关闭窗口、调用 close() 或 studio.dispose() 会释放预览界面与预览渲染会话。close() 可以重复调用。

PreviewOptions.mode 仅用于 studio.preview()；renderer.preview() 和 print() 的选项仍为 BrowserOutputOptions。

print() ​

ts
const { warnings } = await studio.print(input, { timeoutMs: 30000 })

每次调用独立创建隐藏 iframe 并调起浏览器打印对话框，返回时对话框已调起；不做排队或合并。清理由 iframe 内 afterprint 事件触发，60 秒兜底。返回成功只代表打印任务已提交，不代表用户确认或设备出纸；打印对话框与出纸由浏览器和用户控制。

toHTML() / toPDF() ​

ts
const { html, warnings, execution } = await studio.toHTML(input, {
  title: '销售订单',
})
const { blob } = await studio.toPDF(input, undefined, { timeoutMs: 30000 })
  • HtmlParseOptions：title?（输出 <title>，默认文档名）、fontCss?（补充字体 CSS）、signal?。
  • PdfParseOptions：rasterPxPerMm?（旋转元素光栅化密度，默认 300/25.4）、fontCss?、signal?。
  • execution（RenderExecutionOptions）：signal? + timeoutMs?（默认 60000，必须为有限正数）；同步计算阶段无法被立即中断。

结果类型：

ts
interface HtmlResult {
  html: string
  warnings: string[]
  execution: RenderExecution
}
interface PdfResult {
  blob: Blob
  warnings: string[]
  execution: RenderExecution
}

interface RenderExecution {
  backend: 'hybrid' | 'main' | 'worker'
  durationMs: number
  reason?: 'disabled' | 'unavailable' | 'custom-parser' | 'element-capability'
}

execution 用于诊断耗时与执行路径；业务逻辑以输出内容和 warnings 为准。

宿主下载 PDF ​

ts
const { blob } = await studio.toPDF(input)
const url = URL.createObjectURL(blob)
const a = window.document.createElement('a')
a.href = url
a.download = '订单.pdf'
a.click()
URL.revokeObjectURL(url)

嵌入 HTML 输出 ​

toHTML 返回完整 HTML 文档（含 html / body 样式与 @media screen 背景），须写入 iframe 的 srcdoc，不能直接塞入宿主页面的 innerHTML：

ts
const { html } = await studio.toHTML(input)
const iframe = window.document.createElement('iframe')
iframe.srcdoc = html
container.appendChild(iframe)

输出形态辨析 ​

「预览 / 打印 / 导出」三类动作的区别：

形态调用分类说明
模板编辑视图studio.mount({ el })编辑设计器画布，编辑态（示例数据或空白）
数据预览settings.previewWithData预览画布按数据源 sampleData 解析绑定
打印预览studio.preview(input) / studio.preview(input, { mode: 'designer' })预览iframe 模式查看注入数据后的输出效果；Designer 模式提供分页导航、缩放、数据编辑与打印操作
浏览器打印studio.print(input)打印调起浏览器打印对话框，不是预览
自定义展示studio.toHTML(input)导出生成 HTML，自行嵌入页面或弹窗展示
PDF 导出studio.toPDF(input)导出生成 PDF Blob，由宿主下载或上传

字体与资源 ​

自定义字体经 rendering.fonts 配置（PrintFont { family, url, style?, weight? }），运行时在布局测量前加载本次使用的字体。跨域字体需允许嵌入（CORS）。字体、图片等资源失败产生告警，不中断输出。

批量输出 ​

ts
for (const customer of customers) {
  const { blob } = await studio.toPDF({ customer })
  // 逐份下载或收集后统一处理
}

批量渲染共用同一实例即可；PDF 导出过程中设计器内会显示可暂停 / 取消 / 恢复的进度对话框。
