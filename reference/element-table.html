table 表格元素 ​

类型标识 table，默认尺寸 120×40 mm。支持数据行绑定、跨页续排、固定行数补空行、每页 / 全量合计与表尾溢出延续。

基本用法 ​

ts
page.elements.add({
  type: 'table',
  x: 10,
  y: 42,
  width: 190,
  props: {
    columns: [
      { title: '商品', width: 3, align: 'left' },
      { title: '数量', width: 1, align: 'right' },
      { title: '金额', width: 2, align: 'right',
        format: { type: 'currency', digits: 2 } },
    ],
    rows: [
      ['热敏打印机 80mm', '2', '660.00'],
      ['标签纸 φ30', '10', '120.00'],
    ],
    stripe: true,
    pagination: { crossPage: true, repeatHeader: true },
    summary: {
      enabled: true,
      position: 'bottom',
      scope: 'lastPage',
      columns: { '0': { type: 'text', text: '合计' }, '2': { type: 'sum' } },
    },
  },
})

属性 ​

单元格样式按三级优先级合并：单元格覆盖（cellOverrides / 汇总行样式）> 列样式 > 表格默认样式。

属性功能类型必填默认值说明
columns列定义TableColumn[]是预置 3 列（名称 / 数量 / 备注）见下文 TableColumn
rows静态行数据string[][]否[['示例数据 1', '2', ''], ['示例数据 2', '1', '']]求值后的单元格文本二维数组；动态数据用 bindings.rows 绑定数组
heightMode行高模式string否'auto''auto' 按内容自然行高（支持跨页）/ 'fixed' 压缩行高填满定界框
fontFamily字体string否'Microsoft YaHei'
fontSize字号number否9pt
padding单元格内边距number否1.5mm
minRowHeightMm最小行高number否0mm；仅 auto 模式参与行高计算
background表格背景色string否'#ffffff'
color单元格文字颜色string否'#222222'
headerVisible显示表头boolean否true
headerBackground表头背景string否'#f0f0f0'
headerColor表头文字色string否'#111111'
headerAlign表头整体水平对齐string否'''' 跟随各列 align；可设 'left' / 'center' / 'right'
stripe斑马纹boolean否false
stripeColor斑马纹颜色string否'#f7f7f7'

TableColumn ​

ts
interface TableColumn {
  title: string // 表头文字
  bind?: string // 绑定字段，相对于 bindings.rows 的每行对象；行绑定未启用时忽略
  width: number // 权重 / 百分比 / 毫米，含义由 widthMode 决定；非正数归一化为 1
  widthMode?: 'weight' | 'percent' | 'fixed' // 默认 'weight'
  align?: 'left' | 'center' | 'right' // 默认 'left'
  vAlign?: 'top' | 'middle' | 'bottom'
  bold?: boolean
  color?: string
  background?: string // 列级背景：覆盖表格默认，被单元格覆盖
  fontSize?: number
  wrap?: boolean // 自动换行；false 时单行显示、超出裁剪
  format?: TableCellFormat
  mergeSame?: boolean // 纵向动态合并：相邻行取值相同时按列合并单元格
  nullText?: string // 该列取值为空时的替代文本；缺省回退表级 nullText
  minWidthMm?: number
  maxWidthMm?: number
}

interface TableCellFormat {
  type: 'currency' | 'date' | 'lower' | 'none' | 'number' | 'thousand' | 'upper'
  digits?: number // number / thousand / currency 的小数位
  pattern?: string // date 格式化模式，如 yyyy-MM-dd、HH:mm
}

format 各类型的取值语义与绑定表达式格式化器一致，见 数据绑定。

TableBorders ​

ts
interface TableBorders {
  mode: 'all' | 'horizontal' | 'none' | 'outer' | 'vertical' // 内部分隔线画法；外框始终由 outer 与单边覆盖决定
  outer: TableBorderStyle // 必填，外框默认线
  inner: TableBorderStyle // 必填，内部分隔线
  top?: TableBorderStyle // 覆盖外框对应单边（right / bottom / left 同）
  headerBottom?: TableBorderStyle // 表头底部独立加粗线（单据场景）
}

interface TableBorderStyle {
  color: string
  style: 'solid' | 'dashed' | 'dotted'
  width: number // mm，非正数回退缺省值
}

enabled启用合计行boolean否false
position合计行位置'top' | 'bottom'否'bottom'

数据绑定 ​

ts
page.elements.add({
  type: 'table',
  x: 10,
  y: 42,
  width: 190,
  bindings: { rows: 'items' }, // 结构化绑定：数组路径
  props: {
    columns: [
      { title: '商品', bind: 'name', width: 3, align: 'left' },
      { title: '数量', bind: 'quantity', width: 1, align: 'right' },
      { title: '金额', bind: 'amount', width: 2, align: 'right',
        format: { type: 'currency', digits: 2 } },
    ],
    rows: [],
    heightMode: 'auto',
    pagination: { crossPage: true, repeatHeader: true, rowsPerPage: 20,
      fixedRows: true, fillEmptyRows: false, positionMode: 'flow' },
    summary: { enabled: true, position: 'bottom', scope: 'lastPage',
      columns: { '0': { type: 'text', text: '合计' }, '2': { type: 'sum' } } },
  },
})

表尾溢出延续（overflow） ​

长表格超出页高时，可把溢出部分延续到「溢出延续模板」：配置 overflow.templateId 指向一个 owner: { purpose: 'overflow' } 的页面模板。内置发票模板即此用法（主票面 240×140 + 延续清单 210×297）。详细配置见 页面模板与布局扩展。

注意事项 ​

  • 表格拥有 measureSize / paginate / overflow / resolveBindings 能力，是唯一支持跨页切块的元素。
  • 输出态 heightMode: 'auto' 按内容自然高度重算高度，fixed 压缩行高填满定界框；画布缩放下限受内容自然高度约束，不要把表格压扁到小于自然高度。
  • 动态修改列时整体提交新 columns 数组（数组属性整体替换）。
