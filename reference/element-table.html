table 表格元素 ​

类型标识 table，默认尺寸 120×40 mm。支持数据行绑定、跨页续排、固定行数补空行、每页 / 全量合计与表尾溢出延续。

自动高度跨页开启固定行数和空白补行时，画布以半透明空白行展示当前定界框及页面内容区剩余空间内的容量，第一行表体和汇总行保持正常显示。单选未旋转的表格并自由缩放底边时，可吸附到完整行高度；参考线、网格等现有吸附优先。容量为静态空白行的估算，实际数据换行、合并或续页设置可能改变分页结果。

在元素设置的「结构与列」中拖拽表头分隔线可调整相邻列宽，达到下限时显示提示。预览为每列保留操作空间，其余空间按实际列宽分配；极窄列不会放大整张预览表。需要更窄的列时，可在「列设置」中手动设置列宽。

「基本设置 > 数据源」中的「数据来源」可选择静态数据或动态数据。选择动态数据会立即打开选择器：可直接选择数组数据源，也可选择对象中的数组字段。确认后清除静态行及其合并、单元格样式；取消选择保留原状态。动态模式显示数据源名称与绑定路径，可通过「更换」重新选择；切回静态数据会解除行绑定。切换操作可撤销。

「表格样式」设置表格背景、边框、共用字体、字号和内边距。「表体样式」设置表体文字、对齐、换行和隔行背景；「表头样式」设置表头外观。表头字体、字号、内边距可跟随表格或独立设置；表头边框也可跟随表格或独立设置。表头水平对齐和加粗可跟随列，垂直对齐、自动换行和表头高度默认分别为居中、开启和自动。

在「结构与列 > 列设置」中，列可跟随对应的表头或表体样式，也可独立设置。切换为独立设置时以当前生效样式作为初始值；切回跟随后恢复使用对应区域的样式。列的独立设置优先于表头或表体样式；已有单元格覆盖的优先级更高。

「结构与列 > 列与表头」始终显示当前列设置；点击列或数据单元格可切换当前列，点击表头可选择并编辑表头。

「结构与列 > 动态合并规则」可为多列指定共同的分组字段；未指定字段时，各列按自身的非空值分别合并。「列设置 > 相同值合并」只按该列的值合并。两者均只合并相邻数据行，合并后的单元格仅显示首行的值。在「结构与列 > 列设置」中启用「序号列」，该列会为静态或动态数据生成从 1 开始的明细行号，跨页连续编号。启用期间隐藏该列的绑定字段；关闭后恢复原绑定。

「列设置」中可配置单元格格式、空值处理和列宽限制。单元格格式按数据源字段类型筛选；静态列按非空值推断，混合类型或空列按文本处理。已有格式与当前类型不匹配时会提示重新选择，不会自动改写模板。

基本用法 ​

ts
page.elements.add({
  type: 'table',
  x: 10,
  y: 42,
  width: 190,
  props: {
    columns: [
      { title: '商品', width: 3, align: 'left' },
      {
        title: '数量',
        width: 1,
        align: 'right',
        bodyStyle: { align: 'right' },
      },
      {
        title: '金额',
        width: 2,
        align: 'right',
        bodyStyle: { align: 'right' },
        format: { type: 'currency', digits: 2 },
      },
    ],
    rows: [
      ['热敏打印机 80mm', '2', '660.00'],
      ['标签纸 φ30', '10', '120.00'],
    ],
    stripe: true,
    pagination: { crossPage: true, repeatHeader: true },
    summary: {
      enabled: true,
      position: 'bottom',
      scope: 'lastPage',
      columns: { '0': { type: 'text', text: '合计' }, '2': { type: 'sum' } },
    },
  },
})

属性 ​

已有模板中的单元格覆盖（cellOverrides / 汇总列样式）仍按单元格覆盖 > 列样式 > 表格默认样式的优先级渲染；设置界面不提供单个单元格样式编辑。

columns[].headerStyle 和 columns[].bodyStyle 分别覆盖表头和表体。旧模板若将表体样式直接写在列上，需将这些样式移入 bodyStyle；列上的 align 和 bold 仍可作为表头回退值。共用边框优先使用列覆盖。若两侧均有覆盖，使用较宽的可见线，等宽时使用先出现的边。

TableColumn ​

ts
interface TableColumn {
  title: string // 表头文字
  bind?: string // 绑定字段，相对于 bindings.rows 的每行对象；未绑定行或启用序号列时忽略
  rowNumber?: boolean // 从 1 开始自动生成行号；旧模板的 bind: '$rowNumber' 会转换为此配置
  width: number // 权重 / 百分比 / 毫米，含义由 widthMode 决定；非正数归一化为 1
  widthMode?: 'weight' | 'percent' | 'fixed' // 默认 'weight'
  align?: 'left' | 'center' | 'right' // 表头未统一对齐时的回退值
  bold?: boolean // 表头未统一设置加粗时的回退值
  bodyStyle?: TableColumnStyle // 未配置时继承表体统一设置
  headerStyle?: TableColumnStyle // 本列表头样式；省略时继承表头样式
  format?: TableCellFormat
  mergeSame?: boolean // 纵向动态合并：相邻行取值相同时按列合并单元格
  nullText?: string // 该列取值为空时的替代文本；缺省回退表级 nullText
  minWidthMm?: number
  maxWidthMm?: number
}

interface TableColumnStyle extends TableCellOverride {
  borders?: TableBorders // 列区域的边框，内分隔线用于行与行之间
}

interface TableCellFormat {
  type: 'currency' | 'date' | 'lower' | 'none' | 'number' | 'thousand' | 'upper'
  digits?: number // number / thousand / currency 的小数位
  pattern?: string // date 格式化模式，如 yyyy-MM-dd、HH:mm
}

format 各类型的取值语义与绑定表达式格式化器一致，见 数据绑定。

TableBorders ​

ts
interface TableBorders {
  mode: 'all' | 'horizontal' | 'none' | 'outer' | 'vertical' // 内部分隔线画法；外框始终由 outer 与单边覆盖决定
  outer: TableBorderStyle // 必填，外框默认线
  inner: TableBorderStyle // 必填，内部分隔线
  top?: TableBorderStyle // 覆盖外框对应单边（right / bottom / left 同）
  headerBottom?: TableBorderStyle // 表头底部独立加粗线（单据场景）
}

interface TableBorderStyle {
  color: string
  style: 'solid' | 'dashed' | 'dotted'
  width: number // mm，非正数回退缺省值
}

数据绑定 ​

动态行由 bindings.rows 指定的数组生成，不使用静态 rows 作为回退。绑定路径未解析为数组时，表格显示空数据并记录绑定告警。

ts
page.elements.add({
  type: 'table',
  x: 10,
  y: 42,
  width: 190,
  bindings: { rows: 'items' }, // 结构化绑定：数组路径
  props: {
    columns: [
      {
        title: '序号',
        rowNumber: true,
        width: 0.8,
        align: 'center',
        bodyStyle: { align: 'center' },
      },
      { title: '商品', bind: 'name', width: 3, align: 'left' },
      {
        title: '数量',
        bind: 'quantity',
        width: 1,
        align: 'right',
        bodyStyle: { align: 'right' },
      },
      {
        title: '金额',
        bind: 'amount',
        width: 2,
        align: 'right',
        bodyStyle: { align: 'right' },
        format: { type: 'currency', digits: 2 },
      },
    ],
    rows: [],
    heightMode: 'auto',
    pagination: {
      crossPage: true,
      repeatHeader: true,
      rowsPerPage: 20,
      fixedRows: true,
      fillEmptyRows: false,
      positionMode: 'flow',
    },
    summary: {
      enabled: true,
      position: 'bottom',
      scope: 'lastPage',
      columns: { '0': { type: 'text', text: '合计' }, '2': { type: 'sum' } },
    },
  },
})

表尾溢出延续（overflow） ​

长表格超出页高时，可把溢出部分延续到「溢出延续模板」：配置 overflow.templateId 指向一个 owner: { purpose: 'overflow' } 的页面模板。内置发票模板即此用法（主票面 240×140 + 延续清单 210×297）。详细配置见 页面模板与布局扩展。

延续表的列宽值与模式独立于主表；省略 widthMode 时按 weight 分配延续表宽度，不继承主表的列宽模式。延续表缺少对应列时，该列的宽度值和模式一起沿用主表。

输出时，无法在目标页内安全容纳的单元格会保留格位并留空，同时记录告警；其他元素和单元格继续渲染。分页恢复失败时仅跳过该元素，不影响同页其他元素。

注意事项 ​

  • 表格拥有 measureSize / paginate / overflow / resolveBindings 能力，是唯一支持跨页切块的元素。
  • 输出态 heightMode: 'auto' 按内容自然高度重算高度，fixed 压缩行高填满定界框；画布缩放下限受内容自然高度约束，不要把表格压扁到小于自然高度。
  • 动态修改列时整体提交新 columns 数组（数组属性整体替换）。
