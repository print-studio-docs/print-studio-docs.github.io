text 文本元素 ​

类型标识 text，快捷键 t，默认尺寸 80×12 mm。用于标题、字段占位与多行段落，文本内容支持内嵌绑定表达式。

基本用法 ​

ts
page.elements.add({
  type: 'text',
  x: 20,
  y: 30,
  width: 170,
  height: 14,
  props: {
    text: '客户：{{ order.customer }}\n金额：{{ order.amount | currency:¥:2 }}',
    fontSize: 12,
    fontWeight: '700',
    lineHeight: 1.4,
    autoHeight: true,
  },
})

属性 ​

属性
属性类型必填默认值说明
textstring可选'文本内容'文本内容；支持换行与内嵌绑定表达式
fontFamilystring可选'Microsoft YaHei'字体；自定义字体需在 rendering.fonts 配置
fontSizenumber可选12字号；pt
fontWeightstring可选'400'字重；'300' / '400' / '500' / '600' / '700' / '900'
fontStylestring可选'normal'字形；'normal' / 'italic'
textAlignstring可选'left'水平对齐；'left' / 'center' / 'right' / 'justify'
verticalAlignstring可选'top'垂直对齐；'top' / 'middle' / 'bottom'
colorstring可选'#111111'文字颜色
backgroundstring可选'transparent'背景色
letterSpacingnumber可选0字间距；pt
lineHeightnumber可选1.4行高倍数
paddingnumber可选0内边距；mm
textDecorationstring可选'none'文本装饰；'none' / 'underline' / 'line-through'
autoHeightboolean可选false内容自适应高度；开启后高度随内容自动重算

数据绑定 ​

绑定表达式写在 text 内，渲染时按打印数据求值；取值失败输出空串并产生告警，不中断输出。格式化器与文档变量见 数据绑定。

数字与布尔值在数据预览、HTML 和 PDF 中按文本显示，例如 0、false；HTML 标记作为普通文本显示。

注意事项 ​

  • 旧模板需将 props.content.value 迁移到 props.text；当前不再读取 props.content，也不再支持富文本与文本自动分页。
  • 画布内双击可直接内联编辑文本，编辑框上方的按钮可插入变量，按钮尺寸随画布缩放。编辑区域铺满定界框，进入编辑态时光标定位于内容末尾；内容溢出时自动滚动到末尾。失焦、选中其他元素或按 Ctrl+Enter 保存，按 Escape 放弃本次编辑。
  • autoHeight: true 时高度以内容为准，拖拽设置的高度会被内容重算覆盖。
  • verticalAlign 对齐包含行高留白的文本行框；PDF 按字体度量与 lineHeight 定位基线，padding 另计。
