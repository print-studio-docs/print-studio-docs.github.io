事件 API ​

通过 studio.events.on 订阅文档、页面、元素、历史等事件，用于刷新业务 UI、同步保存按钮状态或诊断调用。只需要核心状态刷新时优先用 state.getSnapshot() / state.subscribe()。

订阅 API ​

调用回调参数返回值
studio.events.on(name, handler)对应事件的 payload，类型由名称推导() => void 解绑函数
studio.events.on('*', handler)(type, payload)，收到所有事件() => void 解绑函数
  • 只有 '*' 表示通配，不支持 'element:*' 前缀匹配。
  • 事件 API 只公开 on；单次监听可在回调中调用解绑函数。
  • 订阅不回放当前值或历史事件；先读状态再监听后续变化。
  • 回调保持轻量；总线不等待异步回调、不隔离回调异常。
ts
const offDocument = studio.events.on('document:changed', () => {
  console.log('有修改：', studio.document.dirty)
})
const offSelection = studio.events.on('selection:changed', ({ ids, nodes }) => {
  console.log('选区：', ids)
})

function stopListening() {
  offDocument()
  offSelection()
}

常用事件速查 ​

关注内容事件
文档document:changed/loaded/new/renamed
页面page:activated/added/copied/removed/updated
元素element:added/removed/updated/renamed/flags-changed/reordered、elements:changed
排版element:aligned/distributed/spacingDistributed/nudged/duplicated
元素组element-group:created/updated/removed
选区与历史selection:changed、history:changed/pushed
剪贴板clipboard:copied/cut/pasted

表中 / 表示同域多个事件名。跟随块等配置变化可统一监听 document:changed。

触发时机要点 ​

  • 动作事件：底层 action 成功返回后先派发语义事件，再派发泛化 action:<子域>.<动作>；一次 API 调用可能对应多个事件。
  • 状态事件（document:changed、selection:changed 等）由 Vue watch 派生、默认批处理，可能在同步 API 返回后触发；需要等待时用 await nextTick()。
  • state:changed 例外：同步 watch，在活动页 / 历史可用性 / dirty / 选区变化时发出；用 state.getSnapshot() 读快照，无需等 nextTick()。
  • 撤销 / 加载不会逐个重放元素事件；维护完整文档镜像时监听 document:changed 并读取 document.data。
  • payload 可能含内部响应式引用，只读使用；长期保存请经实例查询快照。

完整事件目录 ​

{} 表示无业务字段，? 表示可选字段。

文档与状态 ​

事件payload说明
document:changed{}文档数据变化（含中间态）；读 document.data 取快照
document:loaded{ skippedTypes?: string[] }loadJson 成功后（load 不派发）；skippedTypes 当前未填充，跳过类型以 deserializeDocument 返回值为准
document:new{}新建文档后
document:renamed{ name: string }重命名后；name 为入参
state:changed{}活动页 / 历史 / dirty / 选区变化时同步通知

页面 ​

事件payload说明
page:added{ pageId: string }添加页面后（携带活动页 ID）
page:copied{ newPageId; sourcePageId }复制页面后
page:removed{ pageId: string }删除确认后

元素与排版 ​

事件payload说明
element:added{ node: ElementNode; pageId: string }添加元素后
element:removed{ ids: string[]; nodes: ElementNode[] }批量删除后（nodes 删除前捕获）
element:updated{ node: ElementNode | null; patch; transient: boolean }更新后；批量逐项通知
element:renamed{ id; name }重命名后
element:flags-changed{ id; locked; visible }锁定 / 显隐切换后
element:reordered{ nodeId?; pageId? }叠放顺序调整后
element:aligned{ mode: AlignMode }对齐后
element:distributed{ mode: AlignMode }分布后；AlignMode 为 'bottom' | 'hcenter' | 'left' | 'right' | 'top' | 'vcenter'
element:spacingDistributed{ direction: 'h' | 'v' }按间距分布后；h 水平间距、v 垂直间距
element:nudged{ deltaX; deltaY }微移后（mm）
element:duplicated{ sourceIds; sourceNodes }副本创建后
elements:changed{}元素注册表变化（非页面内容变化）

事件payload说明
element-group:created{ group: ElementGroup }创建元素组后
element-group:updated{ id; patch }更新元素组后；patch 不含 id / pageId
element-group:removed{ deleteElements: boolean; id: string }删除元素组后；deleteElements 表示是否连带删除成员元素

命令与泛化 action ​

事件payload说明
command:before / command:after{ id; args }命令前后；成功顺序 before → 内部通知 → after
command:error{ id; error }命令失败（原错误继续上抛）
command:unknown{ id }未注册命令（随后派发 command:error）
commands:changed{}命令注册表变化
action:<子域>.<动作>{ name; args; result }底层 action 成功后；如 action:guide.add
action:failed{ name; args; error; result: undefined }action 失败；不再派发成功事件

已订阅 action 的子域共 24 个：canvas / clipboard / config / dataSource / document / element / elementGroup / followBlock / guide / history / layout / navigation / page / panel / plugin / rendering / repeatGroup / scope / selection / template / tutorial / ui / view / zIndex。名称对应底层 action，不能拼 facade 方法名（如 page.create() 底层是 action:page.add）。

与 PrintDesigner 组件事件的区别 ​

<PrintDesigner> 的 Vue 事件为 ready(context)、dirty-change(boolean)、error(error)、dispose（@ready/@dirty-change/@error/@dispose），不属于 DesignerEventMap。实例没有 document:saved / 打印完成事件——保存与输出的后续操作应等待对应 API 的 Promise。
