studio.document ​

studio.document 管理当前打印文档（即「模板」整体）：新建、重命名、加载、保存与快照读取。文档 JSON 模型见 TypeScript 类型定义。

成员
成员类型必填默认值说明
document.dataPrintDocument可选—当前文档快照；只读快照，修改快照不生效，更新走句柄或集合方法
document.dirtyboolean可选—是否不同于已保存基准
document.create()() => void可选—新建文档；重置为空白种子文档（配置 createDocument 工厂时经工厂创建，首页内容清空）；不弹确认框，界面确认由 `file.new` 命令处理
document.rename(name)(name: string) => void可选—更新文档名
document.load(doc)(doc: PrintDocument) => void可选—加载文档对象；经 deserializeDocument 宽容补全并重置历史
document.loadJson(json)(json: string) => void可选—加载 JSON 字符串；同上，JSON 语法错误抛 document.invalid，无 pages 时抛 document.no-pages 领域异常
document.save()() => Promise<void>可选—保存文档；序列化当前快照并调用 onSave(document)，未配置 onSave 时抛错，不会下载文件

创建模板文档 ​

  • @printstack/print-studio/core 的 createSeedDocument() 创建包含空白 A4 页面和内置示例数据源的新文档。
  • @printstack/print-studio 的 loadBuiltinDocument(key) 异步读取一份可独立修改的内置模板，支持 welcome、costSheet、invoice 和 purchaseOrder。

反序列化行为 ​

document.load / loadJson 内部经 @printstack/print-studio/core 的 deserializeDocument：

  • 宽容校验并逐字段补全默认值（页面默认 210×297 mm、白色背景）；
  • 元素经 createElement 补全 props 并校验配置；
  • 剔除未注册元素类型并记入返回值 skippedTypes；
  • 悬空 templateId 置空；缺失 templates 时补空白模板。
ts
import {
  createBuiltinElementRegistry,
  deserializeDocument,
} from '@printstack/print-studio/core'

const { document, skippedTypes } = deserializeDocument(
  rawJson,
  createBuiltinElementRegistry(),
)
if (skippedTypes.length > 0) {
  console.warn('跳过的未注册元素类型：', skippedTypes)
}
studio.document.load(document)

序列化与导出 ​

  • 模板 JSON：studio.export.json()（当前文档序列化字符串）。
  • 保存：studio.document.save() 经 onSave 回调交给宿主；下载 .json 文件是宿主 / 设计器 UI 层的动作，save() 自身不触发下载。
  • 输出 HTML / PDF 是渲染结果，不能当作可编辑 JSON 重新加载。

示例：保存与恢复 ​

ts
// 恢复：从服务端或本地读取 JSON
const json = localStorage.getItem('my-template')
if (json) {
  studio.document.loadJson(json)
}

// 保存
localStorage.setItem('my-template', studio.export.json())

配置 onSave 时，save() 收到的是 PrintDocument 对象，宿主自行序列化传输：

ts
const studio = createDesigner({
  storage: false,
  onSave: async (document) => {
    await fetch('/api/templates', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(document),
    })
  },
})

// 宿主下载 .json 文件（save() 不触发下载）
function downloadTemplate() {
  const json = studio.export.json()
  const url = URL.createObjectURL(
    new Blob([json], { type: 'application/json' }),
  )
  const a = window.document.createElement('a')
  a.href = url
  a.download = `${studio.document.data.name || 'template'}.json`
  a.click()
  URL.revokeObjectURL(url)
}
