TypeScript 类型定义 ​

核心类型从 @printstack/print-studio 导入（标注的从 @printstack/print-studio/core 导入）。单位约定：位置与尺寸 mm、字体 pt、旋转度，坐标原点为页面左上角。

PrintDocument ​

ts
interface PrintDocument {
  name: string
  version: string // DOCUMENT_VERSION = '1.0'
  pages: PageNode[]
  dataSources?: DataSource[]
  templates?: PageTemplate[] // 含内置空白模板
  repeatGroups?: RepeatGroup[]
  followBlocks?: FollowBlock[]
  elementGroups?: ElementGroup[] // 图层组，仅成员关系不参与渲染
  parserVersion?: string
}

可保存为 JSON 的完整模板模型。「打印模板」指这份整个文档；「页面模板」是其中 templates 内被多个页面复用的页眉、页脚、背景配置。

PageNode ​

ts
interface PageNode {
  id: string
  name: string
  width: number // mm
  height: number // mm
  background: string // 默认 '#ffffff'
  elements: ElementNode[] // 索引 0 在最底层
  guides: Guide[] // 编辑参考线，不参与打印
  margins?: PageMargins // { top, right, bottom, left }，mm
  templateId?: string // 缺省使用内置空白模板
}

页面尺寸预设 PAGE_PRESETS（@printstack/print-studio/core）：A4 纵横、A5、Letter、收银纸 80×200、收银纸 58×160。条目为 { height, label, width }（label 随语言变化的 getter），按尺寸匹配取用，不能按字符串索引。方向没有独立字段，width > height 即横版。

ElementNode ​

ts
interface ElementNode {
  id: string
  type: string // 对应 ElementDefinition.type，如 'text' / 'table'
  name: string // 图层面板显示名
  x: number // mm
  y: number // mm
  width: number // mm
  height: number // mm
  rotation: number // 度，绕中心顺时针；点驱动元素恒为 0
  opacity: number // 0–1
  visible: boolean
  locked: boolean
  props: Record<string, unknown> // 元素类型专属属性
  bindings?: Record<string, string> // 结构化绑定，如 { rows: 'items' }
  points?: Point[] // 点驱动元素（如线条）的页面坐标顶点
}

props 可用字段由元素类型决定，见内置元素。更新元素走句柄或 elements.update / updateProps，直接修改快照不生效。

DataSource ​

ts
interface DataSource {
  key: string // 绑定表达式首段 = input 顶层键
  label: string
  description?: string
  schema: DataSourceField[]
  sampleData?: unknown
}

interface DataSourceField {
  name: string
  type: 'array' | 'boolean' | 'date' | 'number' | 'object' | 'string'
  label?: string
  children?: DataSourceField[]
}

PageTemplate ​

ts
interface PageTemplate {
  id: string
  name: string
  page: PageNode // 模板内容容器；约定 page.id === 模板 id
  background?: string
  baseTemplateId?: string // 模板继承链
  builtin?: boolean // 内置空白模板不可删除
  facingPages?: boolean // 双面排版
  evenPage?: PageNode
  oddPages?: boolean // 默认 true
  evenPages?: boolean // 默认 true
  owner?: { elementId: string; purpose: string } // 元素所属模板，purpose 约定 'overflow'（表尾溢出延续）
  requiredElements?: Array<{ elementId: string; type: string }>
}

RepeatGroup / FollowBlock ​

ts
interface RepeatGroup {
  id: string
  name: string
  pageId: string
  elementIds: string[]
  collection: string // 绑定数组路径
  direction: 'grid' | 'page' | 'vertical' // grid 网格平铺；page 每条数据独占一页并保持设计位置；vertical 纵向平铺
  columns: number
  gapX: number // mm
  gapY: number // mm
  positionMode?: 'fixed' | 'flow'
}

interface FollowBlock {
  id: string
  name: string
  pageId: string
  elementIds: string[]
  target: LayoutTarget
  gap: number // mm
}

type LayoutTarget =
  | { id: string; kind: 'element' }
  | { id: string; kind: 'followBlock' }
  | { id: string; kind: 'repeatGroup' }

实例与输出类型 ​

ts
// DesignStudio（主名；另有别名 PrintStudio）——实例类型；成员见各参考页
interface DesignStudio { /* document/page/elements/edit/... */ }
interface PrintStudioOptions { /* 创建选项，见 createPrintStudio() */ }
interface StudioMountOptions extends DesignerOptions {
  el: HTMLElement | string
  onDirtyChange?: (dirty: boolean) => void
  onError?: (error: unknown) => void
}

// 实体引用：ID 字符串或带只读 id 的对象（页面 / 元素 / 页面模板等查询与更新共用）
type EntityReference = string | { readonly id: string }

// 页面模板内容句柄（TemplateHandle.page / TemplateHandle.evenPage）
interface TemplatePageHandle {
  readonly data: PageNode | undefined // 模板删除后为 undefined
  readonly elements: ElementsFacade
  readonly id: string
  update(patch: TemplatePagePatch): void
}

// 输出结果
interface HtmlResult { html: string; warnings: string[]; execution: RenderExecution }
interface PdfResult { blob: Blob; warnings: string[]; execution: RenderExecution }
interface PreviewHandle {
  element: HTMLIFrameElement
  warnings: string[]
  close(): void
}

// 渲染字体
interface PrintFont {
  family: string // 必填，与元素 fontFamily 匹配
  url: string // 必填
  style?: string // 默认 'normal'
  weight?: string // 默认 'normal'
}

DocumentStorage / PreferenceStorage ​

ts
interface DocumentStorage {
  get(): string | null
  set(document: string): void
}

interface PreferenceStorage {
  get(key: string): string | null
  set(key: string, value: string): void
}

自动草稿与界面偏好的存储契约：storage: false 关闭自动草稿，preferenceStorage 仅在 persistPreferences: true 时使用（缺省为 localStorage 实现）。

反序列化 ​

ts
import { deserializeDocument, DOCUMENT_VERSION, elementRegistry } from '@printstack/print-studio/core'

const { document, skippedTypes } = deserializeDocument(raw, elementRegistry)

宽容校验 + 字段补全 + 剔除未注册元素类型；无 pages 时抛 document.no-pages 领域异常（DesignerException，从 @printstack/print-studio/core 导入）。仅从 @printstack/print-studio/core 获取的 elementRegistry 不含内置元素，需主入口模块加载后才完整，见 元素操作 API。
