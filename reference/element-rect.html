rect 矩形元素 ​

类型标识 rect，快捷键 r，默认尺寸 60×40 mm。用于底色块、分区框与标签边框。

基本用法 ​

ts
page.elements.add({
  type: 'rect',
  x: 10,
  y: 40,
  width: 80,
  height: 30,
  props: { fill: '#f0f7ff', stroke: '#164b85', strokeWidth: 0.4, radius: 2 },
})

// 透明底 + 虚线框（分区线效果）
page.elements.add({
  type: 'rect',
  x: 100,
  y: 40,
  width: 80,
  height: 30,
  props: { fill: 'transparent', stroke: '#999999', dash: 'dashed' },
})

属性 ​

属性
属性类型必填默认值说明
fillstring可选'transparent'填充色
strokestring可选'#333333'描边色
strokeWidthnumber可选0.4描边宽度；mm
dashstring可选'solid'虚线样式；'solid' / 'dashed' / 'dotted'
radiusnumber可选0圆角半径；mm；圆形元素无此属性

注意事项 ​

  • 元素通用字段 rotation / opacity 对矩形生效：可做旋转色带、半透明蒙层。
  • 叠放顺序即数组顺序（索引 0 在最底层），可用 elements.move(ref, index) 调整。
