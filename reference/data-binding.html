数据源与数据绑定 ​

数据源声明模板的数据结构与示例数据；绑定把元素属性关联到打印数据字段。渲染时注入的 input 按 key 对应数据源，输出只使用本次数据，不写回模板。

数据源 API ​

成员
成员类型必填默认值说明
dataSource.listDataSource[]可选—全部数据源快照
dataSource.get(keyOrObject)(key: string | { key: string }) => DataSource | undefined可选—查询数据源
dataSource.upsert(source, originalKey?)(source: DataSource, originalKey?: string) => void可选—创建 / 更新 / 重命名；同 key 更新，否则新增；传 originalKey 实现重命名
dataSource.remove(keyOrObject)(key: string | { key: string }) => void可选—按 key 删除
ts
studio.dataSource.upsert({
  key: 'order', // 绑定表达式首段 = input 顶层键
  type: 'object',
  label: '销售订单',
  sampleData: { number: 'SO-2026-001', amount: 1280 },
  schema: [
    { name: 'number', type: 'string', label: '单号' },
    { name: 'amount', type: 'number', label: '金额' },
    {
      name: 'items',
      type: 'array',
      label: '明细',
      children: [
        { name: 'name', type: 'string' },
        { name: 'quantity', type: 'number' },
      ],
    },
  ],
})

字段类型：string / number / boolean / date / object / array；children 描述对象字段或数组项字段。设计器可从示例 JSON 推断根值类型及字段；数组根据首项的对象字段推断。

数据源直接通过 type 声明根值类型。type 为 object 时，schema 描述对象字段；为 array 时，schema 直接描述数组项的对象字段，无需再包一层数组字段。其他类型不设置 schema。标量和数组根值都直接使用数据源 key 作为绑定路径。

旧版 rootValue 声明不再受支持，不会自动迁移。加载旧模板前，请为数据源添加 type，将顶层数组项字段移到 schema，并移除标量的 schema 与旧 rootValue 字段。迁移时无需修改数据源 key、绑定路径或 sampleData。

在绑定选择器中，可按数据源名称、键或描述搜索。为表格行或循环区块选择数据时，点击数组数据源可直接选中其根数组，也可从字段列表选择数组字段；确认后才应用。

两种绑定形态 ​

字符串绑定——表达式内嵌在字符串属性里，一段字符串可含多个表达式：

订单：{{ order.number }}    客户：{{ order.customer }}

路径支持多级与索引：order.customer.name、items[0].name。

结构化绑定——表格通过 bindings: { rows: 'items' } 绑定数组（路径不加花括号），列的 bind 相对于每行对象；启用 rowNumber 的序号列无需绑定字段。循环区块成员内可直接使用 name、quantity 等行字段，$index 是从 0 开始的当前循环索引，$rowNumber 是从 1 开始的显示序号。

格式化器与文档变量 ​

表达式用途
{{ order.amount | number:2 }}固定两位小数
{{ order.amount | thousand:2 }}千分位与两位小数
{{ order.amount | currency:¥:2 }}货币符号 + 千分位
{{ order.date | date:yyyy-MM-dd }}日期格式化
{{ order.code | upper }} / | lower大小写
{{ $document.documentName }}文档名
{{ $document.pageNumber }} / pageCount最终输出页码 / 总页数
{{ $document.now }} / pageName当前时间 / 页面名

以上格式化器为内置实现，集中注册在 bindingFormatterRegistry。

示例数据与真实数据 ​

  • 省略 input 时，设计器使用各数据源的 sampleData 合成示例输入；未设置示例数据时按 type 及 schema 生成。
  • 显式传入的对象是本次完整输入，不与示例数据自动合并；{} 表示空输入。
ts
const { html, warnings } = await studio.toHTML({ order: { number: 'SO-001' } })
console.log(warnings) // 取值失败产生告警，不中断输出

注意事项 ​

  • 重命名数据源 key 或删除后，检查并更新引用它的表达式、表格绑定与循环 collection，否则输出按缺失字段告警。
  • 循环/表格内的整串单表达式保留原生类型（数字不求值为字符串），用于 image.src、barcode.value 等场景。
  • 设计器画布把绑定变量渲染为标签（不含花括号）；按示例数据预览需开启 settings.previewWithData。
