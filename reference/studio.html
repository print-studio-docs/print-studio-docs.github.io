createPrintStudio() ​

createPrintStudio() 是库集成的核心入口：创建 DesignStudio 实例，聚合文档、页面、元素、数据、输出与事件等全部业务 API。

ts
import { createPrintStudio } from '@printstack/print-studio'
import type { DesignStudio, PrintStudioOptions } from '@printstack/print-studio'

const options: PrintStudioOptions = {
  storage: false,
  defaultElementType: 'text',
  rendering: { worker: false, workerTimeoutMs: 60000 },
}
const studio: DesignStudio = createPrintStudio(options)

DesignStudio 与 PrintStudio 是同一类型的两个名称。Vue 项目可改用 usePrintStudio()（见 Vue 集成）；已有模板只输出不编辑时用 createPrintRenderer()。

创建选项 PrintStudioOptions ​

选项功能类型必填默认值说明
initialDocument初始文档PrintDocument否—传入完整文档对象作为初始内容；优先于自动草稿，仅在未提供该选项时读取草稿
createDocument自定义新建文档工厂() => PrintDocument否—「新建文档」与无 initialDocument 且无存储文档时的初始文档工厂；两个场景均缺省时，新建为种子文档、初始为内置欢迎模板；工厂返回的文档必须至少包含一页
storage自动草稿存储DocumentStorage | false否false默认 false 不启用自动草稿；传入存储对象启用，形状为 { get(): string | null; set(document: string): void }，草稿以 JSON 字符串读写
onSave保存回调(document: PrintDocument) => Promise<void>否—配置后 document.save() 把当前文档对象交给宿主处理（如 JSON.stringify 后上传服务端）；未配置时 save() 抛错，见 [studio.document](./document)
defaultElementType默认元素类型string否'text'画布点击创建的元素类型
errors错误运行时ErrorRuntime否—不传时自动创建独立实例
persistPreferences是否持久化界面偏好boolean否falsetrue 时持久化视图布局等偏好，preferenceStorage 缺省为 localStorage 实现
preferenceStorage偏好存储实现PreferenceStorage否—自定义偏好读写位置，形状为 { get(key): string | null; set(key, value): void }，仅在 persistPreferences 启用时生效
pluginPolicy插件装载策略PluginPolicy否—{ allowLegacy?; permissions? }：是否允许旧形态插件、宿主授予插件的最大权限集合
strictInitialDocument严格校验初始文档boolean否—true 时初始文档含未注册元素类型直接抛 document.unsupported-elements 异常
elements自定义元素ElementDefinition[]否—补充或覆盖同类型内置元素，经注册表生效
parsers自定义解析器DocumentParser[]否—补充或覆盖同 ID 解析器
rendering渲染配置{ fonts?; worker?; workerTimeoutMs? }否—worker 默认 false，workerTimeoutMs 默认 60000（ms）；fonts 配置自定义字体，见[字体与资源](./output#字体与资源)

通用实体句柄 ​

页面、元素、页面模板、循环区块和跟随块的查询都返回句柄：只读 id、data 快照，以及 update(patch)、remove()。引用参数统一为 EntityReference（ID 字符串或带只读 id 的对象）。约定：

  • 集合 get(ref) 查询句柄，list 返回句柄数组（属性，不是函数）。
  • 删除后句柄的 data 为 undefined；加载另一份文档后应重新查询句柄。
  • data 是快照，直接修改快照不会生效，更新必须走句柄或集合方法。

生命周期与挂载 ​

调用功能类型必填说明
mount(options)挂载可视化设计器(options: StudioMountOptions) => Promise<void>否resolve 即界面与插件就绪；同一实例同时只挂载一个设计器，重复挂载以异常拒绝
unmount()卸载设计器视图() => void否移除视图，实例与文档保留，可重复调用；在 mount() 挂起期间调用会使挂起中的 mount() Promise 以 AbortError 拒绝
dispose()销毁实例() => void否联动 unmount 并释放事件、插件与文档存储等资源；之后实例不可再用
ts
// StudioMountOptions（extends DesignerOptions）
interface StudioMountOptions {
  /** 挂载容器元素或 CSS 选择器；容器需要有明确高度 */
  el: HTMLElement | string
  plugins?: PluginInput[]
  presets?: DesignerPresets // { dataSources?; pageTemplates? }
  settings?: Partial<DesignerSettings>
  ui?: { infoBar?; menuBar?; optionsBar?; panels?; toolBar? } // 全 boolean
  zIndex?: number
  onDirtyChange?: (dirty: boolean) => void
  onError?: (error: unknown) => void
}

设计器视图按需加载：调用 mount() 时才拉取视图模块，纯输出用法不加载设计器代码。样式无需手动导入。

输出 API 签名 ​

studio.toHTML(input?, options?, execution?) / studio.toPDF(input?, options?, execution?) / studio.preview(input?, options?) / studio.print(input?, options?) 的参数与结果类型详见 预览 / 打印 / 导出。

使用示例 ​

ts
import { createPrintStudio } from '@printstack/print-studio'

const studio = createPrintStudio({ storage: false })
try {
  studio.document.rename('示例')
  const page = studio.page.active
  page.elements.add({
    type: 'text',
    x: 20,
    y: 30,
    width: 170,
    height: 12,
    props: { text: '你好，Print Studio' },
  })
  const { html, warnings } = await studio.toHTML({ customer: { name: '张女士' } })
  console.log(warnings, html.length)
} finally {
  studio.dispose()
}
