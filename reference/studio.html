createDesigner() ​

createDesigner() 是库集成的核心入口：创建 Designer 实例，聚合文档、页面、元素、数据、输出与事件等全部业务 API。

ts
import { createDesigner } from '@printstack/print-studio'
import type { Designer, DesignerOptions } from '@printstack/print-studio'

const options: DesignerOptions = {
  storage: false,
  defaultElementType: 'text',
  rendering: {
    imageLoadTimeoutMs: 15000,
    worker: false,
    workerTimeoutMs: 60000,
  },
}
const studio: Designer = createDesigner(options)

Vue 项目可改用 useDesigner()（见 Vue 集成）；已有模板只输出不编辑时用 createPrinter()。

通用实体句柄 ​

页面、元素、页面模板、循环区块和跟随块的查询都返回句柄：只读 id、data 快照，以及 update(patch)、remove()。引用参数统一为 EntityReference（ID 字符串或带只读 id 的对象）。约定：

  • 集合 get(ref) 查询句柄，list 返回句柄数组（属性，不是函数）。
  • 删除后句柄的 data 为 undefined；加载另一份文档后应重新查询句柄。
  • data 是快照，直接修改快照不会生效，更新必须走句柄或集合方法。

生命周期与挂载 ​

调用
调用类型必填默认值说明
mount(options)(options: DesignerMountOptions) => Promise<void>可选—挂载可视化设计器；resolve 即界面与插件就绪，同一实例同时只挂载一个设计器，重复挂载以异常拒绝
unmount()() => void可选—卸载设计器视图；移除视图，实例与文档保留，可重复调用，在 mount() 挂起期间调用会使挂起中的 mount() Promise 以 AbortError 拒绝
dispose()() => void可选—销毁实例；联动 unmount 并释放事件、插件与文档存储等资源，之后实例不可再用
ts
// DesignerMountOptions（extends DesignerViewOptions）
interface DesignerMountOptions {
  /** 挂载容器元素或 CSS 选择器；容器需要有明确高度 */
  el: HTMLElement | string
  mode?: 'iframe' | 'standalone'
  plugins?: PluginInput[]
  presets?: DesignerPresets // { dataSources?; pageTemplates? }
  settings?: Partial<DesignerSettings>
  setup?: (host: Pick<Designer, 'use'>) => void | Promise<void>
  startup?: DesignerStartupOptions
  ui?: { infoBar?; menuBar?; optionsBar?; panels?; toolBar? } // 全 boolean
  zIndex?: number
  onDirtyChange?: (dirty: boolean) => void
  onError?: (error: unknown) => void
}

设计器视图按需加载。mount() 会先显示库内置的加载页，宿主无需使用 Vue、手动导入样式或接管加载页。仅使用输出 API 时不会加载设计器视图。

默认在 iframe 内挂载工作区，加载页覆盖挂载容器。独立部署可指定 mode: 'standalone' 显示全屏加载页，并由设计器接管页面主题、标题与语言，卸载时恢复原值。每个页面只能同时挂载一个独立设计器。两种模式共用启动流水线：modules（载入界面，10%）、designer（装配内置及宿主插件，60%）、workspace（挂载工作区，95%）、ready（完成，100%）。mount() 在加载页关闭后完成；浏览器启用减少动态效果时直接关闭，无淡出动画。startup.onStageChange 可观察进度，startup.showLoading: false 可隐藏内置加载页。

在 setup({ use }) 中注册的插件按调用顺序安装，库会等待安装完成再挂载工作区；卸载或启动失败会释放此次启动安装的插件。运行中可通过 studio.use(...) 安装插件。mount() 启动失败时拒绝 Promise；默认清理视图，配置 startup.onRetry 且未隐藏加载页时保留加载失败界面以便宿主接管重试。工作区发生根级渲染错误时可重置界面，当前文档和历史保留。

国际化 ​

库共享一套语言状态，默认简体中文（zh-CN）。通过 registerLocaleMessages() 注册全局语言包，通过 await setLocale(locale) 切换所有设计器和打印器的语言。注册返回的函数可移除该贡献；同一 key 按注册顺序覆盖。实例创建、挂载和销毁不改变语言，也不移除通过 registerLocaleMessages() 直接注册的语言包；插件注册的语言包随插件生命周期释放。iframe 模式不修改宿主页面的 <html lang>。

ts
import { registerLocaleMessages, setLocale } from '@printstack/print-studio'

const unregister = registerLocaleMessages({
  'en-US': { app: { app: { browserTitle: 'Print Studio' } } },
})
await setLocale('en-US')
// 不再需要该语言包时调用 unregister()

需要加载器、语言存储或错误处理时，通过 configureAppI18n({ loaders, storage, onError }) 配置；调用 restoreLocale() 显式恢复存储的语言。语言存储与设计器的 persistPreferences / preferenceStorage 独立。并发切换时最后一次请求生效，被后续请求覆盖的调用返回 false；仅由插件提供译文的语言也可切换；未获取到任何译文或语言代码无效时，回退至默认语言。加载器出错时会报告或抛出错误；若仍有可用译文，则应用这些译文。

使用示例 ​

ts
import { createDesigner } from '@printstack/print-studio'

const studio = createDesigner({ storage: false })
try {
  studio.document.rename('示例')
  const page = studio.page.active
  page.elements.add({
    type: 'text',
    x: 20,
    y: 30,
    width: 170,
    height: 12,
    props: { text: '你好，Print Studio' },
  })
  const { html, warnings } = await studio.toHTML({
    customer: { name: '张女士' },
  })
  console.log(warnings, html.length)
} finally {
  studio.dispose()
}
