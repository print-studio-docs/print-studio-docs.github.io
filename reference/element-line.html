line 线条元素 ​

类型标识 line，快捷键 l，默认尺寸 80×1 mm。用于表格分隔线、签章栏与票据装饰线。

线条是点驱动元素：几何由 node.points（页面坐标 mm 的两端点）表达，x/y/width/height 是包围盒的派生值；几何由端点直接决定，rotation 恒为 0。

基本用法 ​

ts
// 水平分隔线
page.elements.add({
  type: 'line',
  x: 10,
  y: 80,
  width: 190,
  height: 0,
  points: [
    { x: 10, y: 80 },
    { x: 200, y: 80 },
  ],
  props: { color: '#333333', strokeWidth: 0.4, dash: 'dashed' },
})

// 任意方向斜线
page.elements.add({
  type: 'line',
  x: 20,
  y: 20,
  width: 60,
  height: 40,
  points: [
    { x: 20, y: 60 },
    { x: 80, y: 20 },
  ],
  props: { color: '#d54941', strokeWidth: 0.6 },
})

属性 ​

属性功能类型必填默认值说明
color线色string否'#333333'
strokeWidth线宽number否0.4mm；与长度无关
dash虚线样式string否'solid''solid' / 'dashed' / 'dotted'

ElementOptions 特有字段 ​

字段类型说明
pointsPoint[]必传两端点：[{ x, y }, { x, y }]，页面坐标 mm

注意事项 ​

  • 更新线条几何时提交新的 points 数组（整体替换），派生包围盒自动重算。
  • points 缺失时回退为包围盒水平中线上的两端点。
