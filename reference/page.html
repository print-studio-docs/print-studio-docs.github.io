studio.page ​

studio.page 管理打印文档的页面：创建、配置、复制、删除与活动页切换。页面尺寸与方向概念见教程《页面尺寸与方向》。

成员
成员类型必填默认值说明
page.activePageHandle可选—当前活动页句柄，始终存在
page.listPageHandle[]可选—全部页面句柄；属性，不是函数
page.create(options?)(options?: PageOptions) => PageHandle可选—创建页面
page.get(ref)(ref: EntityReference) => PageHandle | undefined可选—查询页面句柄
page.setActive(ref)(ref: EntityReference) => void可选—设置活动页
page.update(ref, patch)(ref: EntityReference, patch: PagePatch) => void可选—更新页面配置
page.duplicate(ref)(ref: EntityReference) => PageHandle | undefined可选—复制页面
page.remove(ref)(ref: EntityReference) => void可选—删除页面；其中的元素与相关区块一并清理

PageOptions / PagePatch ​

ts
interface PageOptions {
  id?: string
  name?: string
  width?: number // mm，默认 210
  height?: number // mm，默认 297
  background?: string // 默认 '#ffffff'
  margins?: PageMargins // { top, right, bottom, left }，mm，默认 0
  templateId?: string // 关联页面模板
}

// PagePatch：name / width / height / background / margins / templateId 的部分字段（不含 id）

页面（含默认应用内置空白模板的页面）的尺寸、背景色和页边距由实际生效的页面模板决定，写入 page.update() 的布局和背景设置不会覆盖模板。需要使用独立的页面背景色时，先调用 studio.template.detach(page) 解除模板关联，再更新页面背景。

方向没有独立字段：width > height 即横版（PDF 与打印输出按宽高关系自动处理）。预设尺寸常量 PAGE_PRESETS 从 @printstack/print-studio/core 导入，含 A4 纵横、A5、Letter 与 80mm / 58mm 小票；条目为 { height, label, width }（label 随语言变化的 getter），按尺寸匹配取用，不能按字符串索引：

ts
import { PAGE_PRESETS } from '@printstack/print-studio/core'

const a4 = PAGE_PRESETS.find((p) => p.width === 210 && p.height === 297)

PageHandle ​

页面句柄除通用 id / data / update / remove 外，还持有 elements 元素集合，见 元素操作 API。删除页面后句柄的 data 为 undefined。

示例 ​

获取可直接操作的活动页：

ts
const page = studio.page.active
page.elements.add({ type: 'text', props: { text: 'Hello' } })

文档至少保留一页；page.active 始终返回当前活动页句柄，读取不会创建页面。删除活动页或恢复历史时自动解析有效活动页；最后一页不能删除。

ts
const studio = createDesigner({ storage: false })

// 创建 A4 横版页面
const page = studio.page.create({
  name: '发货单',
  width: 297,
  height: 210,
  margins: { top: 12, right: 10, bottom: 15, left: 10 },
})
studio.page.setActive(page)

// 更新尺寸
page.update({ width: 210, height: 297 })

// 复制与删除
const copy = studio.page.duplicate(page)
studio.page.remove(copy!)
