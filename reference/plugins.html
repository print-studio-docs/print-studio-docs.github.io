插件与扩展 ​

库集成沿注册表扩展：自定义元素、解析器、命令与插件按注册机制接入，设计与输出实例分别装配。核心原则：不硬编码元素类型分支，不绕过事件、命令、插件系统直连。

自定义元素 ​

ts
import { defineElement } from '@printstack/print-studio/core'

const watermark = defineElement({
  type: 'watermark', // 全局唯一标识
  label: '水印',
  icon: 'app',
  order: 90,
  defaultSize: { width: 80, height: 20 },
  createProps() {
    return { text: 'WATERMARK', color: '#cccccc' }
  },
  toHtml(ctx) {
    // 必须返回合法 XHTML 片段
    const { text, color } = ctx.props as { text: string; color: string }
    return `<div style="color:${color}">${text}</div>`
  },
  toPdf(ctx) {
    /* jsPDF 绘制；返回 void */
  },
})

常用装配方式：

ts
// 1. 设计器和独立打印器共用元素定义
import { createDesigner } from '@printstack/print-studio'
import { createPrinter } from '@printstack/print-studio/printer'

const resources = [{ elements: () => [watermark] }]
const studio = createDesigner({ resources })
const renderer = createPrinter({ resources })

// 2. 插件内注册（可获得画布预览组件等视图能力）
const plugin = definePlugin({
  manifest: {
    apiVersion: '1.0',
    id: 'my-company:watermark',
    version: '1.0.0',
    permissions: ['canvas', 'document:write'],
  },
  setup(ctx) {
    ctx.canvas.registerElement(watermark, { replace: true })
  },
})

ElementDefinition 完整能力：createProps / normalizeProps / inspectorSections / toHtml / toPdf / measureSize / canPaginate / paginate / recoverPagination / overflow / pointBased / inlineEditable / fileDrop / resolveBindings / getMinSize / snapResizeHeight / getResources / worker 等。核心字段说明见 table 元素页 的能力清单。

snapResizeHeight({ height, node, page, threshold, width }) 可在未旋转的单选元素自由缩放底边时提供自定义高度（单位为毫米）。垂直方向未命中现有吸附目标时才调用；返回 undefined 保留原高度。

创建、导入和输出统一先合并 createProps() 默认属性（缺失或 undefined 使用默认值），再调用 normalizeProps。嵌套配置的补全与校验由元素的 normalizeProps 负责；该钩子应保持幂等。输出在字体收集、绑定解析、尺寸测量及 worker 分发之前完成属性归一化，不修改传入模板。

PluginResources 还可通过 parsers() 提供解析器。资源先于初始文档反序列化注册。若只需为已注册元素补充画布预览，使用 ctx.canvas.registerElementPreview(type, component)（需 canvas 与 document:write 权限）；已有预览时保持原定义。预览附属于调用时的元素定义，元素被替换或移除时不会延长该定义的生命周期。使用 ctx.canvas.registerElement(definition, { replace: true }) 覆盖时，注册和清理不会让元素类型短暂缺失。

若元素依赖插件完成创建，可在定义中设置 toolEnabled: false。这不影响文档加载、预览和输出；插件通过 ctx.canvas.registerElementTool(type)（同样需 canvas 与 document:write 权限）启用创建工具及快捷键，停用后释放该注册。当前使用的元素工具不可用时自动切回选择工具，并取消正在进行的创建，同 ID 的覆盖命令仍归其注册者所有。

元素定义可选的 toolOptions 按字段 key 顺序声明工具选项栏中的快捷设置，复用 inspectorSections 的控件、约束、显隐和读写逻辑，例如 toolOptions: ['fontSize', 'color']。该顺序同时决定空间不足时的展示优先级，末尾字段收入「更多属性」，仍使用同一字段控件。未声明时自动取前三个数值、颜色、选择或布尔字段；声明空数组可隐藏快捷设置。多选仅展示 batchEditable 字段。

单选元素可通过 settingsDialog: { layout: 'workspace' } 使用带分类导航的元素设置。若 basicTab 与某个 inspectorSections[].tab 同名，该组区块会归入基本设置，与通用属性同组。

自定义绘制覆盖层可通过 ctx.canvas.getToolProps(type)（需要 canvas 权限）读取元素默认属性与当前会话工具设置合并并经 normalizeProps 归一化后的独立副本，用于绘制预览和创建；几何及内容属性仍由绘制流程提供。内置钢笔工具通过此能力同步描边颜色和线宽。

通过 ctx.canvas.add 成功创建元素后，宿主选中新元素；当前工具与元素类型匹配且未勾选「连续放置」时，自动切换到选择工具。

元素定义可选的 toolHints.create 和 toolHints.edit 分别提供创建工具和单选编辑时的工具提示；未提供时使用通用提示。动态文案可通过 getter 返回，以响应语言切换。

插件需要临时占用工具提示栏时，可通过 ctx.extensions.contribute 向 designer.tool.hint 注册函数（apiVersion: '1.0'，需要 panels 权限）。函数返回字符串时覆盖默认提示，返回 undefined 时让出；多个贡献按 order 从小到大取首个有效结果，插件卸载后自动移除。

教程目标通过 designer.guide.target 注册。目标使用稳定 ID 提供元素查找，并可实现 ensureMounted、ensureVisible 和 waitForElement，用于在面板折叠、弹层关闭或目标尚未挂载时恢复界面。异步方法应监听传入的 signal，在取消或超时时停止后续操作。教程步骤只引用目标 ID 与参数，不直接依赖组件 CSS 结构。该扩展点需要 panels 权限，插件卸载时自动移除目标。

canPaginate(node) 可按实例关闭分页能力，并使未被跟随块引用的元素保留静态定位；缺省随 paginate 启用。inlineEditable.enabled(node) 可按实例关闭内联编辑。

分页能力抛出异常时，底层记录告警并跳过该元素，其余元素继续输出。可选的 recoverPagination(context, error) 可尝试一次专属恢复，返回值与 paginate 相同；恢复失败仍跳过元素。HTML/PDF 输出上下文提供 onWarning，供元素报告局部恢复告警。

worker.html 为布尔值，声明该元素能否在 Worker 中生成 HTML。

WARNING

toHtml 返回值必须是合法 XHTML 片段（标签闭合、属性引号齐全）：PDF 解析器把该片段经 SVG foreignObject 光栅化以支持旋转元素。toPdf 仅在元素无旋转时调用，旋转由解析器统一处理。

自定义元素的字体资源 ​

输出方法会按元素声明的字体请求准备资源并等待字体就绪，业务侧无需手工等待 document.fonts.ready：

  • 元素侧：文本类元素实现 getResources，返回 RenderResources（fonts?: FontRequest[]，字段 family / style? / text / weight?），声明该元素渲染所需的字体：
ts
getResources({ props }) {
  return {
    fonts: [
      {
        family: String(props.fontFamily),
        text: String(props.text),
        weight: String(props.fontWeight),
      },
    ],
  }
}
  • 宿主侧：业务字体经 createDesigner({ rendering: { fonts } }) 提供字体文件（PrintFont：family / url 必填，weight? 可选），或由页面可读取的 @font-face 提供。

插件 PluginDefinition ​

业务插件使用带清单的 PluginDefinition：

ts
import { definePlugin } from '@printstack/print-studio'

const myPlugin = definePlugin({
  manifest: {
    apiVersion: '1.0',
    id: 'my-company:order-tools',
    version: '1.0.0',
    permissions: ['commands', 'events'], // 按需声明，未声明的能力访问会抛错
  },
  setup(ctx) {
    // ctx: PluginContext —— 命令、事件、画布、文档、模板库等扩展点
    const off = ctx.events.on('selection:changed', (payload) => {
      /* 业务逻辑 */
    })
    ctx.commands.register({
      id: 'order:export',
      title: '导出订单',
      run: (ctx) => {
        /* 业务逻辑 */
      },
    })
    return () => {
      off() // 清理监听与资源；卸载时按注册逆序自动调用
    }
  },
})

const studio = createDesigner({})
await studio.use(myPlugin) // 安装并启用；已安装时重新启用

成员
成员类型必填默认值说明

plugins.enable(id)(id: string) => Promise<void> | void可选—启用插件
plugins.disable(id)(id: string) => boolean可选—停用插件
plugins.uninstall(id)(id: string) => boolean可选—卸载插件
plugins.dispose(id)(id: string) => boolean可选—卸载插件，与 uninstall 等价
plugins.has(id)(id: string) => boolean可选—插件是否已安装
plugins.list()() => string[]可选—已安装插件 id 列表
plugins.load(plugin)(plugin: LazyPlugin) => Promise<void>可选—安装并启用懒加载插件
plugins.status(id)(id: string) => 'missing' | PluginStatus可选—查询插件状态
studio.use(plugin)(plugin: PluginInput) => Promise<void> | void可选—便捷入口：安装并启用
  • 内置插件使用 DesignerPlugin（setup 接收编辑器上下文），由宿主装配层登记；业务插件必须带 manifest。
  • 权限：ctx 各能力按清单 permissions 放行，全集为 canvas / commands / data / document:read / document:write / events / locales / panels / preferences / rendering / templates / ui。例如 ctx.canvas.registerElement 需要 canvas + document:write。
  • 沙箱：createSandboxedPlugin({ manifest, url, timeoutMs? }) 把插件隔离到 opaque-origin iframe 执行（url 须为 HTTP(S) 模块地址），只通过结构化消息注册命令、执行授权命令和访问文档快照。
  • 插件文案：插件可在自身包内保存 JSON，用 createPluginLocale(id, messages) 创建命名空间语言包；id 必须与插件清单一致。插件在 setup 中通过 ctx.locales.register(resource) 注册（需 locales 权限），插件停用或卸载时自动释放该注册。同一插件的其他注册仍然有效；同 ID 语言包以最后注册的该语言包为准。也可通过 registerPluginLocale(resource) 独立注册，调用其返回函数注销。resource.trans(key, params, fallback) 可指定找不到译文时的默认文案。
ts
import { createPluginLocale, definePlugin } from '@printstack/print-studio'
import zhCN from './locales/zh-CN.json'
import enUS from './locales/en-US.json'

const locale = createPluginLocale('my-company:example', {
  'zh-CN': zhCN,
  'en-US': enUS,
})

export const plugin = definePlugin({
  manifest: {
    apiVersion: '1.0',
    id: 'my-company:example',
    permissions: ['locales'],
    version: '1.0.0',
  },
  setup(ctx) {
    ctx.locales.register(locale)
  },
})
  • 插件状态事件：plugin:registered / plugin:disposed / plugin:state-changed，payload 含插件名。

PluginContext 能力 ​

命令可声明 segment: { id, label, icon? }：同一菜单分组内相同 id 的命令合并为一行分段选择器，通过 checked 返回选中态，点击后菜单保持展开。右上角主题选择使用内置命令 view.theme.light、view.theme.dark、view.theme.system，可按相同 ID 覆盖。

远程模板库 ​

@printstack/print-studio/designer 提供 createRemoteTemplateProvider(options)，把自建模板服务接入模板库；在插件 setup 中经 ctx.templateLibrary.register(provider) 注册（清单需 templates 权限）：

ts
import { definePlugin } from '@printstack/print-studio'
import { createRemoteTemplateProvider } from '@printstack/print-studio/designer'

const remoteTemplates = definePlugin({
  manifest: {
    apiVersion: '1.0',
    id: 'my-company:remote-templates',
    version: '1.0.0',
    permissions: ['templates'],
  },
  setup(ctx) {
    return ctx.templateLibrary.register(
      createRemoteTemplateProvider({
        id: 'my-company:remote',
        title: () => '公司模板库',
        manifestUrl: 'https://cdn.example.com/templates/manifest.json',
        headers: { Authorization: 'Bearer <token>' },
      }),
    )
  },
})

RemoteTemplateProviderOptions 选项：

选项
选项类型必填默认值说明
idstring必填—来源唯一标识
title() => string必填—来源展示名（分组标题）
manifestUrlstring必填—清单地址，返回 RemoteTemplateManifest JSON；相对地址基于 location.href 解析
headersRecord<string, string>可选—请求头（鉴权等）
fetcher(url, init?) => Promise<Response>可选—自定义请求实现（代理、测试替身）；缺省全局 fetch

自建来源亦可直接实现 TemplateLibraryProvider 契约：

ts
interface TemplateLibraryProvider {
  id: string
  title: () => string // 来源展示名（分组标题）
  list(): TemplateLibraryEntry[] | Promise<TemplateLibraryEntry[]>
  create?(document: PrintDocument): Promise<void> // 支持把当前文档保存到该来源
}

interface TemplateLibraryEntry {
  id: string
  name: string
  load(): PrintDocument | Promise<PrintDocument>
  category?: string
  description?: string
  update?(document: PrintDocument): Promise<void>
  remove?(): Promise<void>
}

模板预览使用示例数据渲染，并与其他输出入口共用元素属性的默认值补全与归一化规则。

清单或文档请求失败时，该来源在模板库面板显示加载失败，不影响其他来源。

SaaS 集成 ​

createSaasClient / createSaasPlugin / createSaasTemplateProvider / SaasHttpError 从独立包 @printstack/saas 导出：

ts
import { createSaasClient, createSaasPlugin } from '@printstack/saas'

const client = createSaasClient({/* SaasClientOptions */})
const plugin = createSaasPlugin(client, {
  workspace: true, // 实例文档持久化（自动保存 + 下载 JSON 命令）
  templates: true, // 接入 SaaS 模板库（布尔开关）
})

createSaasPlugin 选项（全部可选，缺省值见表）：

选项
选项类型必填默认值说明
workspaceboolean可选—启用实例文档持久化
templatesboolean可选—启用 SaaS 模板库（经 createSaasTemplateProvider 接入）
exportsboolean可选—启用导出命令（导出作业轮询）
preferencesboolean可选—启用偏好持久化
logoutboolean可选—注册退出登录命令，缺省关闭
saveDelayMsnumber可选—自动保存防抖延迟（ms），缺省 800
initialSnapshotPrintDocument可选—实例初始文档快照；传入后跳过远端初始化，以其为基线
initialRevisionnumber可选—实例初始版本号，缺省 0

安装 @printstack/saas 和兼容版本的 @printstack/print-studio。宿主负责登录、认证凭据与未授权处理；prepare() 默认不检查会话，设置 authenticate: true 可调用服务端会话接口。可通过 headers、credentials、fetcher、api 和 hooks 自定义认证及传输。

createSaasTemplateProvider 供模板库来源使用；SaasHttpError 为 HTTP 失败异常类型。渲染管线依赖浏览器环境 API，不支持 Node SSR。
