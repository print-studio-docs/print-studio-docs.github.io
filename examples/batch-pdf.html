PDF 批量导出 ​

物流场景：同一份快递面单模板对多条收件数据逐份生成独立 PDF 文件。

完整代码 ​

ts
import { createPrintStudio } from '@printstack/print-studio'
import type { PdfResult, PrintDocument } from '@printstack/print-studio'

/** 示例输入：面单内件清单（全部收件人共用） */
const labelItems = [{ name: '热敏纸 80mm', quantity: 2 }]

/** 快递面单文档（100×150 热敏纸）；构建后立即销毁构建用实例 */
function createShippingLabelDocument(): PrintDocument {
  const studio = createPrintStudio({ storage: false })
  try {
    studio.document.create() // 从空白文档开始搭建（默认打开的欢迎模板仅用于设计器试用）
    studio.document.rename('快递面单')
    const page = studio.page.active
    page.update({ name: '面单', width: 100, height: 150 })
    page.elements.add({
      type: 'text',
      x: 10,
      y: 10,
      width: 80,
      height: 8,
      props: {
        text: '收件人：{{ customer.name }}  {{ customer.phone }}',
        fontSize: 10,
        fontWeight: '700',
      },
    })
    page.elements.add({
      type: 'text',
      x: 10,
      y: 20,
      width: 80,
      height: 16,
      props: { text: '地址：{{ customer.address }}', fontSize: 9, autoHeight: true },
    })
    page.elements.add({
      type: 'text',
      x: 10,
      y: 42,
      width: 80,
      height: 8,
      props: { text: '内件：{{ items[0].name }} × {{ items[0].quantity }}', fontSize: 9 },
    })
    page.elements.add({
      type: 'barcode',
      x: 12,
      y: 76,
      width: 76,
      height: 18,
      props: {
        value: '{{ order.trackingNo }}',
        format: 'CODE128',
        displayValue: true,
        fontSize: 9,
      },
    })
    return studio.document.data
  } finally {
    studio.dispose()
  }
}

/** 批量导出：同一模板对多条数据逐份生成 PDF Blob */
export async function exportShippingLabelsBatch(
  recipients: Array<{ name: string; phone: string; address: string; trackingNo: string }>,
): Promise<Array<{ file: string; result: PdfResult }>> {
  const studio = createPrintStudio({
    initialDocument: createShippingLabelDocument(),
    storage: false,
  })
  const results: Array<{ file: string; result: PdfResult }> = []
  try {
    for (const [index, recipient] of recipients.entries()) {
      const input = {
        order: { trackingNo: recipient.trackingNo },
        customer: {
          name: recipient.name,
          phone: recipient.phone,
          address: recipient.address,
        },
        items: labelItems,
      }
      const result = await studio.toPDF(input)
      results.push({ file: `label-${recipient.trackingNo}.pdf`, result })
      console.log(`第 ${index + 1} 份完成：${result.blob.size} 字节，告警 ${result.warnings.length} 条`)
    }
    return results
  } finally {
    studio.dispose()
  }
}

export function downloadBlobs(
  results: Array<{ file: string; result: PdfResult }>,
): void {
  for (const { file, result } of results) {
    const url = URL.createObjectURL(result.blob)
    const link = document.createElement('a')
    link.href = url
    link.download = file
    link.click()
    URL.revokeObjectURL(url)
  }
}

关键 API 讲解 ​

API用途
studio.toPDF(input)每条数据一份独立 PdfResult { blob, warnings, execution }
URL.createObjectURL(blob)宿主侧触发保存

批量打印 vs 批量导出 ​

ts
// 批量打印：每次调用独立调起一个打印对话框
for (const recipient of recipients) {
  await studio.print({ order: { trackingNo: recipient.trackingNo }, customer: recipient })
}

// 批量导出：逐份独立 PDF（本案例）
const results = await exportShippingLabelsBatch(recipients)
downloadBlobs(results)

要点 ​

  • 复用同一 studio 实例即可，模板只构建一次；流程结束在 finally 中 dispose()。
  • 每份 PDF 独立分页；需要一份多页 PDF（每收件人一页）时改用循环区块 direction: 'page'。
  • warnings 逐份检查，资源失败不中断批次。
  • 挂载设计器时，内置导出对话框支持暂停 / 恢复 / 取消。
