8. 模板预览 ​

前置：第 2 课创建的 Designer 实例；本课「数据预览」一节需要挂载设计器（挂载详见第 12 课）。

库的输出动作分三类：预览（查看注入数据后的输出效果，不落纸）、打印（调起浏览器打印对话框）、导出（生成 HTML / PDF 文件）。本课聚焦预览，先区分各形态再选择 API：

形态调用说明
模板编辑视图studio.mount({ el })设计器画布（编辑态，空白或示例数据，见第 12 课）
数据预览设计器设置 previewWithData画布按各数据源 sampleData 解析绑定
打印预览studio.preview(input)注入打印数据后的输出效果与绑定告警（iframe 隔离）；可独立挂载完整打印预览（mode: 'designer'）
浏览器打印studio.print(input)调起浏览器打印对话框——不是预览，见第 9 课
自定义展示studio.toHTML(input)返回 HTML 字符串，宿主自行嵌入，见第 10 课
第 8 课：打印预览两种模式全屏遮罩 / 嵌入容器 / designer 独立挂载，均由按钮触发
在 Playground 中编辑 在新窗口练习

preview()：注入数据后的输出预览 ​

ts
// 全屏遮罩（带关闭按钮）
const handle = await studio.preview({ customer: { name: '张女士' } })
handle.close()

// 独立挂载完整打印预览，默认隐藏「打印数据」
await studio.preview(
  { customer: { name: '张女士' } },
  { mode: 'designer', designer: { themeMode: 'light' } },
)

// 嵌入指定容器
const embedded = await studio.preview(
  { customer: { name: '张女士' } },
  { container: document.getElementById('preview-box')! },
)
console.log(embedded.warnings)
选项功能类型必填默认值说明
container嵌入容器HTMLElement否—需明确高度；缺省全屏遮罩
mode预览方式'iframe' | 'designer'否'iframe'designer 独立挂载完整打印预览，支持 container、signal 与 timeoutMs
designer设计器预览配置object否—仅 designer 模式可传；包含 themeMode 和 showPrintData，详见输出 API
timeoutMs等待上限number否60000覆盖渲染与 iframe 资源就绪
signal取消AbortSignal否—

返回 PreviewHandle：element（iframe）、warnings、close()。两种模式均在首轮渲染与资源就绪后 resolve。Designer 模式无需 studio.mount()，支持指定容器，缺省挂载到 body；关闭窗口或调用 close() 会释放预览渲染会话。

previewWithData：画布内数据预览 ​

ts
const studio = createDesigner({ storage: false })
await studio.mount({
  el: '#designer', // 容器需有明确高度；挂载用法详见第 12 课
  settings: { previewWithData: true },
})

画布即按各数据源 sampleData 渲染绑定值。

自定义预览容器 ​

ts
const input = { customer: { name: '张女士' } } // 打印数据（见第 6 课）
const box = document.createElement('iframe')
const { html, warnings } = await studio.toHTML(input)
box.srcdoc = html // toHTML 返回完整 HTML 文档，须用 iframe.srcdoc 嵌入
document.body.append(box)
console.log(warnings)

注意事项 ​

  • 预览与打印、导出共用同一条渲染管线，输出为成品视图；预览结果不是可编辑文档。
  • preview() 的 Promise resolve 表示 iframe 内容与资源就绪；close() 中止加载并移除。
  • 在完整打印预览的连续页面模式下滚动时，左侧页面列表会让当前页的缩略图保持可见。
  • 浏览器打印对话框不是打印预览；需要打印时直接调 studio.print(input)（第 9 课），不要复用预览 iframe。
