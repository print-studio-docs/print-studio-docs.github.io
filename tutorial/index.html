预备知识 ​

  • JavaScript / TypeScript 基础（模块、async/await、DOM 基本操作）。
  • 不需要 Vue 框架经验：第 1–7、9–11 课全部使用 createDesigner() 命令式 API；第 8、12 课涉及挂载设计器界面（Vue 组件 PrintDesigner），了解组件的基本用法即可跟随。

环境准备 ​

任选其一：

  1. 在线 Playground（零安装）：第 1、4、6、8、9、10、11、12 课页面内嵌可运行的案例，可直接观察效果。
  2. 本地项目：创建一个 Vite 项目并安装库，各课代码片段放入 src/main.ts 即可运行。
bash
npm create vite@latest my-print-app -- --template vanilla-ts
cd my-print-app
npm install @printstack/print-studio

教程面向浏览器环境（渲染依赖浏览器能力），代码以 TypeScript 编写。
