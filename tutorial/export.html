10. 导出 PDF 与 HTML ​

前置：第 2 课创建的 DesignStudio 实例。

toPDF() 返回 PDF Blob，toHTML() 返回自包含 HTML 字符串；export.pdf(input) / export.html(input) 与它们是同一函数，同样只生成并返回结果，不触发下载——保存到本地由宿主完成。

第 10 课：纯输出与 PDF 下载
在新窗口打开

嵌入案例使用纯输出入口 createPrintRenderer() 渲染同一模板，其成员见 createPrintRenderer()。

本课示例统一使用如下输入：

ts
// input：本次打印数据（结构见第 6 课）
const input = {
  customer: { name: '张女士' },
  items: [{ name: '复印纸', quantity: 2, amount: 128 }],
}

PDF ​

ts
const { blob, warnings, execution } = await studio.toPDF(input, {
  rasterPxPerMm: 300 / 25.4, // 旋转元素光栅化密度，默认 300dpi
})
console.log(execution.backend, execution.durationMs)
console.log(warnings)

PDF 输出要点：

  • 页面尺寸与 mm 坐标精确对应；
  • 非旋转元素矢量输出，旋转元素以位图嵌入，密度由 rasterPxPerMm 控制；
  • 字体自动收集嵌入；自定义字体经 rendering.fonts 配置（见下文「字体准备」）。

HTML ​

ts
const { html, warnings } = await studio.toHTML(input, { title: '销售订单' })
// html 是自包含文档：<style> + @page 规则 + .print-page 分节
console.log(warnings)

保存到本地（宿主职责） ​

ts
function downloadPdf(blob: Blob, filename: string): void {
  const url = URL.createObjectURL(blob)
  const anchor = document.createElement('a')
  anchor.href = url
  anchor.download = filename
  anchor.click()
  URL.revokeObjectURL(url)
}

function downloadHtml(html: string, filename: string): void {
  const blob = new Blob([html], { type: 'text/html;charset=utf-8' })
  const url = URL.createObjectURL(blob)
  const anchor = document.createElement('a')
  anchor.href = url
  anchor.download = filename
  anchor.click()
  URL.revokeObjectURL(url)
}

const pdf = await studio.toPDF(input)
downloadPdf(pdf.blob, 'order.pdf')

const htmlResult = await studio.toHTML(input)
downloadHtml(htmlResult.html, 'order.html')

选项与取消 ​

HTML 选项（HtmlParseOptions）功能类型必填默认值说明
title输出 titlestring否—生成的 <title>，默认文档名
fontCss补充字体 CSSstring否—
signal取消AbortSignal否—
PDF 选项（PdfParseOptions）功能类型必填默认值说明
rasterPxPerMm光栅化密度number否300 / 25.4旋转元素位图密度（每毫米像素）
fontCss补充字体 CSSstring否—
signal取消AbortSignal否—

两个方法的第三参数为执行配置（RenderExecutionOptions）：signal? 与 timeoutMs?（默认 60000，必须为有限正数；同步计算阶段无法被立即中断）。

ts
const { blob } = await studio.toPDF(input, undefined, {
  timeoutMs: 30000,
  // signal: controller.signal,
})

执行诊断 ​

ts
interface RenderExecution {
  backend: 'hybrid' | 'main' | 'worker'
  durationMs: number
  reason?: 'disabled' | 'unavailable' | 'custom-parser' | 'element-capability'
}

业务以输出内容和 warnings 为准；execution 用于诊断耗时与执行路径。

字体准备 ​

ts
const fonts = [
  { family: 'Receipt', url: '/fonts/receipt-regular.woff2', weight: '400' },
  { family: 'Receipt', url: '/fonts/receipt-bold.woff2', weight: '700' },
]
const studio = createPrintStudio({ storage: false, rendering: { fonts } })

fontFamily: 'Receipt' 的元素在渲染前自动加载对应字体文件；跨域字体需 CORS 允许嵌入。

没有 PNG / JPG 导出 ​

内置导出格式为 HTML / PDF / 模板 JSON，没有位图导出 API。需要图片时可在 PDF 基础上用宿主侧库转换，或直接使用 HTML 嵌入。
