1. 创建实例 ​

一切从 createPrintStudio() 开始：它创建一个 DesignStudio 实例——文档、页面、元素、数据、输出与事件的统一操作入口。

前置：无（本课是教程起点）。后续所有课程都依赖本课创建的实例。

最小实例 ​

ts
import { createPrintStudio } from '@printstack/print-studio'

const studio = createPrintStudio({ storage: false })

// …业务操作…

studio.dispose() // 销毁实例

创建选项 ​

选项功能类型必填默认值说明
storage自动草稿存储DocumentStorage | false否不启用传入实现 get / set 的存储对象后启用自动草稿；保存完全由业务控制时无需配置
initialDocument初始文档PrintDocument否—以指定文档开局；缺省且无草稿时打开内置欢迎模板
onSave保存回调(document: PrintDocument) => Promise<void>否—document.save() 将当前文档对象交给宿主持久化
errors错误处理ErrorRuntime否—统一接收库内异常与告警，用法见第 12 课
rendering渲染配置{ fonts?; worker?; workerTimeoutMs? }否—worker 默认 false；workerTimeoutMs 默认 60000（毫秒）
elements / parsers自定义扩展数组否—实例级注册自定义元素 / 解析器

完整选项见 API 参考 createPrintStudio()。

生命周期 ​

调用语义
mount({ el })挂载设计器视图，异步完成；resolve 即界面与插件就绪
unmount()移除视图，实例与文档保留；可重复调用
dispose()销毁实例：视图、事件订阅、插件与渲染资源一并释放，实例不可再用
ts
const studio = createPrintStudio({ storage: false })
try {
  // 业务操作
} finally {
  studio.dispose()
}

WARNING

实例销毁统一由 dispose() 承担，建议放在 finally 中保证执行。

Vue 项目可用 usePrintStudio() 在组件作用域内创建实例并自动清理。createPrintStudio() 与 usePrintStudio() 两种入口的对比见指南 简介 · 创建方式。

检查点 ​

  • studio.document.data 返回当前文档快照。
  • studio.document.dirty 标记未保存修改。
  • studio.events.on('document:changed', fn) 可观察一切修改（返回解绑函数）。
