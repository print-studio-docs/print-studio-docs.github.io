5. 样式与层级 ​

前置：第 4 课创建的 DesignStudio 实例、页面句柄 page 与元素句柄。

元素的视觉样式分布在两处：通用字段（所有元素共有）与类型专属 props。位置、尺寸、旋转的单位约定见指南 开发规范 · 单位与坐标。

通用视觉字段 ​

字段功能类型必填默认值说明
x / y位置number否0mm，页面左上角原点
width / height尺寸number否元素 defaultSizemm
rotation旋转number否0度，绕中心顺时针；点驱动元素恒 0
opacity不透明度number否10–1
visible / locked显隐 / 锁定boolean否true / false锁定只约束画布交互，不影响选中与代码更新
ts
const el = page.elements.add({
  type: 'rect',
  x: 10, y: 40, width: 80, height: 30,
  props: { fill: '#f0f7ff' },
})

el.update({ rotation: 10, opacity: 0.7 })          // 通用字段
page.elements.updateProps(el, { fill: '#fff4cc' }) // props

叠放顺序（层级） ​

elements 数组索引即叠放顺序，索引 0 在最底层：

ts
page.elements.list           // 句柄数组，数组索引 0 在最底层
page.elements.move(el, 0)    // displayIndex 0 为最顶层（与数组索引方向相反）
studio.edit.sendTo('front')  // 选区置顶（需先 selection.set([el])）
studio.edit.reorder(1)       // 选区叠放索引 +1

studio.selection 与 studio.edit 是选区与编辑（对齐、分布、微移、层级调整）的入口，方法总览见 API 参考 createPrintStudio() · 选区与编辑。

对齐与分布 ​

ts
const a = page.elements.add({ type: 'rect', x: 10, y: 40, width: 80, height: 30 })
const b = page.elements.add({ type: 'rect', x: 100, y: 90, width: 80, height: 30 })

studio.selection.set([a, b])
studio.edit.align('hcenter')      // left/right/top/bottom/hcenter/vcenter
studio.edit.distribute('h')       // h/v 等距分布
studio.edit.nudge(0, 4)           // 选区微移 mm
studio.selection.clear()

批量排版 ​

ts
// 创建副本：返回句柄数组
const copies = page.elements.duplicate(el)

// 重命名（图层面板显示名）
page.elements.rename(el, '标题底框')

页面模板与共用样式层 ​

页眉、页脚、背景等跨页共用内容放页面模板（详见 页面模板），渲染时在页面元素之下：

ts
// studio：第 2 课创建的实例；page：第 2 课的活动页面句柄
const stationery = studio.template.create({ name: '抬头' })
stationery.page.elements.add({
  type: 'text', x: 10, y: 8, width: 190, height: 10,
  props: { text: '示例公司 · {{ $document.documentName }}', fontSize: 16 },
})
studio.template.apply(stationery, [page])
