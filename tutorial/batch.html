11. 批量打印与批量导出 ​

前置：第 2 课创建的 Designer 实例与页面句柄 page；第 6 课的表达式绑定语法。

两条批量路线：模板内展开（循环区块，一次输出多份内容）与业务侧循环（同模板多份数据逐次输出）。

路线一：循环区块（模板内展开） ​

第 11 课：商品标签网格平铺
在新窗口打开

一组元素按数组数据平铺，超页自动分页——标签阵列的标准做法：

ts
// 成员：一枚标签的三个元素
const card = page.elements.add({
  type: 'rect',
  x: 10,
  y: 10,
  width: 60,
  height: 40,
  props: { fill: '#fff', stroke: '#ccc', strokeWidth: 0.3, radius: 2 },
})
const name = page.elements.add({
  type: 'text',
  x: 13,
  y: 14,
  width: 54,
  height: 12,
  props: { text: '{{ name }}', fontSize: 10 },
})
const code = page.elements.add({
  type: 'barcode',
  x: 16,
  y: 30,
  width: 48,
  height: 14,
  props: { value: '{{ barcode }}', format: 'CODE128', displayValue: false },
})

studio.repeatGroup.create({
  pageId: page.id,
  elementIds: [card.id, name.id, code.id],
  name: '商品标签阵列',
  collection: 'items', // 数组路径
  direction: 'grid', // grid | page | vertical
  columns: 3,
  gapX: 2.5,
  gapY: 3,
  positionMode: 'flow',
})

// 注入数组数据输出（成员内 {{ name }} / {{ barcode }} 相对每条数据求值）
const items = Array.from({ length: 18 }, (_, index) => ({
  name: `商品 ${index + 1}`,
  barcode: '6901234500001',
}))
const { html, warnings } = await studio.toHTML({ items })
console.log(warnings)

direction 三种模式：

模式行为场景
gridcolumns 列网格 + gapX/gapY标签平铺
page每条数据独占一页、保持设计位置批量面单
vertical纵向逐条排布明细列表

成员内可用行字段（{{ name }}）与 $index；positionMode: 'flow' 让后续内容上移跟随。

表格行批量（fillEmptyRows） ​

固定行数单据（出入库单）不足补空行：

ts
const table = page.elements.add({
  type: 'table',
  x: 10,
  y: 40,
  width: 190,
  props: {
    columns: [
      { title: '商品名称', width: 3 },
      { title: '数量', width: 1, align: 'right' },
    ],
    rows: [],
    pagination: {
      crossPage: false,
      fixedRows: true, // fillEmptyRows / rowsPerPage 由固定行数模式门控
      rowsPerPage: 12,
      fillEmptyRows: true,
      positionMode: 'fixed',
    },
  },
})

路线二：业务侧循环（多份独立输出） ​

第 11 课：逐条批量导出 PDF
在新窗口打开
ts
const customers = [
  { name: '张女士', trackingNo: 'SF1001' },
  { name: '李先生', trackingNo: 'SF1002' },
]

// 宿主保存辅助：Blob + <a download>
function saveAs(blob: Blob, filename: string): void {
  const url = URL.createObjectURL(blob)
  const link = document.createElement('a')
  link.href = url
  link.download = filename
  link.click()
  URL.revokeObjectURL(url)
}

for (const customer of customers) {
  const { blob } = await studio.toPDF({ customer }) // 每条一份独立 PDF
  saveAs(blob, `${customer.trackingNo}.pdf`)
}
  • 批量打印：循环内 studio.print({ customer })，每次调用独立打开一个打印对话框。
  • 批量导出：循环内 toPDF 收集 Blob，由宿主统一保存或逐份保存（见第 10 课）。
  • 批量渲染共用同一实例即可。

两种路线的适用场景 ​

场景路线
一张纸上排 N 枚标签循环区块 grid
每条数据一页完整单据循环区块 page 或业务侧循环
每条数据一份独立文件业务侧循环
