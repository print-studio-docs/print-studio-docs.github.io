6. 动态数据绑定 ​

模板写占位表达式，打印时注入 input 求值。数据不写回模板。

第 6 课：数据源与表达式绑定
在新窗口打开

表达式绑定 ​

字符串属性内嵌 {{ 路径 | 格式化:参数 }}，一段字符串可含多个表达式：

ts
page.elements.add({
  type: 'text',
  x: 15, y: 30, width: 180, height: 20,
  props: { text: '尊敬的 {{ customer.name }}，订单 {{ order.number }} 已发货。' },
})
  • 路径支持多级与索引：order.customer.name、items[0].name。
  • 循环区块成员内可直接使用行字段（如 {{ name }}），并可用 $index 取当前序号（0 起）；循环区块见第 11 课。

格式化器 ​

表达式结果示例
{{ amount | number:2 }}1280.00
{{ amount | thousand:2 }}1,280.00
{{ amount | currency:¥:2 }}¥1,280.00
{{ date | date:yyyy-MM-dd }}2026-01-18
{{ code | upper }} / | lower大小写转换

文档变量 ​

{{ $document.pageNumber }} / pageCount / documentName / pageName / now——页码页脚最常用：

ts
// studio：第 2 课创建的实例；页面模板用法见第 5 课
const stationery = studio.template.create({ name: '页脚' })
stationery.page.elements.add({
  type: 'text', x: 10, y: 283, width: 190, height: 8,
  props: { text: '第 {{ $document.pageNumber }} / {{ $document.pageCount }} 页',
    textAlign: 'center', fontSize: 9 },
})
studio.template.apply(stationery, studio.page.list)

结构化绑定（表格） ​

表格的行数据来自数组绑定，列的 bind 相对每行对象：

ts
page.elements.add({
  type: 'table',
  x: 10, y: 42, width: 190,
  bindings: { rows: 'items' },   // 数组路径，不加花括号
  props: {
    columns: [
      { title: '商品', bind: 'name', width: 3 },
      { title: '数量', bind: 'quantity', width: 1, align: 'right' },
    ],
    rows: [],
  },
})

数据源声明 ​

ts
studio.dataSource.upsert({
  key: 'order',
  label: '销售订单',
  sampleData: { number: 'SO-2026-001', amount: 1280 },
  schema: [
    { name: 'number', type: 'string', label: '单号' },
    { name: 'amount', type: 'number', label: '金额' },
  ],
})

作用：设计器字段面板按 schema 树展示、省略 input 时用 sampleData 合成示例输入。

注入数据 ​

ts
const { html, warnings } = await studio.toHTML({
  customer: { name: '张女士' },
  order: { number: 'SO-2026-001', amount: 1280 },
})
console.log(warnings) // 取值失败产生告警，不中断输出

WARNING

显式传入的 input 是本次完整输入，不与 sampleData 自动合并；{} 表示空输入。整串单表达式（如 image.src: '{{ product.image }}'）保留原生类型。
