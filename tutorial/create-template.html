2. 创建打印模板 ​

打印模板 = 一份 PrintDocument。本课经实例逐层构建：文档 → 页面 → 元素。

前置：第 1 课创建的 Designer 实例（本课示例为可独立运行的完整代码）。

三层结构 ​

text
PrintDocument（文档）
 ├── pages: PageNode[]（页面）
 │     └── elements: ElementNode[]（元素，索引 0 最底层）
 ├── dataSources: DataSource[]（数据源声明）
 ├── templates: PageTemplate[]（页面模板 / 主页）
 └── repeatGroups / followBlocks（循环区块与跟随块）

用实例创建 ​

ts
import { createDesigner } from '@printstack/print-studio'

const studio = createDesigner({ storage: false })
try {
  // 新实例缺省打开内置欢迎模板（仅用于无业务上下文时的缺省展示），
  // 业务模板从空白文档开始搭建
  studio.document.create()
  studio.document.rename('客户通知单')

  // 空白文档的初始页面为 210×297（A4 纵向），可按需调整
  const page = studio.page.active
  page.update({ name: '通知单', width: 210, height: 297 })

  // 元素
  page.elements.add({
    type: 'text',
    x: 20,
    y: 30,
    width: 170,
    height: 20,
    props: { text: '尊敬的客户，您的订单已发货。', fontSize: 14 },
  })

  console.log(studio.document.data) // 完整文档快照
} finally {
  studio.dispose()
}

关键语义 ​

  • 句柄：studio.page.create() 返回页面句柄 { id, data, update, remove, elements }；元素同理。
  • props 按类型补全：elements.add 只写关心的字段，其余字段取该元素类型的默认值（如条形码默认 CODE128 码制）。
  • id 自动生成：元素与页面的 id 由库生成，一般不需要手动指定。
  • 快照只读：studio.document.data 拿到的对象直接修改不生效，一律走句柄。

需要在无实例环境（如批量脚本）中组装文档时，走纯函数路线，见 元素操作 API「纯函数创建」一节。

声明数据源（可选） ​

ts
studio.dataSource.upsert({
  key: 'customer',
  type: 'object',
  label: '客户信息',
  sampleData: { name: '张女士' },
  schema: [{ name: 'name', type: 'string', label: '姓名' }],
})

数据源让设计器字段面板可点选绑定，也为「省略 input」时提供示例数据。schema 结构、表达式与格式化器见第 6 课。
