7. 模板保存与加载 ​

前置：第 2 课创建的 Designer 实例。

模板即 JSON。本课覆盖导出、加载与手动反序列化。

导出 JSON ​

ts
const json = studio.export.json() // 当前文档序列化字符串
localStorage.setItem('my-template', json)
// 或交给服务端
await fetch('/api/templates', { method: 'POST', body: json })

配置 onSave 自动交给宿主 ​

document.save() 将当前文档对象交给 onSave 回调，由宿主持久化：

ts
import { createDesigner } from '@printstack/print-studio'
import type { PrintDocument } from '@printstack/print-studio'

const studio = createDesigner({
  storage: false,
  onSave: async (document: PrintDocument) => {
    await fetch('/api/templates', {
      method: 'POST',
      body: JSON.stringify(document), // 收到的是 PrintDocument 对象
    })
  },
})
await studio.document.save()

未配置 onSave 时调用 save() 会抛出错误；save() 不会下载文件。

加载 JSON ​

ts
studio.document.loadJson(json) // json：上一节导出的模板 JSON 字符串
studio.document.load(documentObject) // documentObject：已解析为对象的 PrintDocument

加载处理（以结果为准）：

  • 字段缺省值自动补全；不提供历史文档格式迁移；
  • 未注册的元素类型被剔除，并通过告警提示类型名（需要精确读取剔除列表时用下节的手动反序列化）；
  • 悬空的页面模板引用清空后使用空白页面模板；缺 templates 时补空白页面模板；
  • JSON 不合法或缺 pages 时抛领域异常（document.invalid / document.no-pages）。

手动反序列化（检查剔除类型） ​

deserializeDocument（@printstack/print-studio/core）返回结果与剔除列表。纯输出入口 createPrinter（@printstack/print-studio/printer）创建的实例注册表适合作为第二个参数；createPrinter 省略 elements 时自动注册全部内置元素：

ts
import { deserializeDocument } from '@printstack/print-studio/core'
import { createPrinter } from '@printstack/print-studio/printer'

export async function renderStoredTemplate(
  rawJson: string, // 此前经 studio.export.json() 导出的模板 JSON
  input: Record<string, unknown>, // 本次打印数据（见第 6 课）
) {
  const renderer = createPrinter() // 纯输出实例，成员见 createPrinter() 参考
  try {
    const { document: template, skippedTypes } = deserializeDocument(
      rawJson,
      renderer.elements,
    )
    if (skippedTypes.length > 0) {
      console.warn('未注册的元素类型被剔除：', skippedTypes)
    }
    return await renderer.toHTML(template, input)
  } finally {
    renderer.dispose()
  }
}

注意事项 ​

  • 加载会重置历史（撤销栈清空）；loadJson() 成功后触发 document:loaded 事件（load() 不触发）。
  • HTML / PDF 是渲染结果，不能当模板 JSON 重新加载。
  • version 标识文档格式，parserVersion 选择解析器版本；不提供历史文档格式迁移。
  • 自动草稿默认不启用：给 storage 传入实现 get / set 的存储对象后，文档变更自动写入并在下次打开时恢复；缺省或传 false 均不启用。
