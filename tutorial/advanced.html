12. 高级功能与业务集成 ​

本课汇总业务集成常用能力：挂载设计器、事件驱动、错误处理、插件与自定义元素、SaaS 集成与 Worker 渲染。

前置：第 1 课创建的 DesignStudio 实例；第 8 课的预览概念。

挂载可视化设计器 ​

实例与视图分离：不调用 mount() 的纯代码用法不创建任何设计器视图。

第 12 课：命令式挂载设计器
在新窗口打开
ts
const studio = createPrintStudio({ storage: false })
await studio.mount({ el: '#designer' }) // 容器需有明确高度；resolve 即界面与插件就绪
studio.unmount()  // 只移除视图，实例与文档保留
studio.dispose()  // 销毁实例

挂载中的 mount() 若被 unmount() 打断，对应的 Promise 会以取消错误拒绝。Vue 项目可改用 usePrintStudio() + <PrintDesigner :studio="studio" />，见 Vue 集成。

事件驱动集成 ​

ts
// 同步保存按钮状态（saveButton：宿主页面上的按钮元素）
const saveButton = document.querySelector<HTMLButtonElement>('#save-button')
const off = studio.events.on('document:changed', () => {
  if (saveButton) {
    saveButton.disabled = !studio.document.dirty
  }
})

// 通配诊断（开发环境）
const trace = studio.events.on('*', (type, payload) => console.log(type, payload))

// 清理
off()
trace()

完整事件目录与触发时机见 事件 API。刷新按钮状态优先 studio.state.subscribe()。

统一错误处理 ​

第 1 课选项表中的 errors 选项在这里展开：createErrorRuntime 创建的错误运行时统一接收库内异常，业务侧的异步失败也可汇入：

ts
import { createErrorRuntime } from '@printstack/print-studio'

const errors = createErrorRuntime({
  report(event) {
    console.error('输出失败', event.context.source, event.error)
  },
})
const studio = createPrintStudio({ storage: false, errors })

async function fetchTemplate(): Promise<string> {
  const response = await fetch('/api/templates/current')
  if (!response.ok) {
    throw new Error(`加载模板失败：${response.status}`)
  }
  return response.text()
}

// 外部异步失败也汇入统一处理
try {
  await fetchTemplate()
} catch (error) {
  await studio.errors.capture(error, { source: 'fetch-template' })
}

插件与自定义元素 ​

业务插件必须携带 manifest；注册画布元素需要 canvas 与 document:write 权限：

ts
import { definePlugin } from '@printstack/print-studio'
import { defineElement } from '@printstack/print-studio/core'
import type { ElementDefinition } from '@printstack/print-studio/core'
import type { PluginContext } from '@printstack/print-studio'

// 最小自定义元素定义（toPdf 的绘制实现此处省略）
const stampElement: ElementDefinition = defineElement({
  type: 'stamp',
  label: '图章',
  icon: 'app',
  order: 99,
  defaultSize: { width: 30, height: 30 },
  createProps: () => ({ text: '已审核' }),
  inspectorSections: [
    {
      title: '内容',
      fields: [{ key: 'text', label: '文字', type: 'string' }],
    },
  ],
  toHtml(ctx) {
    const { text } = ctx.props as { text: string }
    return `<div style="color:#b42318;border:0.4mm solid #b42318;border-radius:50%;width:30mm;height:30mm;line-height:30mm;text-align:center">${text}</div>`
  },
  toPdf() {
    // 生产插件在此实现 PDF 绘制
  },
})

// studio：第 1 课创建的实例
const stampPlugin = definePlugin({
  manifest: {
    apiVersion: '1.0',
    id: 'stamp-tools',
    version: '1.0.0',
    permissions: ['canvas', 'document:write'],
  },
  setup(ctx: PluginContext) {
    // registerElement 返回解绑函数，作为插件清理逻辑返回
    return ctx.canvas.registerElement(stampElement)
  },
})

await studio.use(stampPlugin)

扩展点总览见 插件与扩展。

SaaS 后端集成 ​

ts
import { createSaasClient, createSaasPlugin } from '@printstack/print-studio'

const client = createSaasClient({ baseUrl: '/api' })
await studio.use(createSaasPlugin(client, { templates: true }))

SaaS 插件提供模板云存储、保存同步等能力；远程模板库可经 createSaasTemplateProvider 或 createRemoteTemplateProvider（@printstack/print-studio/designer）构建。

Worker 渲染 ​

ts
const studio = createPrintStudio({
  storage: false,
  rendering: { worker: true, workerTimeoutMs: 60000 },
})

开启后 HTML 渲染在 Web Worker 中执行，主线程不阻塞；需要主线程环境的元素能力自动回退，execution.backend 与 reason 可诊断（见第 10 课）。
