4. 绘制内置元素 ​

内置元素统一经 page.elements.add({ type, x, y, width, height, props }) 创建；props 字段随类型不同。各元素的属性说明见元素操作 API。

前置：第 2 课创建的 Designer 实例与活动页面句柄 page。

第 4 课：八种元素代码绘制
在新窗口打开

工具选项栏 ​

在设计器中切换元素工具，工具选项栏显示该元素的常用设置，例如文本的字体、字号、颜色，形状的填充、描边和线宽。未选中同类型元素时，修改作为当前会话内该工具后续绘制的默认属性；选中同类型元素时，修改实时应用到选区，支持撤销和重做。同类型多选仅显示支持批量编辑的字段，锁定元素时禁用编辑。选择工具也显示选区对应的快捷字段，抓手工具提供画布缩放设置。

未勾选「连续放置」时，绘制完成后自动切换到选择工具并选中新元素；勾选后保留当前工具以继续绘制。

栏首标明当前修改的是「创建默认值」还是「编辑选区」。快捷字段按可用宽度显示，放不下的字段进入「更多属性」。选择工具有选区时提供对齐与分布入口；吸附开关、参考线锁定和网格尺寸集中在「吸附与辅助」中，数据预览保留独立入口。

文本 text ​

ts
// page：第 2 课从 studio.page.active 取得的页面句柄
page.elements.add({
  type: 'text',
  x: 10,
  y: 10,
  width: 190,
  height: 14,
  props: {
    text: '客户：张女士', // 动态取值（表达式绑定）见第 6 课
    fontSize: 12, // pt
    fontWeight: '700',
    textAlign: 'left',
    autoHeight: true, // 按内容自适应高度
  },
})

线条 line（点驱动） ​

线条由 points（两端点、页面坐标 mm）驱动；x / y / width / height 包围盒由两端点派生，rotation 恒为 0：

ts
page.elements.add({
  type: 'line',
  x: 10,
  y: 80,
  width: 190,
  height: 0,
  points: [
    { x: 10, y: 80 },
    { x: 200, y: 80 },
  ],
  props: { color: '#333333', strokeWidth: 0.4, dash: 'dashed' },
})

图片 image ​

page.elements.add({

表格 table ​

ts
page.elements.add({
  type: 'table',
  x: 10,
  y: 128,
  width: 190,
  props: {
    columns: [
      { title: '商品', width: 3, align: 'left' },
      {
        title: '数量',
        width: 1,
        align: 'right',
        bodyStyle: { align: 'right' },
      },
      {
        title: '金额',
        width: 2,
        align: 'right',
        bodyStyle: { align: 'right' },
        format: { type: 'currency', digits: 2 },
      },
    ],
    rows: [
      ['复印纸 A4', '2', '128.00'],
      ['墨盒', '1', '80.00'],
    ],
    heightMode: 'auto',
    pagination: { crossPage: true, repeatHeader: true },
  },
})

行数据也可来自数组绑定（bindings.rows + 列的 bind），动态取值见第 6 课。表格是能力最完整的元素（跨页延续、合计行、补空行），专页详解见 table 表格元素。

钢笔路径 pen-path ​

在画布上，可用「钢笔」（P）加锚点，按 Enter 完成开放路径，或点击起点闭合。通过 API 创建时，props.anchors 中的锚点、入柄和出柄均使用路径局部坐标；viewWidth 和 viewHeight 定义局部坐标范围，元素的 width 和 height 决定它在页面上的尺寸。

ts
page.elements.add({
  type: 'pen-path',
  x: 10,
  y: 10,
  width: 40,
  height: 20,
  props: {
    anchors: [
      {
        incoming: { x: 0, y: 20 },
        outgoing: { x: 10, y: 20 },
        point: { x: 0, y: 20 },
      },
      {
        incoming: { x: 25, y: 0 },
        outgoing: { x: 40, y: 0 },
        point: { x: 40, y: 0 },
      },
    ],
    closed: false,
    stroke: '#333333',
    strokeWidth: 0.4,
    viewHeight: 20,
    viewWidth: 40,
  },
})

strokeWidth 单位为 mm。设置 closed: true 后可通过 fill 填色；开放路径只绘制描边。钢笔工具和锚点编辑均由设计器内置，无需安装插件。

元素更新与删除 ​

ts
const el = page.elements.add({
  type: 'text',
  x: 10,
  y: 10,
  width: 80,
  height: 14,
}) // add 返回元素句柄
el.update({ x: 30, y: 40 }) // 通用字段
page.elements.updateProps(el, { text: '新文案' }) // props
page.elements.remove(el) // 删除
page.elements.clear() // 清空本页
