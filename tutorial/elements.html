4. 绘制内置元素 ​

八种内置元素统一经 page.elements.add({ type, x, y, width, height, props }) 创建；props 字段随类型不同。完整属性表见 API 参考 / 内置元素。

前置：第 2 课创建的 DesignStudio 实例与活动页面句柄 page。

第 4 课：八种元素代码绘制
在新窗口打开

文本 text ​

ts
// page：第 2 课从 studio.page.active 取得的页面句柄
page.elements.add({
  type: 'text',
  x: 10, y: 10, width: 190, height: 14,
  props: {
    text: '客户：张女士', // 动态取值（表达式绑定）见第 6 课
    fontSize: 12,        // pt
    fontWeight: '700',
    textAlign: 'left',
    autoHeight: true,    // 按内容自适应高度
  },
})

矩形 rect / 圆形 ellipse ​

ts
page.elements.add({
  type: 'rect', x: 10, y: 40, width: 80, height: 30,
  props: { fill: '#f0f7ff', stroke: '#164b85', strokeWidth: 0.4, radius: 2 },
})
page.elements.add({
  type: 'ellipse', x: 100, y: 40, width: 30, height: 30,
  props: { fill: 'transparent', stroke: '#333333', dash: 'dotted' },
})

线条 line（点驱动） ​

线条由 points（两端点、页面坐标 mm）驱动；x / y / width / height 包围盒由两端点派生，rotation 恒为 0：

ts
page.elements.add({
  type: 'line',
  x: 10, y: 80, width: 190, height: 0,
  points: [{ x: 10, y: 80 }, { x: 200, y: 80 }],
  props: { color: '#333333', strokeWidth: 0.4, dash: 'dashed' },
})

图片 image ​

ts
page.elements.add({
  type: 'image', x: 10, y: 10, width: 30, height: 30,
  props: { src: 'data:image/png;base64,…', fit: 'contain' }, // contain | cover | fill
})

条形码 barcode ​

ts
page.elements.add({
  type: 'barcode', x: 10, y: 92, width: 70, height: 20,
  props: {
    value: 'SO-2026-001',
    format: 'CODE128', // 共 10 种码制
    displayValue: true,
    margin: 0.5,       // 静区 mm
  },
})

二维码 qrcode ​

ts
page.elements.add({
  type: 'qrcode', x: 100, y: 88, width: 26, height: 26,
  props: { value: 'https://example.com/order/SO-2026-001', level: 'M' }, // L M Q H
})

表格 table ​

ts
page.elements.add({
  type: 'table',
  x: 10, y: 128, width: 190,
  props: {
    columns: [
      { title: '商品', width: 3, align: 'left' },
      { title: '数量', width: 1, align: 'right' },
      { title: '金额', width: 2, align: 'right',
        format: { type: 'currency', digits: 2 } },
    ],
    rows: [
      ['复印纸 A4', '2', '128.00'],
      ['墨盒', '1', '80.00'],
    ],
    heightMode: 'auto',
    pagination: { crossPage: true, repeatHeader: true },
  },
})

行数据也可来自数组绑定（bindings.rows + 列的 bind），动态取值见第 6 课。表格是能力最完整的元素（跨页延续、合计行、补空行），专页详解见 table 表格元素。

元素更新与删除 ​

ts
const el = page.elements.add({ type: 'text', x: 10, y: 10, width: 80, height: 14 }) // add 返回元素句柄
el.update({ x: 30, y: 40 })                        // 通用字段
page.elements.updateProps(el, { text: '新文案' })   // props
page.elements.remove(el)                           // 删除
page.elements.clear()                              // 清空本页
