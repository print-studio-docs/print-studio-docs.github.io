3. 页面尺寸与方向 ​

前置：第 2 课创建的 DesignStudio 实例（已通过 document.create() 从空白文档开始）。

所有几何值以毫米（mm）为单位，页面左上角为原点，y 向下。单位与坐标约定见指南 开发规范 · 单位与坐标。

设置尺寸 ​

ts
// studio 与 page：第 2 课创建的实例与活动页面句柄
const page = studio.page.active

page.update({ width: 210, height: 297 }) // A4 纵向（空白文档的初始尺寸）

// A4 横向：交换宽高即可
page.update({ width: 297, height: 210 })

方向没有独立字段：width > height 即横版，HTML 的 @page 规则与 PDF 输出自动按宽高关系处理。

页边距 ​

ts
page.update({
  margins: { top: 25, right: 10, bottom: 20, left: 10 },
})

边距主要作用于布局语义（循环、表格分页以内容区高度为准）；元素定位仍以页面左上角为原点。

常用尺寸预设 ​

PAGE_PRESETS 常量（@printstack/print-studio/core）：

预设宽 × 高 (mm)
A4 纵向210 × 297
A4 横向297 × 210
A5 纵向148 × 210
Letter215.9 × 279.4
收银纸80 × 200
收银纸（小）58 × 160
ts
import { PAGE_PRESETS } from '@printstack/print-studio/core'

// label 是随界面语言变化的展示名，仅用于展示；查找预设按宽高匹配
const preset = PAGE_PRESETS.find((item) => item.width === 210 && item.height === 297)
if (preset) {
  page.update({ width: preset.width, height: preset.height })
}

自定义尺寸直接写毫米值——标签类场景常用 100×150、100×100 等。

多页文档 ​

ts
const order = studio.page.create({ name: '订单页', width: 210, height: 297 })
const labels = studio.page.create({ name: '标签页', width: 100, height: 150 })
studio.page.setActive(order)
console.log(studio.page.list.map((item) => item.data?.name))

每页可以有不同尺寸（如订单页 A4 + 标签页 100×150）。共用的页眉页脚放页面模板与共用样式层。

检查点 ​

  • studio.page.list 包含新建的页面，item.data.width / item.data.height 与设置一致。
  • studio.page.setActive(id) 后 studio.page.active.id 随之变化。
  • 边距修改后 studio.page.active.data.margins 反映新值。
