9. 执行打印 ​

前置：第 2 课创建的 Designer 实例。

studio.print(input, { target: 'browser' }) 把模板与数据渲染为分页 HTML，注入隐藏 iframe 并调起浏览器打印对话框。浏览器打印对话框不是打印预览；打印前的效果确认用 studio.preview()（第 8 课）。

第 9 课：调起浏览器打印对话框打印动作由按钮触发，resolve 只代表任务已提交
在 Playground 中编辑 在新窗口练习

基本用法 ​

ts
const { warnings } = await studio.print(
  {
    customer: { name: '张女士' },
    items: [{ name: '复印纸', quantity: 2, amount: 128 }],
  },
  { target: 'browser' },
)
console.log(warnings)

结果语义 ​

阶段print() resolve 代表的含义
resolve打印任务已提交给浏览器（隐藏 iframe 已调用 window.print()）
用户确认由浏览器打印对话框决定，API 无法感知
设备出纸同上

返回成功不代表用户确认或设备出纸成功。需要知道用户是否打印，只能由宿主监听浏览器 afterprint 事件自行封装。隐藏 iframe 在打印结束（afterprint）后清理，超时 60 秒后清理。

指定模板打印（纯输出） ​

ts
import { deserializeDocument } from '@printstack/print-studio/core'
import { createPrinter } from '@printstack/print-studio/printer'

export async function printStoredTemplate(
  templateJson: string, // 已有的模板 JSON（见第 7 课）
  input: Record<string, unknown>, // 本次打印数据（见第 6 课）
) {
  const renderer = createPrinter() // 纯输出入口，成员见 createPrinter() 参考
  try {
    const { document: template } = deserializeDocument(
      templateJson,
      renderer.elements,
    )
    return await renderer.print(template, input, {
      target: 'browser',
      timeoutMs: 30000,
    })
  } finally {
    renderer.dispose()
  }
}

选项 ​

选项功能类型必填默认值说明
timeoutMs等待上限number否60000覆盖字体准备、渲染与 iframe 就绪；必须为有限正数
signal取消渲染与等待AbortSignal否—

打印样式 ​

打印 CSS 由库生成，业务无需提供：

  • 每页尺寸写入对应的 @page size；
  • 页面分节设置 break-after: page 保证分页边界；
  • print-color-adjust: exact 保留背景色。

批量打印 ​

ts
const customers = [{ name: '张女士' }, { name: '李先生' }]
for (const customer of customers) {
  await studio.print({ customer }) // 每次调用独立打开一个打印对话框
}

每次 print() 调用独立调起一个打印对话框，浏览器不会把多次调用合并为一次会话。更高效的批量方式见第 11 课。

注意事项 ​

  • 没有弹出打印对话框：检查浏览器是否拦截了自动打印（站点权限与弹出窗口设置）。
  • 打印内容分页错位：确认页面尺寸与纸张设置一致（@page size 已自动写入）。
  • 背景色丢失：在打印对话框勾选「背景图形」。
