文档站维护 ​

本页面向仓库维护者。业务接入从快速开始开始。

启动与构建 ​

在仓库根目录执行：

bash
pnpm docs:dev
pnpm docs:build

docs:api 构建库并对 docs/lib/examples、docs/lib/playground 中的 TS / Vue 示例进行类型检查。示例从 @printstack/print-studio、@printstack/print-studio/vue、@printstack/print-studio/designer、@printstack/print-studio/core、@printstack/print-studio/runtime 公共入口导入，对照当前构建产物验证。

docs:build 先执行上述检查，再构建示例容器和 VitePress 站点。产物为 dist/docs/；部署子路径时设置 DOCS_BASE 后重新构建。pnpm build 包含项目、库与文档站构建。

示例容器与浏览器检查 ​

docs:playground 使用构建后的 dist/lib 公共入口，将独立 Vue 应用生成到 docs/lib/public/playground/，由文档站复制到输出目录。生成文件已忽略，不提交。docs:dev 和 docs:build 都先准备容器；修改示例源码后需重新执行 pnpm docs:playground。

文档通过 DemoFrame / PlaygroundEmbed 组件引用容器，使用 withBase 适配站点子路径并附带 embed=1 隐藏容器自带头部；容器自己的资源使用相对路径。仅切换页面不把设计器样式引入文档主题，重置通过重建 iframe 释放旧运行环境。新增运行示例先登记到 playground/example-registry.ts（切换器与入口共用该清单），案例页位于 playground/cases/，复用 playground/snippets/ 中的共享源码；examples/snippets/ 中被 <<< 引用的教学源码保持自包含样式，通过 playground/cases/ 下的案例页包装接入演练场。

执行 pnpm docs:test 验证已构建文档站，首次安装浏览器执行 pnpm exec playwright install chromium。测试覆盖及人工边界见浏览器验收。版本信息维护见版本与迁移。

教学截图来自实际浏览器，执行 node tests/docs/capture-screenshots.mjs 从端口 4174 的文档预览刷新截图，再重新构建文档。可传入完整的示例地址作为第一个参数。截图需检查启动遮罩已经消失、字体与图片完成加载，不能用占位图代替运行结果。

内容与验证边界 ​

主要入门教程使用 <<< 引用示例源码，避免文案代码和实际文件分离。Markdown 内联片段不会由当前示例类型检查自动覆盖；类型通过与静态站构建通过，也不代表浏览器预览和打印已经验收。

当前站点发布手写指南与 API 参考，不生成完整源码 API 网站。多个指南页共用同一 runner 时，运行案例先在 playground/runner.ts 声明类型，再通过 playground/cases/case-runner.vue 组织运行按钮与输出面板。
