浏览器验收 ​

类型检查验证公共入口与示例契约，静态构建验证页面和链接，浏览器验收验证实际运行结果。三者不能互相替代。

运行自动验收 ​

在仓库根目录执行：

bash
pnpm install
pnpm exec playwright install chromium
pnpm build
pnpm docs:test

测试使用构建后的文档站及 dist/lib 公共入口，不用源码别名替代包。配置位于 tests/docs/playwright.config.ts；失败保留 trace，可用 pnpm exec playwright show-trace <trace.zip> 查看。默认自动启动端口 4174 的预览服务。

验收项检查结果
首例画布显示绑定表达式，手动保存、恢复及刷新后恢复
空数组输出页面存在，客户名称保留，不出现 undefined
长文本输出保留完整字符串，尾部明细仍存在
跨页明细生成多页，首条与末条存在，末条只输出一次
预览生命周期关闭删除 iframe，再次打开只创建一个 iframe
PDF浏览器下载实际 PDF，文件头与文件大小有效
文档导航重置重新创建运行环境，离开文档后移除示例容器
字体与图片等待字体就绪，核对默认字体声明、实际图片解码与 PDF 图片对象
扩展初始 12 条输出 2 页，修改为 25 条输出 3 页，顶部边距规则生效
无效输入JSON 非对象时反馈错误，修正后可再次运行

长文本完整出现在 HTML 中，不代表固定高度文本框能显示全部文字；裁切、中文字体、图片清晰度仍需视觉验收。PDF 文件结构有效也不代表所有页已正确绘制。

人工验收 ​

在示例练习的新窗口中完成以下操作，并记录操作系统、浏览器版本和库版本：

  1. 修改文本、保存、再次修改和恢复，核对画布和“未保存”标记。
  2. 预览真实数据，关闭后继续编辑；多次进入和离开宿主路由，确认没有残留预览或重复回调。
  3. 在文档中加入中文、业务字体与图片，通过 rendering.fonts 或可读取的 @font-face 提供字体。在字体、图片响应延迟时立即输出，确认布局测量等待字体、打印等待 iframe 资源；同时验证字体失败拒绝、图片失败告警、超时及取消。
  4. 导出 PDF，逐页检查中文、图片、分页表头与末条商品；对比 HTML 预览。
  5. 调用浏览器打印，确认纸张、缩放、边距、背景与实际设备出纸。取消打印后应可以继续编辑。

自动测试当前以 Chromium 为基线，不能替代 Firefox、Safari、移动端、实际打印设备及真实路由宿主的验收。兼容范围见版本与迁移。
