模板格式与迁移 ​

本系统的可编辑打印模板是一份 PrintDocument 对象，通常序列化为 JSON 保存。要迁移其他设计器的模板，需要在业务侧读取源格式，转换为 PrintDocument，再加载到设计器或传给输出入口。本页说明目标格式和转换方法；源格式的读取、字段映射与不支持功能的处理由转换工具负责。

DocumentParser 是输出解析器：它接收本系统文档并生成 HTML、PDF 等结果，不负责读取其他设计器的模板。外部模板转换不需要注册 DocumentParser。需要扩展输出实现时，参考插件与扩展。

文档结构 ​

text
PrintDocument
├─ name、version、parserVersion
├─ pages[]                         页面及其 elements[]、guides[]
├─ dataSources[]                   数据结构与示例数据
├─ templates[]                     多页面共用的页面模板
├─ repeatGroups[]、followBlocks[]  循环与跟随布局
└─ elementGroups[]                 图层组成员关系

name、version 和非空 pages 是文档的基本结构；其他集合可省略。完整类型见 PrintDocument 类型。version 是文档格式版本，当前为 1.0；parserVersion 选择输出解析器版本，省略时使用 1.0.0。这两个版本字段不负责格式迁移；旧版数据源声明需在加载前按数据绑定迁移。

对象转换时关注的字段
页面 PageNodeid、name、width、height、background、elements、guides；方向由宽高决定
元素 ElementNodeid、type、name、x、y、width、height、rotation、opacity、visible、locked、props；可选 bindings、points
数据源 DataSourcekey 对应打印数据的顶层键，type 声明根值类型，对象和数组可通过 schema 描述字段，sampleData 用于示例输入
页面模板 PageTemplatepage 为可复用内容容器，页面通过 templateId 引用；与整份打印模板不同
循环区块 RepeatGrouppageId、elementIds 引用同页元素，collection 是数组绑定路径

页面和元素的 ID 应在转换结果中保持唯一，引用它们的字段必须使用对应 ID。页面元素按 elements 数组顺序叠放，索引 0 在最底层。参考线不参与打印，图层组只保存成员关系，不改变元素的扁平存储和输出。页面模板、循环区块、跟随块及图层组的字段见类型定义和页面模板与布局扩展。

坐标、单位和元素 ​

  • 页面尺寸、元素位置和尺寸、边距及线宽使用 mm；字号使用 pt，旋转使用度。页面左上角是元素坐标原点，Y 轴向下。源数据为像素时，应按源设计器实际使用的 DPI 换算：mm = px × 25.4 / DPI；不要直接把屏幕像素当作毫米。
  • 定界框元素用 x/y/width/height 和绕中心顺时针的 rotation 表示几何。线条 line 是点驱动元素：points 存页面坐标中的端点，包围盒由点集派生，rotation 为 0。转换线条时应先把源几何转换成端点，不能只复制旋转值。
  • type 必须对应目标注册表中的元素定义；每种元素的专属属性放在 props 中。内置类型为 text、rect、ellipse、line、image、barcode、qrcode 和 table。具体字段及单位见内置元素参考。例如文本内容是 props.text，矩形颜色是 props.fill / stroke，图片地址是 props.src。
  • 对齐、字体、颜色、线型、条形码制式和图片适配方式应逐项映射到目标支持的值。属性缺失会使用目标元素默认值，不一定与源设计器的默认值相同；字体及远程图片还需在目标输出环境中可用。

数据和布局映射 ​

字符串内容可写成 订单：{{ order.number }}；输出时传入 { order: { number: 'SO-001' } }。路径、格式化器和文档变量的语法见数据绑定。不要直接复制源设计器特有的表达式或脚本；应转换受支持的路径和格式化方式，对无法表达的逻辑报告给调用方。

表格动态行使用 bindings: { rows: 'items' }，列的 bind 相对于每行；静态行放在 props.rows。循环区块的 collection 也是不带花括号的数组路径，成员仍是页面中的扁平元素。表格分页、合计和循环排布有各自的目标配置，不应把源系统的分页参数直接原样复制。参见表格元素和数据绑定。

dataSources 可记录字段结构和 sampleData，但实际打印数据由输出时的 input 提供。使用 createPrinter() 时必须显式传入数据；{} 不会自动合并示例数据。共用页眉页脚可映射为页面模板；其他无法一一对应的布局或元素应记录为转换告警或拒绝转换，避免静默丢失内容。

示例：转换简单的像素模板 ​

下面的源格式是为说明转换过程虚构的 JSON：单页、96 DPI、元素按从底到顶的顺序排列，只包含静态文本、字段文本和矩形。真实项目应按源格式实现解析和校验，不能直接把此示例当作其他产品的格式。

ts
import {
  createBuiltinElementRegistry,
  createElement,
  createPage,
  deserializeDocument,
  DOCUMENT_VERSION,
} from '@printstack/print-studio/core'
import type { ElementNode, PrintDocument } from '@printstack/print-studio/core'

type SourceItem =
  | {
      kind: 'text'
      x: number
      y: number
      width: number
      height: number
      text: string
      fontSizePx: number
    }
  | {
      kind: 'field'
      x: number
      y: number
      width: number
      height: number
      path: string
      fontSizePx: number
    }
  | {
      kind: 'box'
      x: number
      y: number
      width: number
      height: number
      fill: string
      stroke: string
    }

interface SourceTemplate {
  name: string
  width: number
  height: number
  items: SourceItem[]
}

const source: SourceTemplate = {
  name: '订单标签',
  width: 384,
  height: 192,
  items: [
    {
      kind: 'box',
      x: 0,
      y: 0,
      width: 384,
      height: 192,
      fill: '#ffffff',
      stroke: '#333333',
    },
    {
      kind: 'text',
      x: 16,
      y: 16,
      width: 200,
      height: 24,
      text: '订单号',
      fontSizePx: 16,
    },
    {
      kind: 'field',
      x: 16,
      y: 48,
      width: 300,
      height: 24,
      path: 'order.number',
      fontSizePx: 16,
    },
  ],
}

function convertTemplate(source: SourceTemplate): PrintDocument {
  const dpi = 96 // 此示例源格式的约定；真实源格式应读取或配置 DPI
  const mm = (px: number) => (px * 25.4) / dpi
  const pt = (px: number) => (px * 72) / dpi
  const elements = createBuiltinElementRegistry()
  const page = createPage(mm(source.width), mm(source.height), '标签')
  page.templateId = 'template-none' // 保留此页面的独立尺寸，不应用空白页面模板

  for (const item of source.items) {
    const geometry = {
      x: mm(item.x),
      y: mm(item.y),
      width: mm(item.width),
      height: mm(item.height),
    }
    let node: ElementNode
    switch (item.kind) {
      case 'text':
        node = createElement(
          'text',
          {
            ...geometry,
            props: { text: item.text, fontSize: pt(item.fontSizePx) },
          },
          elements,
        )
        break
      case 'field':
        // 此示例只接受由字段名和点组成的路径，避免把源脚本当作表达式。
        if (!/^[A-Za-z_$][\w$]*(\.[A-Za-z_$][\w$]*)*$/.test(item.path)) {
          throw new Error(`不支持的字段路径：${item.path}`)
        }
        node = createElement(
          'text',
          {
            ...geometry,
            props: {
              text: `{{ ${item.path} }}`,
              fontSize: pt(item.fontSizePx),
            },
          },
          elements,
        )
        break
      case 'box':
        node = createElement(
          'rect',
          {
            ...geometry,
            props: { fill: item.fill, stroke: item.stroke },
          },
          elements,
        )
        break
      default:
        throw new Error('不支持的源元素类型')
    }
    page.elements.push(node)
  }

  const candidate: PrintDocument = {
    name: source.name,
    version: DOCUMENT_VERSION,
    pages: [page],
  }
  const { document, skippedTypes } = deserializeDocument(candidate, elements)
  if (skippedTypes.length > 0) {
    throw new Error(`未注册的目标元素：${skippedTypes.join(', ')}`)
  }
  return document
}

const template = convertTemplate(source)
const json = JSON.stringify(template) // 保存或传输给业务系统

createPage 和 createElement 生成 ID 并补充默认字段；createElement 还会归一化属性和尺寸，因此结果可能与输入尺寸不同。页面设置 templateId: 'template-none' 可保留自身尺寸和背景；缺省时应用内置空白页面模板的布局和背景。这里复用同一个内置元素注册表创建和反序列化。实际从 JSON 读取源模板时，先 JSON.parse 并验证未知输入的结构、数值、单位和类型；TypeScript 类型本身不会校验运行时数据。

加载、输出和验收 ​

ts
import { createDesigner } from '@printstack/print-studio'
import { createPrinter } from '@printstack/print-studio/printer'

// template 是上一步转换后的 PrintDocument。
const studio = createDesigner({ storage: false })
studio.document.load(template) // 可继续在设计器中编辑

const printer = createPrinter()
try {
  const { html, warnings } = await printer.toHTML(template, {
    order: { number: 'SO-001' },
  })
  console.log(warnings) // 检查绑定、资源和布局告警
  // 使用 html，或调用 printer.toPDF(template, input) 检查 PDF。
} finally {
  printer.dispose()
  studio.dispose()
}

deserializeDocument 接收对象，宽容补全字段、剔除未注册类型，并返回 skippedTypes；无页面时抛错。它不是外部格式转换器，也不保证源模板的语义和视觉效果完整保留。导入前应检查转换工具自己的告警和 skippedTypes；如果使用自定义元素，反序列化、设计器和输出器都需要配置相同的元素定义。

使用有代表性的源模板和真实数据，检查页面尺寸、层级、坐标、字体、图片、条形码、绑定取值与分页；分别核对设计器编辑、HTML、PDF 和实际打印结果。比较转换前后的元素数量及引用关系，检查输出返回的 warnings，再保存转换后的 JSON。加载与保存 API 见模板保存与加载。

hiprint 模板转换 ​

将 vue-plugin-hiprint 的 getJson() 或 getJsonTid() 结果转换为可编辑的 PrintDocument。转换器根据 vue-plugin-hiprint 实现，可能与官方原版存在差异；转换不依赖 hiprint 运行时。

选择转换方式 ​

场景怎么做
转换单个 JSON 文件打开hiprint 模板转换器，粘贴 JSON 或导入文件，转换后下载结果。转换在浏览器本地完成。
在代码中批量转换，或需要自定义类型调用下面的 convertHiprintTemplate API。

在代码中转换 ​

ts
import { convertHiprintTemplate } from '@printstack/print-studio/hiprint'

const { document, warnings } = convertHiprintTemplate(hiprintJson, {
  name: '迁移模板',
  // getJsonTid() 省略自定义类型定义时，按 tid 提供原 provider 的定义
  types: {
    'myProvider.customer': { type: 'text', title: '客户', field: 'customer' },
  },
})
console.log(warnings) // 检查每条提示的 code、path 和 message
studio.document.load(document)

输入可以是对象或 JSON 字符串。getJsonTid() 中仅含 tid 的内置类型可直接识别；自定义类型如未提供定义，会跳过对应元素并生成提示。types 可传入原 provider 的类型定义，但转换器不会执行其中的函数。JSON 无效、缺少 panel 或页面尺寸无效时会抛出 DesignerException。

转换后检查什么 ​

  1. 查看 warnings：按 path 找到源模板中的位置，处理被跳过的元素和未完整转换的属性。在线工具中可展开提示查看路径。
  2. 在设计器中加载结果，检查页面尺寸、元素位置、字体、图片、条形码和旋转效果。
  3. 使用真实打印数据检查绑定、表格和分页，并核对 HTML、PDF 和实际打印结果。转换器不转换打印数据，输出时仍需传入业务数据。

需要手动复核

HTML、自定义渲染、动态表格合并、脚本、水印、页码、页眉页脚重复及复杂布局不能保证等价。长文本和表格分页也需要复核；转换不会生成循环区块。

转换范围 ​

源内容转换结果
panel每个 panel 转为一个设计页面；源 panel 的动态分页不等同于固定页面数量。
文本、长文本、图片、水平/垂直线、矩形、椭圆、条形码、二维码、表格转为对应元素，保留源数组顺序作为叠放顺序；文本 textType 中的条码也会识别。
字段、表格行和列字段转为绑定表达式，表格 field 转为行绑定；根据已转换字段生成 dataSources，无法确定的字段类型按字符串声明。部分表格列、表头合并及分页设置可转换。表头无效或超过 128 行、256 列时会告警，并尝试仅使用末行生成列。
页码转为页面模板中的普通文本元素，由页面引用以便自动续页重复显示；隐藏页码的 panel 不生成该元素。页码按整个文档计算。
源格式和单位

根对象的 panels[] 保存纸张配置，panel 的 width/height 为毫米，paperHeader/paperFooter 为磅，printElements[] 保存元素。元素包含 options 及 printElementType，也可以通过 tid 引用 provider。表格 columns 是表头行数组，列包含 field、title、width、rowspan、colspan 等配置。

元素的 left/top/width/height 和列宽按磅转为毫米（25.4 / 72）；字号保持磅。自定义 provider 可以提供更多属性或函数，源格式并非固定封闭结构。

实现依据上游 0.0.62（提交 66195d3721ebbf8c2a4dea381d4d5f12d3384f98）的公开代码。
