开发规范 ​

遵循以下约定可避免最常见的集成问题。

单位与坐标 ​

  • 位置、宽高、边距、间距：mm；字号：pt；旋转：度（顺时针，绕元素中心）。
  • 坐标原点为页面左上角，y 向下。
  • 代码中写坐标保留最多 2 位小数，消除浮点残差。

数据流 ​

  1. 模板与数据分离：模板 JSON 持久化（服务端 / localStorage）；每次打印注入 input，绝不把业务数据写进模板。
  2. 快照只读：document.data、句柄 data、事件 payload 都是快照或内部引用，只读使用；修改一律走实例方法。
  3. 显式输入：toHTML({}) 表示空输入，不会自动合并示例数据；需要示例数据就省略 input 参数。
  4. 数组属性整体提交：更新 columns、rows、points 时提交新数组，不做就地 push。

资源与生命周期 ​

  • createPrintStudio() / createPrintRenderer() 的实例用完必须 dispose()，放在 finally 中；await print() 返回（打印对话框已调起）后再 dispose 是安全的。含 await print() 的流程同样在 finally 中释放即可。
  • preview() 返回的 PreviewHandle 在不再展示时调用 close()；预览窗口未关闭前不要 dispose() 实例。
  • events.on / state.subscribe / errors.addRule 返回解绑函数，按订阅生命周期调用。
  • Vue 中优先 usePrintStudio()（随作用域自动清理）；跨路由、跨页面复用的实例用 createPrintStudio() 创建并自行管理。

错误处理 ​

  • 实例方法调用失败由调用方接 Promise；统一上报经 studio.errors（capture 记录、addRule 定制规则）。
  • 输出 warnings 必须检查：绑定取值失败、资源加载失败不中断输出，但会体现在 warnings 中。
  • 领域错误类型为 DesignerException（@printstack/print-studio/core），按 error.code 分支。
  • 外部异步失败调用 studio.errors.capture(error, context)，交由统一错误处理展示，不要在业务代码中静默丢弃。

事件使用 ​

  • 刷新按钮状态优先 state.subscribe()（同步、轻量）；需要动作 payload 才用事件总线。
  • 订阅不回放当前值：先读状态再监听。
  • 事件回调保持轻量；远端保存由业务层防抖。
  • 撤销 / 加载不重放元素事件；维护文档镜像监听 document:changed 并整体读取快照。

模板 JSON 管理 ​

  • 版本字段：version 当前 '1.0'；加载外部 JSON 用 deserializeDocument 检查 skippedTypes。
  • 保存前后不做格式假设；JSON 即序列化结果，不要手工重组结构。
  • 重命名数据源 key 后同步更新表达式 / 表格绑定 / 循环 collection。

扩展 ​

  • 新元素类型走 ElementDefinition 注册，不在业务代码里按 type 写分支渲染。
  • 界面扩展（按钮 / 面板 / 命令 / 菜单项）通过插件系统接入：definePlugin() 声明权限与清单，setup 中经 commands / events / panels / menu 等公开入口注册能力。
  • 自定义字体在 rendering.fonts 声明，fontFamily 与 family 精确匹配，粗体提供对应字重文件。
