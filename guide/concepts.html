核心概念 ​

以下概念是理解库集成 API 组织结构的基础。

文档（PrintDocument）与「模板」 ​

一份文档 = 一个可保存为 JSON 的打印模板，包含页面、元素、数据源、页面模板与循环配置。studio.document 管理它；studio.export.json() 序列化。业务上说的「维护模板」就是维护这份 JSON。

页面（PageNode） ​

文档由页面数组组成。每页有 width/height（mm）、margins、background、elements 与可选 templateId。方向由宽高关系表达：width > height 即横版。元素数组索引 0 在最底层。

元素（ElementNode） ​

页面内容的原子单元：text / rect / ellipse / line / image / barcode / qrcode / table 八种内置类型。通用字段（位置、尺寸、旋转、不透明度、锁定、显隐）+ 类型专属 props。所有元素经注册表驱动，新增类型即注册 ElementDefinition。

线条是点驱动元素：几何由 points（页面坐标中的两端点）定义，包围盒为派生值，rotation 恒为 0。

页面模板（PageTemplate）——不是「模板库」 ​

概念含义API
页面模板多个页面共用的页眉、页脚、背景等内容studio.template
模板库整份文档的可复用副本业务层自行存储 JSON

页面模板支持继承（baseTemplateId）、双面（facingPages + 偶数页变体）、表尾溢出延续（长表格的溢出行延续到页面模板承载的专属页面）。渲染时模板元素显示在页面元素下方。

数据源与绑定 ​

数据源（dataSource）声明数据结构与示例数据；绑定把元素属性连到数据字段：

  • 表达式绑定：字符串属性内嵌 {{ 路径 | 格式化:参数 }}。
  • 结构化绑定：bindings: { rows: 'items' }（表格数组行）；循环成员内直接用行字段与 $index。
  • 文档变量：$document.pageNumber/pageCount/now/documentName/pageName。

渲染时注入的 input 按 key 对应数据源，不写回模板。

循环区块与跟随块 ​

  • 循环区块（RepeatGroup）：一组元素按数组数据平铺，direction 支持 grid 网格（标签平铺）、page 每条数据一页、vertical 纵向列表，超页自动分页；positionMode: 'flow' 时后续内容上移。
  • 跟随块（FollowBlock）：元素始终跟随目标（表格 / 循环区块）末尾，间距 gap，签字区场景。

表格跨页与合计 ​

  • 跨页续排：pagination.crossPage 开启后长表格自动分页，延续页可重复表头（repeatHeader）。
  • 补空行：fillEmptyRows 用空白行补满本页余量；配置 rowsPerPage 时补齐到固定行数。
  • 合计：summary 提供每页小计（scope: 'eachPage'）与全量合计（scope: 'lastPage'）。

输出与渲染管线 ​

所有输出走同一条管线：

text
input → 解析绑定 → 文档展开（循环区块物化、自动分页）→ 输出解析器渲染 → HTML / PDF

展开后的中间结果仍是合法 PrintDocument——HTML / PDF 解析器对绑定无感知。执行后端可选主线程 / Worker / 混合（rendering.worker），execution 字段用于诊断。

生命周期 ​

text
createPrintStudio()  ──mount()──▶ 设计器视图（按需加载，隔离 iframe）
      │                     │
      │◀──── unmount() ─────┘   只卸视图，实例保留
      ▼
   dispose()  销毁实例（联动 unmount），实例不可再用
  • mount resolve 即界面与插件就绪；一个实例同时只挂载一个设计器。
  • usePrintStudio() 本次创建的实例随 Vue 作用域销毁自动 dispose。
  • 纯输出实例 createPrintRenderer() 用完 dispose()。

快照语义 ​

所有查询返回快照或句柄：

  • 句柄：{ id, data, update, remove }；删除后 data 为 undefined。
  • 集合：list 是属性不是函数；get(ref) 接收 ID 或 { id } 对象。
  • 修改必须走句柄 / 集合方法；直接改快照不生效。
