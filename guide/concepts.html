核心概念 ​

整体架构 ​

库按「框架无关内核 + 能力层」分层，依赖只自上而下：

text
core（框架无关：文档模型 · 几何 · 数据上下文 · 事件 · 注册表）
  ▲
  ├─ elements  九种内置元素定义
  ├─ designer  可视化设计器（状态 · 命令 · 插件 · 视图）
  ├─ parser    文档展开与 HTML / PDF 解析器、渲染运行时
  └─ 外部插件  独立 package（如 SaaS 服务集成）
  • core 不依赖任何上层模块。
  • parser 同样不依赖设计器，可脱离设计器独立使用——createPrinter() 即基于此。

核心模块 ​

模块职责包入口
core文档模型、页面与元素结构、数据上下文与绑定表达式、元素注册表、错误类型@printstack/print-studio/core
elements内置元素定义：属性 Schema、渲染、测量与分页能力Designer 默认全量；Printer 默认全量，也支持显式集合
designer设计器界面、状态管理、命令与事件、插件系统、挂载入口/designer、/vue
parser渲染前文档展开、HTML / PDF 解析器、渲染运行时随主入口、/runtime
外部插件可选业务插件与外部服务集成@printstack/saas

模块之间的关系 ​

  • 注册表协作：designer 与 parser 经 elementRegistry / parserRegistry 查找元素与解析器能力，不出现按元素类型硬编码的分支；两侧注册的定义需保持一致。
  • 编辑与输出分离：designer 只负责编辑与状态，输出一律走 parser 模块的渲染管线。
  • 插件经契约访问宿主：业务插件通过 PluginDefinition 契约获得按权限约束的能力（命令、事件、面板、文档读写），不直连内部状态，见插件与扩展。

设计理念 ​

  • 模板与数据分离：模板 JSON 持久化，业务数据渲染时注入，不写回模板。
  • 文档是唯一数据源：文档数据只存于文档模型，编辑统一提交历史（撤销 / 重做），不另存副本。
  • 注册表驱动：元素、解析器、命令、面板等能力按标识注册查找，新增能力不改内核代码（开闭原则）。
  • 命令与事件是统一入口：菜单、快捷键等动作都是命令；状态变化派生语义事件（如 selection:changed），扩展方监听而非侵入。
  • 异常分类处理：编程错误直接抛出快速失败；领域操作失败抛出 DesignerException 统一展示；预期分支（未选中、用户取消）不作为异常。

文档（PrintDocument）与「模板」 ​

一份文档 = 一个可保存为 JSON 的打印模板，包含页面、元素、数据源、页面模板与循环配置。studio.document 管理它；studio.export.json() 序列化。业务上说的「维护模板」就是维护这份 JSON。

页面（PageNode） ​

文档由页面数组组成。每页有 width/height（mm）、margins、background、elements 与可选 templateId。方向由宽高关系表达：width > height 即横版。元素数组索引 0 在最底层。

元素（ElementNode） ​

页面内容的原子单元：text / rect / ellipse / line / image / barcode / qrcode / table / pen-path 九种内置类型。通用字段（位置、尺寸、旋转、不透明度、锁定、显隐）+ 类型专属 props。所有元素经注册表驱动，新增类型即注册 ElementDefinition。

线条是点驱动元素：几何由 points（页面坐标中的两端点）定义，包围盒为派生值，rotation 恒为 0。钢笔路径的锚点和控制柄则保存在路径局部坐标中，元素仍通过定界框定位、缩放和旋转。

页面模板（PageTemplate）——不是「模板库」 ​

概念含义API
页面模板多个页面共用的页眉、页脚、背景等内容studio.template
模板库整份文档的可复用副本业务层自行存储 JSON

页面模板支持继承（baseTemplateId）、双面（facingPages + 偶数页变体）、表尾溢出延续（长表格的溢出行延续到页面模板承载的专属页面）。渲染时模板元素显示在页面元素下方。

数据源与绑定 ​

数据源（dataSource）声明数据结构与示例数据；绑定把元素属性连到数据字段：

  • 表达式绑定：字符串属性内嵌 {{ 路径 | 格式化:参数 }}。
  • 结构化绑定：bindings: { rows: 'items' }（表格数组行）；循环成员内直接用行字段与 $index。
  • 文档变量：$document.pageNumber/pageCount/now/documentName/pageName。

渲染时注入的 input 按 key 对应数据源，不写回模板。

循环区块与跟随块 ​

  • 循环区块（RepeatGroup）：一组元素按数组数据平铺，direction 支持 grid 网格（标签平铺）、page 每条数据一页、vertical 纵向列表，超页自动分页；positionMode: 'flow' 时后续内容上移。
  • 跟随块（FollowBlock）：元素始终跟随目标（表格 / 循环区块）末尾，间距 gap，签字区场景。

循环区块和跟随块的画布角标随画布同比例缩放。

表格跨页与合计 ​

  • 跨页续排：pagination.crossPage 开启后长表格自动分页，延续页可重复表头（repeatHeader）。
  • 补空行：fillEmptyRows 用空白行补满本页余量；配置 rowsPerPage 时补齐到固定行数。
  • 合计：summary 提供每页小计（scope: 'eachPage'）与全量合计（scope: 'lastPage'）。

数据流与执行机制 ​

编辑态：设计器内的工具与命令修改文档模型并统一提交历史；状态变化派生语义事件，扩展方通过事件与状态快照感知，不直接改写内部数据。

输出态：所有输出走同一条管线：

text
input → 解析绑定 → 文档展开（循环区块物化、自动分页）→ 输出解析器渲染 → HTML / PDF

展开后的中间结果仍是合法 PrintDocument——HTML / PDF 解析器对绑定无感知。执行后端可选主线程 / Worker / 混合（rendering.worker），execution 字段用于诊断。

生命周期 ​

text
createDesigner()  ──mount()──▶ 设计器视图（按需加载）
      │                     │
      │◀──── unmount() ─────┘   只卸视图，实例保留
      ▼
   dispose()  销毁实例（联动 unmount），实例不可再用
  • mount resolve 即界面与插件就绪；一个实例同时只挂载一个设计器。
  • useDesigner() 本次创建的实例随 Vue 作用域销毁自动 dispose。
  • 纯输出实例 createPrinter() 用完 dispose()。

快照语义 ​

所有查询返回快照或句柄：

  • 句柄：{ id, data, update, remove }；删除后 data 为 undefined。
  • 集合：list 是属性不是函数；get(ref) 接收 ID 或 { id } 对象。
  • 修改必须走句柄 / 集合方法；直接改快照不生效。

右侧属性检查器 ​

  • 文档：未选择元素时显示文档名称、页数和当前页尺寸。操作提示可关闭；选择元素后，此区块切换为元素属性。
  • 页面：使用「页面」「模板」标签切换列表，在标题右侧新增。在行上右键，或悬停后点击「更多操作」，可管理页面或模板。
  • 图层：按名称或元素类型搜索，并按显隐或锁定状态筛选。搜索或筛选会显示折叠组中的匹配项，不改变组原本的折叠状态；清除筛选后可继续拖拽排序。选中一个未锁定元素时，可通过滑块或百分比输入修改不透明度。

点击区块标题可折叠或展开。拖动展开区块底部的分隔线调整高度（最小 120 px），双击分隔线恢复自动高度。高度和折叠状态随面板布局保留。默认布局下，文档和页面区块按内容占用空间，图层列表使用剩余高度。右栏外观随设计器主题切换。

拖拽面板时，落点提示显示在拖拽预览下方，不遮挡正在移动的内容。
