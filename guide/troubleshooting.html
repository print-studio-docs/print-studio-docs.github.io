常见问题 ​

创建实例应该用 create 还是 use？ ​

Vue 页面内优先使用 usePrintStudio()，实例随 Vue 作用域自动清理；业务模块需要自行管理存活期时用 createPrintStudio()。二者返回同一套实例 API，差异在创建方式与生命周期归属，见简介 · 创建方式。已有模板只需输出时用 createPrintRenderer。

安装时找不到 print-studio 包 ​

确认包源已发布该包（pnpm view @printstack/print-studio version 可查），安装步骤见安装与项目集成。

设计器空白或高度为零 ​

确认容器有明确高度，grid/flex 子项允许收缩，并检查启动错误。先使用快速开始的布局。默认 Vite 模板的居中和宽度样式可按业务布局移除。

命令式挂载提示 already mounted 或 ready 被拒绝 ​

同一个容器或实例同时只能挂载一个设计器，先调用 studio.unmount() 或旧句柄的 unmount() 再重新挂载。mount() / ready 在启动失败时拒绝，初始化完成前卸载会产生 AbortError；宿主应处理拒绝并清理。外部 studio 在卸载后可以复用，入口自建的内部实例随卸载销毁，见 studio.mount() 与 mountPrintDesigner()。

按钮修改了文档，但画布没变化 ​

确认按钮和 <PrintDesigner :studio="studio" /> 使用同一实例。兄弟组件分别调用 usePrintStudio() 通常会创建各自的实例。不要修改 element.data.props 或 document.data 快照来编辑状态，应使用实例方法。

usePrintStudio 的 onSave 或 initialDocument 没生效 ​

检查是否复用了显式或祖先注入的上下文。复用时不重新应用创建选项，配置应放在上下文创建处。替换文档使用 studio.document.load/loadJson，见 usePrintStudio()。

保存失败，或者刷新后内容丢失 ​

document.save() 必须配置 onSave。storage 仅管理本地草稿，默认关闭；export.json() 只返回字符串。快速开始是手动保存再手动恢复，服务器保存示例需要替换接口。浏览器存储也可能失败，应接入统一错误处理。

绑定仍显示表达式或输出为空 ​

画布把绑定变量渲染为标签（不含花括号）；设计时预览使用 sampleData 与 settings.previewWithData。实际输出把数据传给 studio.preview(input) 等方法，确认字段路径匹配。

字符串表达式用双花括号，表格 bindings.rows 和循环 collection 用裸路径。省略输入会使用示例数据；显式 {} 表示空输入，不自动合并示例。检查 warnings，见数据源与数据绑定。

PDF、字体、图片或分页与预期不同 ​

输出需要浏览器 DOM / Canvas 和可读取的字体、图片。输出 API 会在布局前等待字体，预览和打印还会等待 iframe 的字体、图片就绪。检查元素的字族、字重与 rendering.fonts 或 @font-face 是否匹配，字体文件和远程图片是否允许跨域读取、是否满足 CSP。跨域样式表无法读取时，改用 rendering.fonts 显式提供字体 URL，见字体与资源。

字体失败会以 render.font-load-failed 拒绝输出；资源任务超时为 render.resource-timeout，通过输出的 execution.timeoutMs 或预览、打印的 options.timeoutMs 调整，默认 60000ms。仅增大 workerTimeoutMs 不会改变整体资源任务超时。PDF 与浏览器打印走不同输出路径，需要分别验证；打印对话框的纸张、缩放、边距和背景选项也影响结果。

表格自动分页需启用 heightMode: 'auto' 与 pagination.crossPage；长文本自适应高度不等于任意长文本自动拆页，见元素配置和布局。

输出成功是否代表已经打印？ ​

print() 返回表示调用流程完成（打印对话框已调起），无法确认用户是否取消或设备是否出纸。不要仅据此更新「已打印」业务状态，见 print()。

返回了 disposed 错误 ​

实例或借用上下文已被销毁。usePrintStudio() 返回的实例随 Vue 作用域销毁释放，不要继续在模块中持有并使用。跨路由保留实例用业务模块创建的 createPrintStudio()，由持有方最终清理；加载另一份文档后重新查询句柄。
