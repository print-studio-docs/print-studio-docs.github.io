简介 ​

Print Studio 用于制作可编辑的打印模板，注入业务数据后生成 HTML、PDF，或调用浏览器预览与打印。提供可视化设计器与纯代码 API 两条路径：既可以让用户在设计器里编辑模板，也可以完全通过代码创建模板并输出。

组件接入基于 Vue 3，其他浏览器环境通过命令式 API 挂载。

三种使用形态 ​

形态入口适用场景
可视化编辑usePrintStudio() + <PrintDesigner> 或 createPrintStudio() + studio.mount({ el })让用户在设计器里编辑模板
代码编辑 + 输出createPrintStudio()（不挂载视图）业务代码创建 / 修改模板，直接输出
纯输出createPrintRenderer()已有模板 JSON，只注入数据输出

三种形态共用同一条渲染管线；形态之间只是「谁来创建模板、要不要视图」的差别。

创建方式 ​

前两种形态都需要先创建 DesignStudio 实例。按宿主环境选择创建方式：

创建方式来源适用场景
createPrintStudio(options?)@printstack/print-studio纯代码创建实例，拥有全部编辑与输出能力；需要界面时再调用 studio.mount({ el }) 挂载
mountPrintDesigner(container, options?)@printstack/print-studio/designer非 Vue 宿主一次性挂载设计器：同步返回 { ready, studio, unmount } 句柄，ready resolve 即界面与插件就绪；未传 studio 时自建实例，unmount() 时一并销毁
usePrintStudio() + <PrintDesigner>@printstack/print-studio/vueVue 组件树集成：组合式函数创建实例并随 Vue 作用域销毁自动清理，组件负责渲染视图与生命周期

三种方式得到同一套实例 API，差异只在生命周期归属：createPrintStudio() 由持有方自行 dispose()；mountPrintDesigner() 的生命周期跟随句柄；usePrintStudio() 跟随 Vue 作用域。详见 Vue 集成与 createPrintStudio()。

学习路径 ​

从快速开始跑通第一个设计器页面，再按循序渐进教程系统学习；只想用代码完成「建模板 → 打印 → 导出」可走完整工作流。API 细节见 createPrintStudio() 参考与内置元素；在线可运行示例见 Playground。

四个核心对象 ​

对象说明常见操作
studioDesignStudio 实例的业务操作入口studio.document.loadJson(json)
打印文档 PrintDocument可保存为 JSON 的模板模型，含页面、元素与绑定配置studio.document.data 读取快照
打印数据 input本次输出的客户、订单、明细等数据studio.preview({ customer: { name: '张女士' } })
PrintDesigner连接实例的 Vue 可视化设计器组件<PrintDesigner :studio="studio" />

「打印模板」是整个可复用文档；「页面模板」是页面共用的页眉、页脚、背景（studio.template 管理）。打印数据不会写回模板；HTML / PDF 是输出结果，不能当作可编辑 JSON 加载。

基本约定 ​

  • 位置、尺寸、边距单位 mm；字号 pt；旋转度；页面左上角为坐标原点，y 向下。
  • data 是快照：修改快照不会编辑文档，更新必须走句柄或集合方法。
  • 查询缺失对象返回 undefined；句柄在对象删除后其 data 也可能为 undefined；加载另一份文档后重新查询句柄。
  • 模板渲染依赖浏览器环境，不支持 Node.js 服务端渲染（SSR）。
