典型使用场景 ​

1. SaaS 单据打印 ​

在 Web 应用中嵌入设计器，运营人员维护发货单 / 发票模板；系统保存模板 JSON，打印时注入订单数据调用 print() 或 toPDF()。

2. 标签批量打印 ​

商品标签、货架标签、资产标签：用循环区块（repeatGroup，direction: 'grid'）按 3 列 × N 行平铺，超页自动分页；配合 80mm / 58mm 热敏纸预设。

3. 报表导出 ​

多页报表：表格跨页续排（pagination.crossPage）+ 每页小计 / 全量合计（summary）+ 页码（$document.pageNumber/pageCount），一键导出 PDF。

4. 纯输出服务 ​

模板由设计器团队维护、业务系统只做输出：createPrintRenderer() 接收模板 JSON + 业务数据，生成 HTML / PDF / 预览 / 打印，不加载任何编辑能力。

5. 二维码 / 条形码批量 ​

出入库、溯源场景：循环区块内放 barcode / qrcode 元素，按数据批量生成码图并打印或导出。

能力边界 ​

  • 模板渲染依赖浏览器环境，不支持 Node SSR；服务端输出需以无头浏览器等宿主承载。
  • 输出格式为 HTML / PDF / 模板 JSON，无位图导出；各输出入口的返回值与行为见预览 / 打印 / 导出。
  • 浏览器打印依赖用户在打印对话框中确认；「静默打印」需宿主环境另行封装。
