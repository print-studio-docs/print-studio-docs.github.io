快速开始 ​

Print Studio 不要求宿主应用使用 Vue。React、Angular 或原生 JavaScript 项目都可以把设计器挂载到普通 DOM 容器；Vue 项目也可以选择组件接入。如果已有模板，只需预览、打印或导出，可以直接使用纯输出 API，不挂载设计器。

可通过在线 Playground 修改并运行示例代码。

安装 ​

bash
pnpm add @printstack/print-studio
bash
npm install @printstack/print-studio
bash
yarn add @printstack/print-studio

环境要求与兼容范围 ​

  • 浏览器：Chrome / Edge / Firefox / Safari 现代版本；系统打印行为由浏览器决定，建议按目标浏览器实际验收。
  • 模块格式：纯 ESM 包，不提供 CommonJS 接入。
  • 移动端：可打开文档；设计器需要足够的容器宽高。
  • Node.js / SSR：模板渲染依赖浏览器环境，不在服务端直接运行；服务端输出需以无头浏览器等宿主承载。
  • PDF / 图片 / 字体：浏览器资源加载与跨域策略参与输出结果，需用实际资源验证。

选择接入方式 ​

你的需求推荐入口
在业务页面嵌入设计器，不限宿主框架DOM 挂载：createDesigner() + studio.mount({ el })
在 Vue 页面中用组件嵌入设计器Vue 组件：useDesigner() + <PrintDesigner>
已有模板，只需预览、打印或导出纯输出：createPrinter()，不创建编辑实例

Vue 是包的运行时依赖，安装 Print Studio 时会一并安装；非 Vue 项目不需要创建 Vue 应用，也不需要从 /vue 入口导入组件。

DOM 挂载（不限宿主框架） ​

先在页面提供一个有明确高度的容器：

html
<div id="print-designer" style="height: 80vh"></div>

容器插入 DOM 后，在浏览器端运行：

js
import { createDesigner } from '@printstack/print-studio'

const studio = createDesigner()
await studio.mount({ el: '#print-designer' })

// 页面卸载、不再使用实例时，调用 studio.dispose()

el 也可以传入 HTMLElement，例如通过宿主框架的 ref 拿到的容器。mount() 完成后即可使用设计器，无需手动导入样式。若只想移除界面、保留实例和当前文档，使用 studio.unmount()，之后可重新挂载。

Vue 组件（可选） ​

vue
<script setup lang="ts">
import { PrintDesigner, useDesigner } from '@printstack/print-studio/vue'

const studio = useDesigner()
</script>

<template>
  <div style="height: 80vh">
    <PrintDesigner :studio="studio" />
  </div>
</template>

纯输出（已有模板） ​

ts
import { createPrinter } from '@printstack/print-studio/printer'

const printer = createPrinter()

try {
  // template 是已加载的 PrintDocument 对象，不是 JSON 字符串
  await printer.print(template, { orderNo: 'A001' })
} finally {
  printer.dispose()
}

createPrinter() 的输出方法每次都显式传入模板和业务数据；无业务数据时传 {}。JSON 字符串的加载、预览以及 HTML / PDF 导出见 createPrinter() 参考。如果需要用代码创建或编辑模板，但不需要界面，可以只调用 createDesigner()，不调用 mount()。

模板保存到自己的系统 ​

模板在设计器中就是一份 JSON 文档（PrintDocument），创建编辑实例时传入 onSave 回调（Vue 组件接入时，将相同选项传给 useDesigner()）：

ts
const studio = createDesigner({
  onSave: async (document) => {
    // document 为完整模板 JSON，存到你的数据库 / 接口
    await saveToMySystem(templateId, JSON.stringify(document))
  },
})
  • 触发途径：界面「保存」按钮、文件菜单的保存命令，或代码调用 studio.document.save()。save() 返回只表示回调执行完成。
  • 若未提供 onSave，界面保存能力不可用（studio.document.dirty 仍正常）。
  • 程序化获取当前文档：studio.document.data；导出 JSON 字符串：studio.export.json()。
  • 文档有未保存修改时 studio.document.dirty 为 true，可用于自己的保存提示；挂载方式可另传 onDirtyChange 监听脏状态。

加载系统已有模板 ​

两种途径：

代码加载（使用 studio 实例时，无论是否挂载设计器）：

ts
// 字符串 JSON
studio.document.loadJson(json)
// 对象
studio.document.load(document)

创建实例时直接带入初始模板：

ts
const studio = createDesigner({ initialDocument: myTemplate })

接入模板库（让用户在设计器「文件 > 模板库」中浏览、选用、上传、维护系统模板）：

ts
import { createDesigner, definePlugin } from '@printstack/print-studio'
import { createRemoteTemplateProvider } from '@printstack/print-studio/designer'

const myTemplateLibrary = definePlugin({
  manifest: {
    apiVersion: '1.0',
    id: 'my-company:templates',
    version: '1.0.0',
    permissions: ['templates'],
  },
  setup(ctx) {
    return ctx.templateLibrary.register(
      createRemoteTemplateProvider({
        id: 'my-company:remote',
        manifestUrl: '/api/templates/manifest',
        title: () => '系统模板',
        headers: { Authorization: `Bearer ${token}` },
      }),
    )
  },
})

const studio = createDesigner()
studio.use(myTemplateLibrary)
  • 远程清单格式与自定义 Provider 契约见 插件与扩展。Provider 支持 create / update / remove 时，用户可在模板库中把当前文档存入你的系统、更新或删除已有模板。
  • 不需要模板库时也可用 studio.template.import() 程序化导入模板对象。

配置偏好与草稿 ​

草稿与界面偏好分别配置：

配置项默认行为关闭自定义存储
草稿（未保存的模板数据）默认关闭；传入 storage 后自动保存和恢复storage: falsestorage: { get(): string | null, set(json) }，实现 DocumentStorage 接口
偏好设置（主题等界面偏好）默认关闭；设置 persistPreferences: true 后从 localStorage 读取并写回persistPreferences: false启用后传入 preferenceStorage: { get(key), set(key, value) }，实现 PreferenceStorage 接口

宿主系统统一管理模板时，保持草稿关闭并配置 onSave 即可。

在业务场景中预览与打印 ​

模板加载到 studio 后，可以直接传入业务数据 input，键需与模板中的数据绑定一致：

ts
// 预览：打开成品视图，用完后调用 handle.close()
const handle = await studio.preview({ orderNo: 'A001' })

// 打印：提交浏览器打印任务；resolve 表示任务已提交，不代表用户确认或设备出纸
await studio.print({ orderNo: 'A001' })

// 导出
const { blob } = await studio.toPDF({ orderNo: 'A001' })
const { html } = await studio.toHTML({ orderNo: 'A001' })

批量打印、PDF 批量导出等进阶输出见教程 批量打印与批量导出。
