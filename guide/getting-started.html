快速开始 ​

从新的 Vue 3 项目开始，完成「打开设计器 → 编辑模板 → 保存与恢复 → 预览与打印」的全流程。无需后端服务支持。可通过在线 Playground 在线修改并运行示例代码；本地代码接入方式参见循序渐进教程。

以下示例展示完整的接入效果：

快速上手演示
在 Playground 中编辑 在新窗口练习

创建 Vue 项目 ​

bash
pnpm create vite print-demo --template vue-ts
cd print-demo
pnpm install

已有 Vue 3.5+ 项目可跳过本步。

安装库 ​

bash
pnpm add @printstack/print-studio

Vue 已作为运行时依赖自动安装，无需手动引入样式。无需为设计器单独安装 Pinia 插件。

编写第一个设计器页面 ​

不传任何模板时，设计器默认打开内置欢迎模板（横向 A4 海报，可直接试用）。将 src/App.vue 替换为：

vue
<script setup lang="ts">
import { PrintDesigner, usePrintStudio } from '@printstack/print-studio/vue'

const STORAGE_KEY = 'print-demo:template'

const studio = usePrintStudio({
  storage: false, // 关闭自动草稿；点「保存模板」才写入
  onSave: async (document) => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(document))
  },
})

async function saveTemplate() {
  await studio.document.save()
}

function restoreTemplate() {
  const raw = localStorage.getItem(STORAGE_KEY)
  if (raw) {
    studio.document.loadJson(raw)
  }
}

async function preview() {
  await studio.preview()
}

async function print() {
  await studio.print()
}
</script>

<template>
  <div style="height: 80vh; display: flex; flex-direction: column">
    <div style="display: flex; gap: 8px; padding: 8px">
      <span>{{ studio.document.dirty ? '未保存' : '无待保存修改' }}</span>
      <button @click="saveTemplate">保存模板</button>
      <button @click="restoreTemplate">恢复模板</button>
      <button @click="preview">预览</button>
      <button @click="print">打印</button>
    </div>
    <div style="flex: 1; min-height: 0">
      <PrintDesigner :studio="studio" />
    </div>
  </div>
</template>

若使用 Vite 模板，删除 src/main.ts 中模板自带的 import './style.css'，避免演示页样式影响设计器布局。

要点：

  • usePrintStudio() 在页面 setup 作用域中创建实例，传给 PrintDesigner 后代码与界面操作同一份文档；页面卸载时自动清理。
  • 设计器容器需要明确高度（示例用 flex 撑满剩余空间）。
  • 无 initialDocument 时默认打开内置欢迎模板；业务模板可用 initialDocument 传入或 studio.document.loadJson() 加载，见模板保存与加载。

运行并验证 ​

bash
pnpm dev
  1. 设计器应显示欢迎模板（横向 A4 海报）。在画布选中任意文本，属性面板修改文案，状态应变为「未保存」。
  2. 点击「保存模板」，状态复位为「无待保存修改」；再修改一处后点击「恢复模板」，画布应回到刚才保存的内容。
  3. 点击「预览」，应打开成品视图（欢迎模板为静态内容，无数据绑定告警）。
  4. 点击「打印」，浏览器应打开打印对话框；print() 返回只表示打印任务已提交，不代表用户确认或设备出纸。
