设计器区域与操作 ​

以下导览基于默认配置的设计器界面；各区域可通过 ui 选项调整或关闭。挂载后默认打开内置欢迎模板：横向 A4（297 × 210 mm）单页海报，含 30 个演示元素与一个页面模板，可直接选中编辑试用。正式制作模板时，从菜单「文件 → 新建文档」（或代码 studio.document.create()）开始空白文档。

区域用途
菜单栏按「文件 / 编辑 / 页面 / 排版 / 数据 / 视图 / 导出 / 帮助」分组的命令菜单，涵盖新建与保存文档、撤销重做、页面设置、打印预览、打印与导出
工具栏选择工具、抓手平移工具，以及每种内置元素的创建工具；选中创建工具后在画布点击或拖拽创建元素
工具选项栏随当前工具变化的编辑选项
画布与标尺页面是打印范围，页面外区域用于编辑；标尺显示毫米刻度，可从标尺拖出参考线；画布可平移与缩放，缩放不改变物理打印尺寸
页面 / 图层面板切换页面；查看元素列表、叠放顺序、显隐与锁定
属性面板修改选中元素的位置、尺寸、旋转、不透明度、内容与绑定
元素设置单个元素的独立属性弹窗，字段与属性面板一致
信息栏查看坐标、选区尺寸、页码与缩放比例

从选中到修改 ​

用选择工具单击元素，画布出现选择框，属性面板随之显示该元素的可编辑字段。修改内容、字号或位置后画布即时更新；位置与宽高单位是 mm，字号单位是 pt。发生编辑后文档进入未保存状态（studio.document.dirty 为 true），保存成功后复位。

从模板到输出 ​

  • 画布中的绑定变量以标签展示（如 {{ customer.name }}），编辑不影响表达式本身。
  • 「文件 → 打印预览」打开打印预览：查看注入打印数据后的输出效果与绑定告警，可在对话框内调整输入数据。
  • 「文件 → 打印」调起浏览器打印对话框；「导出 → 导出 HTML / 导出 PDF」生成输出文件。
  • 打印数据只参与本次输出，不会把模板中的表达式永久替换掉。
