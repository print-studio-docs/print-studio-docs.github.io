命令 ​

命令是设计器里「可被命名的动作」：菜单项、快捷键、右键菜单、编程调用都指向同一条命令（CommandDefinition）。新增功能 = 注册一条命令，自动获得快捷键与菜单能力；替换功能 = 注册同 id 命令整条替换。

命令机制 ​

ts
interface CommandDefinition {
  id: string              // 点分命名空间，如 'edit.undo'
  title: string           // 默认标题（菜单 / 日志展示）
  run: (ctx, ...args) => unknown   // 执行体，ctx 提供事件总线 / 注册表 / store
  group?: 'file' | 'edit' | 'page' | 'data' | 'layout' | 'view' | 'export' | 'help'  // 菜单分组；缺省 = 不进菜单
  shortcut?: string | string[]     // 快捷键，如 'Ctrl+S'；声明即自动获得键盘触发
  order?: number          // 组内排序
  icon?: string | fn      // 菜单图标
  label?: () => string    // 随状态变化的菜单标题（如 锁定/解锁）
  checked?: () => boolean // 视图开关类菜单勾选态
  enabled?: () => boolean // 返回 false 时菜单置灰（快捷键不受影响）
  danger?: boolean        // 危险操作（红色强调）
  dividerBefore?: boolean // 菜单条目前插入分隔线
  submenu?: …             // 归入二级子菜单（如「对齐」）
  segment?: …             // 相关命令合并为一行分段选择器
  preventDefault?: boolean // 快捷键是否阻止浏览器默认行为（缺省 true）
}

要点：

  • 同 id 重复注册 = 整条替换：插件可据此覆盖内置行为（如替换保存行为）。
  • 命令执行会派发事件：command:before → 内部通知 → command:after；失败派发 command:error（原错误上抛），未注册 id 派发 command:unknown。
  • 菜单 / 快捷键 / 右键菜单索引由命令注册表自动生成，commands:changed 事件通知重建。

宿主如何调用与扩展命令 ​

设计器实例不直接暴露命令注册表，宿主通过插件访问。以下示例在已有的 studio 实例上安装插件：

ts
import { definePlugin } from '@printstack/print-studio'

const myCommands = definePlugin({
  manifest: {
    apiVersion: '1.0',
    commands: ['edit.undo'],
    id: 'my-company:commands',
    permissions: ['commands', 'document:read', 'ui'],
    version: '1.0.0',
  },
  async setup(ctx) {
    // 编程调用内置命令（与点击菜单等效）
    await ctx.commands.execute('edit.undo')

    // 注册新命令（自动进菜单，可声明快捷键）
    ctx.commands.register({
      id: 'my-company.export.json',
      title: '导出业务 JSON',
      group: 'export',
      order: 90,
      shortcut: 'Ctrl+Alt+E',
      run: () => {
        ctx.output.download(
          'template.json',
          new Blob([JSON.stringify(ctx.document.getDocument())]),
        )
      },
    })

    // 整条替换内置命令
    ctx.overrides.command({
      group: 'file',
      id: 'file.save',
      order: 3,
      shortcut: 'Ctrl+S',
      title: '保存',
      async run() {
        const response = await fetch('/api/templates/current', {
          body: JSON.stringify(ctx.document.getDocument()),
          headers: { 'Content-Type': 'application/json' },
          method: 'PUT',
        })
        if (!response.ok) {
          throw new Error(`保存模板失败：${response.status}`)
        }
      },
    })
  },
})

await studio.use(myCommands)
  • 覆盖保存命令前，先将示例中的 /api/templates/current 替换为宿主的保存接口。commands、document:read 和 ui 权限分别用于命令、文档读取和下载。
  • ctx.commands.execute(id, ...args) 返回 Promise<boolean>，成功时解析为 true；未注册命令会抛出异常。调用宿主命令还需在 manifest 的 commands 中声明命令 ID。
  • ctx.overrides.command() 替换整条命令；如需保留菜单位置和快捷键，在新定义中显式声明。插件命令 API 细节见插件与扩展。
  • 未挂载设计器的纯输出场景，直接用实例方法（studio.print() 等），无需命令层。

内置命令目录 ​

内置命令分四类：菜单命令（进菜单 + 快捷键）、域命令（桥接实例方法与命令层，不进菜单）、动态命令（按模式生成的一组命令）、插件命令（内置插件注册）。

文件（file） ​

命令 id快捷键说明
file.new新建文档；页面或页面模板有元素时打开确认对话框
document.create直接创建新文档，不显示确认；由 file.new 或确认对话框调用
file.openCtrl+O打开本地模板 JSON 文件
file.saveCtrl+S保存：调用宿主配置的 onSave；未配置时菜单置灰
file.pageSetup打开页面设置对话框；参数 [pageId?]

编辑（edit） ​

命令 id快捷键说明
edit.undoCtrl+Z撤销
edit.redoCtrl+Shift+Z / Ctrl+Y重做
edit.copyCtrl+C复制选区到剪贴板
edit.cutCtrl+X剪切选区
edit.pasteCtrl+V将复制选区的包围盒中心对准当前视口中心
edit.pasteInPlaceCtrl+Shift+V保留复制时的文档全局坐标
edit.pasteAtCursorCtrl+Alt+V将复制选区的包围盒中心对准鼠标位置；从右键菜单执行时以右键点击处为准
edit.pasteSamePagePosition—以首个源页面左上角为基准，保留选区的相对位置并粘贴到当前页面
edit.deleteDelete / Backspace删除选区元素
edit.duplicateCtrl+D原位创建选区副本
edit.selectAllCtrl+A全选当前页元素
edit.cancelEsc退出内联编辑 / 回到选择工具 / 清空选区（不阻止浏览器默认行为）
edit.clearPage清空当前页全部内容（危险操作）

视口中心、鼠标位置或原始文档坐标可以落在其他页面；若该页面容得下完整选区，粘贴后该页面将成为活动页。粘贴位置不可用，或没有页面容得下指定位置的选区包围盒时，改为在当前页面居中粘贴，不缩放元素。

页面空白处右键提供粘贴和全选；页面外的画布右键提供背景预设及自定义颜色。
